# Programming Basic

프로그래밍 언어의 기초를 **입문서처럼** 정리한 학습 노트 저장소입니다.

각 언어를 기초 문법부터 자료구조, 함수, 객체 지향, 예외 처리, 파일 입출력까지 순서대로 공부할 수 있도록 장(章) 단위로 구성했습니다. 코딩테스트(알고리즘 문제 풀이)에 필요한 빠른 입출력, 구현 패턴, 자주 하는 실수는 각 언어의 **부록**에 따로 모았습니다.

## 기준
- Python 3.10+
- C++17
