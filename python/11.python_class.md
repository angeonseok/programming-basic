# 🐍 파이썬 객체 지향 — 클래스 기초 · 메서드

> 데이터와 그 데이터를 다루는 기능을 하나로 묶는 **클래스**의 기본 구조, 클래스 변수와 인스턴스 변수의 차이, 세 종류의 메서드를 다룬다.

---

## 프로그래밍 패러다임

> **패러다임** : 프로그램을 바라보고 구조화하는 **사고 방식**. 대표적으로 절차 지향과 객체 지향이 있다.

| 구분 | 절차 지향 (Procedural) | 객체 지향 (Object-Oriented) |
|------|------------------------|------------------------------|
| 중심 | **함수(절차)**의 순차 실행 | **객체**들의 상호작용 |
| 데이터 | 함수와 분리 | 객체 안에 데이터+기능 묶음 |
| 비유 | 요리 레시피 (순서대로) | 역할을 가진 직원들의 협업 |
| 장점 | 단순·직관적 | 재사용·확장·유지보수 용이 |

```python
# 절차 지향: 데이터와 함수가 따로
name = "건석"
def greet(n):
    print(f"Hi, {n}")
greet(name)

# 객체 지향: 데이터와 기능을 객체에 묶음
class Person:
    def __init__(self, name):
        self.name = name
    def greet(self):
        print(f"Hi, {self.name}")

p = Person("건석")
p.greet()
```

### 클래스와 객체

> **클래스(class)** : 객체를 만들기 위한 **설계도(틀)**
> **객체(object)** / **인스턴스(instance)** : 설계도로 찍어낸 **실체**

| 개념 | 비유 | 설명 |
|------|------|------|
| 클래스 | 붕어빵 틀 | 속성·기능의 정의 |
| 인스턴스 | 붕어빵 | 틀로 만든 실제 데이터 (여러 개 가능) |

> 💡 사실 파이썬의 모든 값은 객체다. `"hello".upper()`는 `str` 클래스의 인스턴스에서 `upper` 메서드를 부른 것이다.

## 클래스 기초

### 클래스 정의와 인스턴스 생성

> 클래스 이름은 **PascalCase**로 짓는다. `클래스이름()`으로 인스턴스를 만든다.

```python
class Dog:
    species = "개"              # 클래스 변수

    def __init__(self, name):   # 생성자: 인스턴스를 만들 때 자동 호출
        self.name = name        # 인스턴스 변수

    def bark(self):             # 인스턴스 메서드
        print(f"{self.name}: 멍멍")

dog1 = Dog("바둑이")            # 인스턴스 생성 → __init__(dog1, "바둑이") 호출
dog2 = Dog("초코")

dog1.bark()                     # 바둑이: 멍멍
dog2.bark()                     # 초코: 멍멍   (각자 다른 name)
print(dog1.species)             # 개           (클래스 변수)

print(type(dog1))               # <class '__main__.Dog'>
print(isinstance(dog1, Dog))    # True
```

| 구성요소 | 설명 | 예시 |
|----------|------|------|
| 클래스 변수 | 모든 인스턴스가 공유 | `species = "개"` |
| 인스턴스 변수 | 인스턴스마다 고유 | `self.name` |
| 생성자 `__init__` | 인스턴스 생성 시 자동 호출 | 초기 속성 설정 |
| 인스턴스 메서드 | 객체의 동작 | `def bark(self):` |
| `self` | 메서드를 호출한 인스턴스 자신 | 메서드의 첫 매개변수 |

> 💡 `dog1.bark()`는 내부적으로 `Dog.bark(dog1)`과 같다. 그래서 메서드 정의에 `self`를 첫 매개변수로 꼭 적어야 한다. (C++의 `this`에 해당하지만, 파이썬은 명시적으로 쓴다)

### 클래스 변수와 인스턴스 변수

```python
class Dog:
    species = "개"            # 클래스 변수 (공유)
    count = 0

    def __init__(self, name):
        self.name = name      # 인스턴스 변수 (고유)
        Dog.count += 1        # 클래스 변수 수정은 클래스 이름으로

dog1 = Dog("바둑이")
dog2 = Dog("초코")

print(dog1.species, dog2.species)   # 개 개        (공유)
print(dog1.name, dog2.name)         # 바둑이 초코  (고유)
print(Dog.count)                    # 2            (만들어진 개수)
```

> ⚠️ **클래스 변수에 리스트 같은 가변 객체를 두면 모든 인스턴스가 공유한다.** 인스턴스마다 따로 가져야 하는 값은 반드시 `__init__`에서 `self.`로 만들어라.
> ```python
> class Dog:
>     tricks = []                  # ❌ 모든 개가 같은 리스트를 공유
>     def __init__(self, name):
>         self.name = name
>         self.my_tricks = []      # ✅ 인스턴스마다 새 리스트
>
> a, b = Dog("a"), Dog("b")
> a.tricks.append("앉아")
> print(b.tricks)                  # ['앉아']  ← b도 바뀜!
> ```

### 이름을 찾는 순서 (인스턴스 → 클래스)

> 속성을 찾을 때 **인스턴스에서 먼저** 찾고, 없으면 **클래스에서** 찾는다.

```python
class Dog:
    species = "개"

d = Dog()
print(d.species)          # 개      (인스턴스에 없으니 클래스에서 찾음)

d.species = "강아지"       # 인스턴스에 새 변수가 생김 (클래스 변수는 그대로)
print(d.species)          # 강아지  (인스턴스 것이 우선)
print(Dog.species)        # 개
```

> ⚠️ 그래서 `d.species = ...`처럼 **인스턴스를 통해 대입하면 클래스 변수가 바뀌지 않는다.** 클래스 변수를 바꾸려면 `Dog.species = ...`로 써야 한다.

## 메서드

> 클래스 안에 정의된 함수. 첫 인자와 데코레이터에 따라 **세 종류**로 나뉜다.

### 인스턴스 메서드

> 첫 인자로 `self`(인스턴스)를 받는다. 인스턴스의 데이터를 읽고 바꾼다. 가장 일반적인 메서드.

```python
class Circle:
    def __init__(self, radius):
        self.radius = radius

    def area(self):
        return 3.14 * self.radius ** 2

c = Circle(5)
print(c.area())   # 78.5
```

### 클래스 메서드 (@classmethod)

> 첫 인자로 `cls`(클래스 자신)를 받는다. 클래스 변수를 다루거나, **다른 방식으로 인스턴스를 만드는 생성 함수**로 쓴다.

```python
class Dog:
    count = 0

    def __init__(self, name):
        self.name = name
        Dog.count += 1

    @classmethod
    def get_count(cls):
        return cls.count

    @classmethod
    def from_string(cls, text):    # "이름" 문자열로 만드는 또 다른 생성 방법
        return cls(text.strip())

Dog("바둑이")
d = Dog.from_string("  초코  ")
print(d.name, Dog.get_count())     # 초코 2
```

### 스태틱 메서드 (@staticmethod)

> `self`·`cls`를 **둘 다 받지 않는다.** 클래스와 관련은 있지만 인스턴스·클래스 상태가 필요 없는 기능.

```python
class Calculator:
    @staticmethod
    def add(a, b):
        return a + b

print(Calculator.add(3, 5))   # 8   (인스턴스를 만들지 않고 바로 사용)
```

### 메서드 활용

```python
class BankAccount:
    bank_name = "SSAFY은행"         # 클래스 변수

    def __init__(self, owner, balance=0):
        self.owner = owner          # 인스턴스 변수
        self.balance = balance

    def deposit(self, amount):      # 인스턴스 메서드: 객체 상태 변경
        if not BankAccount.is_valid(amount):
            raise ValueError("입금액은 0보다 커야 한다")
        self.balance += amount
        return self.balance

    @classmethod
    def get_bank_name(cls):         # 클래스 메서드: 클래스 정보
        return cls.bank_name

    @staticmethod
    def is_valid(amount):           # 스태틱 메서드: 상태가 필요 없는 검증
        return amount > 0

acc = BankAccount("건석", 1000)
acc.deposit(500)                    # 1500
print(BankAccount.get_bank_name())  # SSAFY은행
print(BankAccount.is_valid(-100))   # False
```

### 메서드 정리

| 종류 | 데코레이터 | 첫 인자 | 접근 대상 | 호출 |
|------|-----------|---------|-----------|------|
| 인스턴스 메서드 | 없음 | `self` | 인스턴스 변수 (+클래스 변수) | `obj.method()` |
| 클래스 메서드 | `@classmethod` | `cls` | 클래스 변수 | `Class.method()` |
| 스태틱 메서드 | `@staticmethod` | 없음 | (상태 접근 X) | `Class.method()` |
