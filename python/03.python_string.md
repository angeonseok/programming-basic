# 🐍 파이썬 기초 — 문자열 (str)

> 문자들이 순서대로 놓인 **변경 불가능한(immutable)** 시퀀스. 인덱싱·슬라이싱, f-string 포맷, 자주 쓰는 문자열 메서드를 다룬다.

---

## 문자열 만들기

```python
s1 = 'hello'
s2 = "world"          # 작은따옴표·큰따옴표 둘 다 같음
s3 = """여러 줄
문자열"""             # 따옴표 3개: 줄바꿈 포함 여러 줄
path = r"C:\new\test" # r"...": raw 문자열 → \ 를 이스케이프로 해석하지 않음
```

### 이스케이프 시퀀스

| 이스케이프 | 의미 |
|------------|------|
| `\n` | 줄 바꿈 |
| `\t` | 탭 |
| `\\` | 백슬래시 |
| `\'` | 작은따옴표 |
| `\"` | 큰따옴표 |

> ⚠️ Windows 경로를 `"C:\new"`처럼 쓰면 `\n`이 줄바꿈으로 바뀐다. 경로는 `r"C:\new"`나 `"C:/new"`로 쓰자.

## 인덱싱 · 슬라이싱

> `s[i]`로 한 글자, `s[start:stop:step]`으로 일부분을 꺼낸다. 인덱스는 0부터, 음수 인덱스는 뒤에서부터 센다.

```text
 문자열    h   e   l   l   o
 인덱스    0   1   2   3   4
 음수     -5  -4  -3  -2  -1
```

```python
s = "hello"

s[0]       # 'h'
s[-1]      # 'o'      (마지막 글자)
s[1:4]     # 'ell'    (1 이상 4 미만)
s[:2]      # 'he'     (처음부터)
s[2:]      # 'llo'    (끝까지)
s[::2]     # 'hlo'    (2칸씩)
s[::-1]    # 'olleh'  (뒤집기)
```

| 형태 | 의미 |
|------|------|
| `s[a:b]` | `a` 이상 `b` 미만 (`b`는 포함 안 됨) |
| `s[a:]` / `s[:b]` | `a`부터 끝까지 / 처음부터 `b` 전까지 |
| `s[::k]` | `k`칸씩 건너뛰며 |
| `s[::-1]` | 거꾸로 |

> 💡 **인덱싱은 범위를 벗어나면 에러, 슬라이싱은 안전하다.** `s[10]`은 `IndexError`지만 `s[10:]`은 그냥 빈 문자열 `''`이다.

> 💡 슬라이싱 규칙은 문자열·리스트·튜플 모두 같다. ([04. 리스트 · 튜플](04.python_list_tuple.md))

## 문자열의 불변성

> 문자열은 한 번 만들면 **글자를 바꿀 수 없다.** 수정이 필요하면 새 문자열을 만든다.

```python
s = "hello"
# s[0] = "H"      ❌ TypeError

s = "H" + s[1:]   # ✅ 새 문자열을 만들어 다시 담기
print(s)          # Hello
```

> ⚠️ 그래서 **문자열 메서드는 원본을 바꾸지 않고 새 문자열을 반환**한다. 결과를 쓰려면 반드시 다시 받아야 한다.
> ```python
> s = "hello"
> s.upper()         # 'HELLO'을 만들기만 하고 버림
> print(s)          # hello   (그대로)
> s = s.upper()     # ✅ 다시 담아야 바뀐다
> ```

## f-string — 값을 문자열에 넣기

```python
name = "건석"
age = 25
print(f"이름: {name}, 나이: {age}")   # 이름: 건석, 나이: 25
print(f"내년 나이: {age + 1}")        # 내년 나이: 26  (식도 가능)
```

`{값:형식}`으로 출력 형식을 정할 수 있다.

| 형식 | 의미 | 예시 | 결과 |
|------|------|------|------|
| `.2f` | 소수점 아래 2자리 | `f"{3.14159:.2f}"` | `'3.14'` |
| `,` | 천 단위 쉼표 | `f"{1234567:,}"` | `'1,234,567'` |
| `03d` | 3자리, 빈자리 0 | `f"{5:03d}"` | `'005'` |
| `>5` / `<5` / `^5` | 5칸 오른쪽 / 왼쪽 / 가운데 정렬 | `f"{'a':>5}"` | `'    a'` |
| `%` | 백분율 | `f"{0.256:.1%}"` | `'25.6%'` |

> 💡 **디버깅용 `=` (3.8+):** `f"{x=}"`는 `'x=42'`처럼 변수 이름과 값을 함께 보여준다.

### 옛 방식의 문자열 포맷

> f-string(3.6+) 이전에 쓰던 방식이다. 오래된 코드나 문서에서 자주 보이므로 읽을 줄은 알아두자.

```python
name, age = "건석", 25
"이름: %s, 나이: %d" % (name, age)        # % 포맷 (C의 printf 방식)
"이름: {}, 나이: {}".format(name, age)    # str.format
"{:.2f}".format(3.14159)                  # '3.14' (형식 지정 규칙은 f-string과 같다)
```

## 탐색 · 검사 메서드

> **메서드(method)** : 특정 타입의 객체에 **속해 있는 함수**. `객체.메서드()` 형태로 부른다. `len(s)`처럼 객체를 인자로 받는 일반 함수와 구분된다.
>
> | 구분 | 형태 | 예시 |
> |------|------|------|
> | 함수 | `함수(객체)` | `len(text)` |
> | 메서드 | `객체.메서드()` | `text.upper()` |

| 메서드 | 설명 | 예시 | 결과 |
|--------|------|------|------|
| `.find(x)` | `x` 위치, 없으면 `-1` | `"apple".find("p")` | `1` |
| `.index(x)` | `x` 위치, 없으면 **에러** | `"apple".index("p")` | `1` |
| `.count(x)` | `x`의 개수 | `"banana".count("a")` | `3` |
| `.startswith(x)` | `x`로 시작하는지 | `"apple".startswith("ap")` | `True` |
| `.endswith(x)` | `x`로 끝나는지 | `"apple".endswith("le")` | `True` |
| `x in s` | 포함 여부 | `"pp" in "apple"` | `True` |

```python
text = "hello world"
text.find("o")         # 4   (처음 나오는 위치)
text.find("z")         # -1
# text.index("z")      # ❌ ValueError (없으면 에러)
```

> ⚠️ `find`와 `index`는 같은 일을 하지만, **못 찾았을 때** `find`는 `-1`, `index`는 에러를 낸다. 단순 포함 여부는 `in`이 가장 읽기 쉽다.

### 문자 유형 판별

| 메서드 | 판별 대상 | 예시 | 결과 |
|--------|-----------|------|------|
| `.isalpha()` | 문자(알파벳·한글 등) | `"abc".isalpha()` | `True` |
| `.isdigit()` | 숫자 | `"123".isdigit()` | `True` |
| `.isalnum()` | 문자+숫자 | `"a1".isalnum()` | `True` |
| `.isspace()` | 공백 | `"  ".isspace()` | `True` |
| `.isupper()` / `.islower()` | 모두 대문자 / 소문자 | `"ABC".isupper()` | `True` |

```python
user_input = "12345"
if user_input.isdigit():
    age = int(user_input)   # 숫자일 때만 안전하게 변환
```

> ⚠️ `"-5".isdigit()`와 `"3.14".isdigit()`는 `False`다. 음수·소수까지 받으려면 `try: int(x)` / `float(x)`로 검사하자. ([13. 예외 처리](13.python_exception.md))

## 변환 · 조작 메서드

| 메서드 | 설명 | 예시 | 결과 |
|--------|------|------|------|
| `.upper()` / `.lower()` | 대문자 / 소문자로 | `"abc".upper()` | `"ABC"` |
| `.title()` | 단어 첫 글자 대문자 | `"hi bob".title()` | `"Hi Bob"` |
| `.capitalize()` | 첫 글자만 대문자 | `"hi bob".capitalize()` | `"Hi bob"` |
| `.replace(a, b)` | `a`를 `b`로 교체 | `"a-b".replace("-", "_")` | `"a_b"` |
| `.strip()` | 양쪽 공백(줄바꿈 포함) 제거 | `"  hi\n".strip()` | `"hi"` |
| `.lstrip()` / `.rstrip()` | 왼쪽 / 오른쪽만 제거 | `"hi\n".rstrip()` | `"hi"` |
| `.split(sep)` | `sep` 기준 분리 → 리스트 | `"a,b".split(",")` | `["a", "b"]` |
| `.join(iter)` | `iter`의 문자열들을 이어붙임 | `",".join(["a", "b"])` | `"a,b"` |

```python
text = "  Hello, World  "
text.strip()                        # "Hello, World"
text.strip().replace(",", "!")      # "Hello! World"

words = "apple banana cherry".split()   # ['apple', 'banana', 'cherry']
"-".join(words)                         # 'apple-banana-cherry'
```

### ⚠️ split · join 함정

```python
" a  b ".split()      # ['a', 'b']               인자 없음: 공백 여러 개를 하나로, 양끝 무시
" a  b ".split(" ")   # ['', 'a', '', 'b', '']   " " 지정: 공백 하나하나를 구분자로

# ",".join([1, 2])                 # ❌ TypeError: join은 문자열만 이어붙인다
",".join(map(str, [1, 2]))         # ✅ '1,2'
```

> 💡 입력을 나눌 땐 대부분 **인자 없는 `split()`**이 맞다.

### 문자열 이어붙이기는 join으로

> 문자열은 불변이라 `s += "x"`는 매번 새 문자열을 만든다. 조각이 많으면 **리스트에 모았다가 `join` 한 번**으로 합치는 것이 안전하고 빠르다.

```python
parts = []
for i in range(5):
    parts.append(str(i))
result = "".join(parts)    # '01234'
```

### 메서드 체이닝

> 문자열 메서드는 새 문자열을 반환하므로, 그 결과에 바로 다음 메서드를 이어 부를 수 있다.

```python
text = "  Hello World  "
result = text.strip().lower().replace(" ", "_")
print(result)   # hello_world

# "  Hello World  " → strip()   → "Hello World"
#                   → lower()   → "hello world"
#                   → replace() → "hello_world"
```

> ⚠️ 체이닝은 **새 값을 반환하는 메서드**끼리만 된다. 리스트의 `.sort()`, `.append()`처럼 원본을 고치고 `None`을 반환하는 메서드 뒤에는 이어 붙일 수 없다.

### 문자 ↔ 숫자 코드 (ord / chr)

```python
ord("a")            # 97   (문자 → 유니코드 번호)
chr(97)             # 'a'  (번호 → 문자)
ord("c") - ord("a") # 2    (알파벳 순서 인덱스)
```

> 💡 알파벳 빈도를 셀 때 `cnt[ord(c) - ord("a")] += 1`처럼 쓸 수 있지만, 파이썬에선 `collections.Counter`가 더 간단하다. ([10. 모듈 · 표준 라이브러리](10.python_modules.md))
