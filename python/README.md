# Python Basic

이 디렉토리는 **Python 3.10 이상 기준**으로 정리한 Python 학습 노트입니다.

입문서처럼 **기초 문법 → 자료구조 → 흐름 제어와 함수 → 모듈과 객체 지향 → 예외와 파일** 순서로 구성했습니다. 문법 설명과 예제 코드로 개념을 익히고, 각 문서의 ⚠️(함정)·💡(팁) 상자로 실수하기 쉬운 부분을 짚습니다. 코딩테스트(알고리즘 문제 풀이)에 필요한 내용은 본문과 분리해 **부록**에 모았습니다.

특정 버전부터 쓸 수 있는 문법에는 **(3.8+)**, **(3.10+)**처럼 표시를 붙였습니다.

> ⚠️ 사용하는 Python 버전이 낮으면 버전 표시가 붙은 문법(`match`, `:=`, `int | None` 등)은 동작하지 않습니다. `python --version`으로 확인하세요.
