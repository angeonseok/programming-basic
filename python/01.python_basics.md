# 🐍 파이썬 기초 — 기본 규칙 · 입출력 · 숫자 · 형변환

> 파이썬 코드를 읽고 쓰기 위한 **가장 기본적인 규칙**과, 값을 넣고 빼는 **입출력**, 그리고 모든 계산의 바탕인 **숫자형**을 다룬다.

---

## 기본 규칙

### 들여쓰기가 곧 문법

> 파이썬은 중괄호 `{}` 대신 **들여쓰기**로 코드 블록을 구분한다. 콜론(`:`) 다음 줄부터 같은 깊이로 들여쓴 줄들이 하나의 블록이다.

```python
if 3 > 1:
    print("블록 안")      # 4칸 들여쓰기 → if 블록
    print("여기도 블록 안")
print("블록 밖")          # 들여쓰기 없음 → if와 무관하게 실행
```

> ⚠️ 들여쓰기 깊이가 맞지 않으면 `IndentationError`가 난다. **공백 4칸**이 표준이며, 탭과 공백을 섞어 쓰면 안 된다.

### 주석

```python
# 한 줄 주석: # 뒤는 실행되지 않는다

"""
여러 줄 문자열을 주석처럼 쓰기도 한다.
(함수·클래스 맨 위에 쓰면 설명 문서인 '독스트링'이 된다)
"""
```

### 변수와 동적 타이핑

> 변수는 `이름 = 값`으로 만든다. 타입을 선언하지 않으며, 값이 들어갈 때 타입이 정해진다(**동적 타이핑**). 같은 변수에 다른 타입의 값을 다시 넣을 수도 있다.

```python
x = 10          # int
x = "hello"     # 이제 str (에러 아님)
print(type(x))  # <class 'str'>

a, b = 1, 2     # 여러 변수 한 번에
a, b = b, a     # 값 교환 → a=2, b=1
```

> 💡 변수 이름은 문자·숫자·`_`로 만들고 숫자로 시작할 수 없다. `list`, `str`, `sum`, `max`처럼 **내장 함수 이름을 변수 이름으로 쓰지 마라.** `list = [1, 2]`라고 하면 그 뒤로 `list()` 함수를 쓸 수 없게 된다.

### 데이터 타입 개요

> **데이터 타입** : 값의 종류와 그 값으로 할 수 있는 동작(연산)을 결정하는 속성

| 분류 | 타입 | 문서 |
|------|------|------|
| 숫자형 | `int`, `float`, `complex` | 이 문서 |
| 텍스트 시퀀스 | `str` | [03. 문자열](03.python_string.md) |
| 시퀀스 | `list`, `tuple`, `range` | [04. 리스트 · 튜플](04.python_list_tuple.md) |
| 비시퀀스 | `dict`, `set` | [05. 딕셔너리 · 세트](05.python_dict_set.md) |
| 기타 | `bool`, `None` | [02. 연산자](02.python_operators.md) |

## 출력 (print)

```python
print("hello")              # hello
print(1, 2, 3)              # 1 2 3   (여러 값은 공백으로 구분)
print(1, 2, 3, sep="-")     # 1-2-3   (sep: 구분자 지정)
print("a", end="")          # 줄바꿈 없이 출력 (end: 끝 문자, 기본 "\n")
print("b")                  # ab

nums = [1, 2, 3]
print(*nums)                # 1 2 3   (리스트를 풀어서 출력)
print("\n".join(map(str, nums)))   # 한 줄에 하나씩 출력
```

> 💡 값을 문자열 안에 넣어 출력할 땐 **f-string**(`f"{name}님"`)을 쓴다. ([03. 문자열](03.python_string.md) 참고)

## 입력 (input)

> `input()`은 한 줄을 읽어 **항상 문자열(`str`)로** 돌려준다. 숫자가 필요하면 직접 변환해야 한다.

```python
name = input()                      # "건석" 입력 → "건석"
age = int(input())                  # "25" 입력 → 25 (int로 변환)

a, b = map(int, input().split())    # "3 5" 입력 → a=3, b=5
nums = list(map(int, input().split()))   # "1 2 3" 입력 → [1, 2, 3]
```

> ⚠️ `input()`의 결과로 바로 계산하면 문자열 연산이 된다. `input() + input()`에 `1`, `2`를 넣으면 `3`이 아니라 `"12"`다.

| 입력 형태 | 코드 |
|-----------|------|
| 정수 하나 | `n = int(input())` |
| 공백으로 구분된 정수 여러 개 | `a, b = map(int, input().split())` |
| 정수 리스트 | `nums = list(map(int, input().split()))` |
| 여러 줄 (n줄) | `rows = [input() for _ in range(n)]` |

### 빠른 입력 (코딩테스트)

> `input()`은 느려서 입력이 수십만 줄이면 시간 초과가 날 수 있다. `sys.stdin.readline`으로 바꾸면 훨씬 빠르다.

```python
import sys
input = sys.stdin.readline      # 이후 input()이 빠른 버전으로 동작

n = int(input())
nums = list(map(int, input().split()))
line = input().rstrip()         # ⚠️ 문자열은 끝의 줄바꿈 제거 필수
```

> ⚠️ `sys.stdin.readline`은 줄 끝의 **`\n`까지 포함**해서 돌려준다. `int()`와 `split()`은 알아서 무시하지만, 문자열 그대로 쓸 땐 `.rstrip()`으로 지워야 한다. 안 그러면 `"hello\n"`처럼 줄바꿈이 붙은 값이 된다.

## 숫자형 (Numeric Type)

| 타입 | 설명 | 예시 |
|------|------|------|
| `int` | 정수 | `42`, `-7`, `1_000_000` |
| `float` | 실수 | `3.14`, `-0.5`, `1.5e3`(= `1500.0`) |
| `complex` | 복소수 | `3 + 4j` |

> 💡 숫자 사이의 `_`는 자릿수 구분용이라 무시된다(`1_000_000 == 1000000`).

### int는 크기 제한이 없다

> 파이썬 `int`는 메모리가 허락하는 한 **얼마든지 커진다.** C++의 `int`처럼 21억에서 넘치는(오버플로) 일이 없다.

```python
print(2 ** 100)   # 1267650600228229401496703205376
```

### float는 오차가 있다

> 실수는 2진수로 근사해서 저장하므로 **아주 작은 오차**가 생긴다. 그래서 실수끼리 `==`로 비교하면 틀릴 수 있다.

```python
print(0.1 + 0.2)              # 0.30000000000000004
print(0.1 + 0.2 == 0.3)       # False

import math
print(math.isclose(0.1 + 0.2, 0.3))   # True  (오차를 허용한 비교)
```

> 💡 돈 계산처럼 오차가 허용되지 않으면 정수(원 단위)로 계산하거나 `decimal.Decimal`을 쓴다.

## 형변환 (Type Conversion)

### 암시적 형변환 (파이썬이 자동으로)

```python
print(3 + 1.5)   # 4.5  (int → float 자동 변환)
print(True + 1)  # 2    (bool → int: True는 1, False는 0)
print(10 / 2)    # 5.0  (/ 의 결과는 항상 float)
```

### 명시적 형변환 (개발자가 직접 지정)

| 함수 | 변환 대상 | 예시 | 결과 |
|------|----------|------|------|
| `int()` | str, float, bool → int | `int("3")` | `3` |
| `float()` | str, int, bool → float | `float("3.14")` | `3.14` |
| `str()` | 모든 타입 → str | `str(42)` | `"42"` |
| `bool()` | 모든 타입 → bool | `bool(0)` | `False` |
| `list()` | 반복 가능한 것 → list | `list("abc")` | `['a', 'b', 'c']` |
| `tuple()` | 반복 가능한 것 → tuple | `tuple([1, 2])` | `(1, 2)` |
| `set()` | 반복 가능한 것 → set | `set([1, 1, 2])` | `{1, 2}` |

```python
int(3.9)          # 3     (반올림이 아니라 소수부 버림)
int(-3.7)         # -3    (0 쪽으로 버림)
int("ff", 16)     # 255   (16진수 문자열 → 정수)
int("101", 2)     # 5     (2진수 문자열 → 정수)
```

> ⚠️ `int("3.5")`는 **ValueError**다. 소수점이 있는 문자열은 `int(float("3.5"))`처럼 두 단계로 바꾼다.

> ⚠️ `bool("False")`는 `True`다. 비어 있지 않은 문자열은 내용과 상관없이 참이기 때문이다. ([02. 연산자](02.python_operators.md)의 Truthy · Falsy 참고)

## 참고

### 코드 스타일 (PEP 8)

> 파이썬 공식 스타일 가이드. 협업·가독성을 위한 코드 작성 관례다.

| 대상 | 규칙 | 예시 |
|------|------|------|
| 변수·함수 | snake_case | `user_name`, `get_data()` |
| 클래스 | PascalCase | `class UserAccount:` |
| 상수 | UPPER_CASE | `MAX_SIZE = 100` |
| 들여쓰기 | 공백 4칸 | (탭 대신 스페이스) |
| 연산자 주위 | 양옆 공백 1칸 | `x = a + b` |
| 쉼표 뒤 | 공백 1칸 | `func(a, b)` |

```python
# ❌ PEP 8 위반
def getUser( ):
    userName="kim"
    return userName

# ✅ PEP 8 준수
def get_user():
    user_name = "kim"
    return user_name
```

> 💡 `black`, `ruff` 같은 도구로 PEP 8 준수를 자동 검사·정리할 수 있다.
