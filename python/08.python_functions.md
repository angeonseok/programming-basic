# 🐍 파이썬 함수 — 정의 · 인자 · 패킹 · 타입 힌트

> **함수** : 특정 작업을 하는 코드 묶음에 이름을 붙여, 필요할 때마다 재사용할 수 있게 만든 것. **중복 제거**, **가독성 향상**, **유지보수 용이**라는 이점을 얻는다.

---

## 함수 기초

### 함수 구조

```python
def 함수이름(매개변수):
    """독스트링 (함수 설명, 선택)"""
    실행할_코드
    return 반환값
```

```python
def greet(name):
    return f"안녕, {name}!"

message = greet("건석")   # 함수 호출(call)
print(message)            # 안녕, 건석!
```

| 구성 요소 | 설명 |
|-----------|------|
| `def` | 함수 정의 키워드 |
| 함수이름 | 호출할 때 쓰는 이름 (snake_case) |
| 매개변수 | 함수가 받을 입력값 (선택) |
| 독스트링 | `"""..."""` 함수 설명 (선택, `help(함수)`로 볼 수 있음) |
| `return` | 결과값 반환 (선택) |

### 반환값

> 함수는 `return`을 만나면 **값을 돌려주고 즉시 종료**된다.

```python
def add(a, b):
    return a + b
    print("실행 안됨")   # return 이후라서 도달하지 않음

result = add(3, 5)        # 8
print(add(add(1, 2), 3))  # 6  (반환값을 바로 다른 함수의 인자로)
```

`return`이 없거나 값 없이 `return`만 쓰면 **`None`을 반환**한다.

```python
def say_hi():
    print("hi")

x = say_hi()   # hi 출력
print(x)       # None
```

> ⚠️ `print`는 화면에 보여줄 뿐이고, `return`은 값을 **돌려준다.** 함수 결과로 계산을 이어가려면 `print`가 아니라 `return`해야 한다.

여러 값을 반환하면 **튜플로 묶여서** 반환된다.

```python
def min_max(nums):
    return min(nums), max(nums)

result = min_max([3, 1, 4])       # (1, 4)
lo, hi = min_max([3, 1, 4])       # 언패킹으로 나눠 받기
```

## 매개변수와 인자

> **매개변수(parameter)** : 함수를 **정의**할 때 받는 변수
> **인자(argument)** : 함수를 **호출**할 때 전달하는 값

```python
def greet(name):     # name → 매개변수
    print(f"Hi, {name}")

greet("건석")        # "건석" → 인자
```

### 위치 인자 · 키워드 인자

```python
def introduce(name, age):
    print(f"{name}, {age}세")

introduce("건석", 25)            # 위치 인자: 정의된 순서대로
introduce(age=25, name="건석")   # 키워드 인자: 이름을 지정하면 순서 무관
introduce("건석", age=25)        # 섞어 쓰기: 위치 인자가 앞
# introduce(name="건석", 25)     # ❌ SyntaxError: 키워드 인자 뒤에 위치 인자 불가
```

### 기본 인자 값

> 인자를 생략하면 **기본값**이 사용된다.

```python
def greet(name, greeting="안녕"):
    print(f"{greeting}, {name}")

greet("건석")              # 안녕, 건석
greet("건석", "반가워")     # 반가워, 건석
```

> ⚠️ 기본값이 있는 매개변수는 **없는 매개변수보다 뒤**에 와야 한다. `def f(a=1, b):`는 SyntaxError.

### ⚠️ 가변 기본값 함정

> 기본값은 함수를 **정의할 때 딱 한 번** 만들어진다. 기본값이 리스트·딕셔너리면 **모든 호출이 같은 객체를 공유**한다.

```python
def add_item(item, lst=[]):
    lst.append(item)
    return lst

add_item(1)      # [1]
add_item(2)      # [1, 2]  ← 새 리스트가 아니라 이전 것에 이어 붙음!

def add_item(item, lst=None):    # ✅ None을 기본값으로 두고
    if lst is None:
        lst = []                 #    호출할 때마다 새로 만든다
    lst.append(item)
    return lst
```

> 💡 기본값에는 `None`, 숫자, 문자열, 튜플처럼 **불변 값만** 쓰자. (원리는 [06. 참조 · 복사](06.python_reference_copy.md))

### 가변 인자 `*args` · `**kwargs`

```python
def total(*args):            # 위치 인자 여러 개 → 튜플
    print(args)              # (1, 2, 3)
    return sum(args)

total(1, 2, 3)               # 6

def info(**kwargs):          # 키워드 인자 여러 개 → 딕셔너리
    print(kwargs)            # {'name': '건석', 'age': 25}

info(name="건석", age=25)
```

### 키워드 전용 · 위치 전용 인자

```python
def connect(host, *, port=80, timeout=5):   # * 뒤는 반드시 키워드로
    ...

connect("a.com", port=8080)    # ✅
# connect("a.com", 8080)       # ❌ TypeError

def power(base, exp, /):       # / 앞은 반드시 위치로 (3.8+)
    return base ** exp

power(2, 3)                    # ✅ 8
# power(base=2, exp=3)         # ❌ TypeError
```

> 💡 `*` 뒤에 두면 호출하는 쪽이 `connect("a.com", True, False)`처럼 의미를 알 수 없는 값을 늘어놓는 것을 막을 수 있다.

### 매개변수 작성 순서

```python
def func(pos_only, /, normal, default=0, *args, kw_only, **kwargs):
    ...
```

| 순서 | 종류 |
|------|------|
| 1 | 위치 전용 (`/` 앞) |
| 2 | 일반 매개변수 → 기본값 있는 매개변수 |
| 3 | `*args` (또는 단독 `*`) |
| 4 | 키워드 전용 (`*` 뒤) |
| 5 | `**kwargs` |

## Packing & Unpacking

### Packing (패킹)

> 여러 값을 **하나로 묶는** 것. `*`를 쓰면 나머지를 리스트로 묶는다.

```python
numbers = 1, 2, 3          # 튜플로 묶임 → (1, 2, 3)

a, *b = [1, 2, 3, 4]       # a = 1, b = [2, 3, 4]
first, *middle, last = [1, 2, 3, 4, 5]
print(middle)              # [2, 3, 4]
```

함수의 `*args`, `**kwargs`도 패킹이다.

### Unpacking (언패킹)

> 묶여 있는 값을 **풀어서** 개별 값으로 나누는 것.

```python
x, y, z = (1, 2, 3)        # 시퀀스 언패킹

nums = [1, 2, 3]
print(*nums)               # 1 2 3   (print(1, 2, 3)과 같음)

def introduce(name, age):
    print(f"{name}, {age}세")

person = {"name": "건석", "age": 25}
introduce(**person)        # 건석, 25세  (딕셔너리 → 키워드 인자)

merged = [*nums, 4]        # [1, 2, 3, 4]
combined = {**person, "job": "dev"}   # 딕셔너리 합치기
```

| 기호 | 대상 | 동작 |
|------|------|------|
| `*` | 시퀀스(list, tuple 등) | 원소를 풀어서 전달 |
| `**` | 딕셔너리 | key-value를 키워드 인자로 전달 |

## 타입 힌트 (Type Hint)

> 매개변수와 반환값의 **예상 타입을 표시**한다. 읽는 사람과 편집기(자동완성, 오류 표시)를 위한 것이며, 실행에는 영향이 없다.

```python
def area(radius: float) -> float:
    return 3.14 * radius ** 2

def find(names: list[str], target: str) -> int | None:   # 3.10+ 표기
    for i, name in enumerate(names):
        if name == target:
            return i
    return None

count: int = 0                        # 변수에도 붙일 수 있다
```

> ⚠️ 타입 힌트는 **검사하지 않는다.** `area("ab")`라고 불러도 힌트 때문에 막히지는 않는다. 검사하려면 `mypy` 같은 도구를 쓴다.

> 💡 `list[str]`, `dict[str, int]` 표기는 3.9+, `int | None` 표기는 3.10+다. 그 전 버전은 `from typing import List, Optional`을 쓴다.

## 함수 스타일 가이드

### 함수 이름 짓기

| 규칙 | 설명 | 예시 |
|------|------|------|
| snake_case | 소문자 + 언더스코어 | `get_user_name` |
| 동사로 시작 | 동작을 나타냄 | `calculate_total`, `is_valid` |
| 명확한 이름 | 역할이 드러나게 | `send_email` (O), `do_it` (X) |
| 축약 지양 | 알아보기 쉽게 | `count` (O), `cnt` (X) |

### 단일 책임 원칙 (Single Responsibility Principle)

> 하나의 함수는 **하나의 일만** 해야 한다. 그래야 테스트·재사용·수정이 쉽다.

```python
# ❌ 한 함수가 여러 일을 함
def process(data):
    cleaned = [x.strip() for x in data]   # 정제
    total = sum(len(x) for x in cleaned)  # 계산
    print(total)                          # 출력
    return cleaned

# ✅ 책임별로 분리
def clean(data):
    return [x.strip() for x in data]

def count_total(data):
    return sum(len(x) for x in data)
```
