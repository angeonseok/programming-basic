# 🐍 파이썬 자료구조 — 딕셔너리 · 세트

> key로 값을 찾는 `dict`와, 중복 없는 집합 `set`. 둘 다 **해시 테이블**로 만들어져 조회가 평균 O(1)로 빠르다.

---

## 딕셔너리 (dict)

> **key-value 쌍**을 저장하는 **변경 가능한** 자료형. key는 중복될 수 없다.

```python
person = {"name": "건석", "age": 25, "lang": "Python"}

person["name"]               # '건석'   (접근)
person["email"] = "a@b.com"  # 추가
person["age"] = 26           # 변경
del person["lang"]           # 삭제
"name" in person             # True    (in은 key를 검사)
len(person)                  # 3
```

| | key | value |
|-|-----|-------|
| 중복 | ❌ 불가 (같은 key에 넣으면 덮어씀) | ✅ 가능 |
| 타입 | **변경 불가능한 타입만** (`str`, `int`, `tuple` 등) | 모든 타입 |

> 💡 **dict는 넣은 순서를 기억한다(3.7+).** 순회하면 key가 추가한 순서대로 나온다. 다만 `d[0]`처럼 "몇 번째" 위치로 꺼낼 수는 없다.

### 주요 메서드

| 메서드 | 설명 | 예시 |
|--------|------|------|
| `.get(k)` | `k`의 값, 없으면 `None` | `d.get("x")` |
| `.get(k, 기본값)` | 없으면 기본값 | `d.get("x", 0)` |
| `.keys()` / `.values()` / `.items()` | key / value / (key, value) 쌍 | `d.items()` |
| `.setdefault(k, v)` | `k`가 없으면 `v`로 추가하고, 값을 반환 | `d.setdefault("x", [])` |
| `.update(other)` | 다른 dict로 갱신·추가 | `d.update({"y": 2})` |
| `.pop(k)` | `k` 삭제 후 값 반환 | `d.pop("x")` |

```python
person = {"name": "건석", "age": 25}

person.get("phone")           # None   (없어도 에러 안 남)
person.get("phone", "없음")   # '없음'

for key, value in person.items():   # 순회에 가장 많이 쓰는 형태
    print(key, value)               # name 건석 → age 25

person.update({"age": 26, "job": "dev"})   # 갱신 + 추가
merged = {"a": 1} | {"b": 2}               # {'a': 1, 'b': 2}  (3.9+ 합치기)
```

> ⚠️ `person["phone"]`은 없는 key면 **KeyError**, `person.get("phone")`은 **None**이다. key가 없을 수 있으면 `.get()`이나 `in`으로 확인하라.

### 빈도수 세기

```python
counter = {}
for ch in "banana":
    counter[ch] = counter.get(ch, 0) + 1   # 없으면 0에서 시작
print(counter)   # {'b': 1, 'a': 3, 'n': 2}
```

> 💡 빈도수는 `collections.Counter("banana")` 한 줄로도 된다. ([10. 모듈 · 표준 라이브러리](10.python_modules.md))

### value 기준 정렬

```python
scores = {"a": 3, "b": 1, "c": 2}
sorted(scores.items(), key=lambda kv: kv[1])                # [('b', 1), ('c', 2), ('a', 3)]
sorted(scores.items(), key=lambda kv: kv[1], reverse=True)  # 큰 값부터
max(scores, key=scores.get)                                 # 'a'  (값이 가장 큰 key)
```

### ⚠️ 순회하면서 크기를 바꾸지 마라

```python
d = {"a": 1, "b": 2}
# for k in d:
#     del d[k]          # ❌ RuntimeError: dictionary changed size during iteration

for k in list(d):       # ✅ key 목록을 복사해 두고 순회
    del d[k]
```

## 세트 (set)

> **순서와 중복이 없는 변경 가능한** 자료형 — 수학의 집합과 같다. 중복 제거와 빠른 존재 확인에 쓴다.

```python
s = {1, 2, 3, 2, 1}
print(s)            # {1, 2, 3}  (중복 자동 제거)

empty = set()       # ⚠️ 빈 세트는 set(). {}는 빈 딕셔너리다

unique = list(set([3, 1, 3, 2]))   # 중복 제거 (순서는 보장 안 됨)
```

### 주요 메서드

| 메서드 | 설명 | 예시 |
|--------|------|------|
| `.add(x)` | 원소 하나 추가 | `s.add(4)` |
| `.update(iter)` | 여러 원소 추가 | `s.update([4, 5])` |
| `.remove(x)` | 삭제 (없으면 **KeyError**) | `s.remove(2)` |
| `.discard(x)` | 삭제 (없어도 통과) | `s.discard(2)` |
| `.pop()` | 임의의 원소 하나 삭제·반환 | `s.pop()` |

```python
s = {1, 2, 3}
s.add(4)            # {1, 2, 3, 4}
s.update([5, 6])    # {1, 2, 3, 4, 5, 6}
# s.remove(10)      # ❌ KeyError (없는 값)
s.discard(10)       # ✅ 에러 없이 통과
```

### 집합 연산

| 연산자 | 메서드 | 의미 | `{1,2,3}` 와 `{2,3,4}` |
|--------|--------|------|-------------------------|
| `a \| b` | `a.union(b)` | 합집합 | `{1, 2, 3, 4}` |
| `a & b` | `a.intersection(b)` | 교집합 | `{2, 3}` |
| `a - b` | `a.difference(b)` | 차집합 | `{1}` |
| `a ^ b` | `a.symmetric_difference(b)` | 대칭 차집합 (한쪽에만 있는 것) | `{1, 4}` |
| `a <= b` | `a.issubset(b)` | 부분집합인가 | `False` |

## 딕셔너리 · 세트 컴프리헨션

```python
{x: x ** 2 for x in range(3)}             # {0: 0, 1: 1, 2: 4}
{v: k for k, v in {"a": 1, "b": 2}.items()}   # {1: 'a', 2: 'b'}  (key·value 뒤집기)
{x % 3 for x in range(6)}                 # {0, 1, 2}
```

## 해시 테이블 — 왜 빠르고, 왜 key에 제한이 있나

> `dict`와 `set`은 key를 **해시 함수**로 숫자로 바꿔 저장 위치를 정한다. 그래서 전체를 뒤지지 않고 바로 찾아가므로 검색·삽입·삭제가 평균 **O(1)**이다.

| 연산 | `list` | `dict` / `set` |
|------|--------|----------------|
| `x in ...` | O(n) | 평균 O(1) |
| 추가 | O(1) (끝에) | 평균 O(1) |
| 삭제 | O(n) | 평균 O(1) |

> 해시값은 key가 바뀌지 않아야 의미가 있다. 그래서 `dict`의 key와 `set`의 원소에는 **변경 불가능한 값만** 쓸 수 있다. `list`, `dict`, `set`은 쓸 수 없다.
> ```python
> # {[1, 2]: "x"}    ❌ TypeError: unhashable type: 'list'
> {(1, 2): "x"}      # ✅ tuple은 불변이라 가능 (좌표를 key로 쓸 때)
> ```

## 참고

### defaultdict — 기본값이 있는 딕셔너리

> 없는 key에 접근하면 에러 대신 **기본값을 자동으로 만들어 넣는** 딕셔너리.

```python
from collections import defaultdict

counter = defaultdict(int)        # 기본값 0
for ch in "banana":
    counter[ch] += 1              # 없는 key도 0에서 시작
print(dict(counter))              # {'b': 1, 'a': 3, 'n': 2}

groups = defaultdict(list)        # 기본값 빈 리스트
groups["fruit"].append("apple")   # 알아서 []를 만들고 추가
print(dict(groups))               # {'fruit': ['apple']}

graph = defaultdict(list)         # 인접 리스트 (그래프 문제)
graph[1].append(2)
```

| 선언 | 기본값 |
|------|--------|
| `defaultdict(int)` | `0` |
| `defaultdict(list)` | `[]` |
| `defaultdict(set)` | `set()` |

### 컬렉션 타입 비교

| 타입 | 순서 | 중복 | 변경 가능 | 표기 |
|------|------|------|-----------|------|
| `str` | ✅ | ✅ | ❌ | `"abc"` |
| `list` | ✅ | ✅ | ✅ | `[1, 2]` |
| `tuple` | ✅ | ✅ | ❌ | `(1, 2)` |
| `range` | ✅ | ❌ | ❌ | `range(5)` |
| `set` | ❌ | ❌ | ✅ | `{1, 2}` |
| `dict` | ✅ 넣은 순서 (3.7+) | ❌ (key) | ✅ | `{"k": "v"}` |
