# 🐍 파이썬 자료구조 — 리스트 · 튜플 · range

> 여러 값을 **순서대로** 담는 시퀀스 자료형. 가장 많이 쓰는 `list`의 메서드·정렬·시간 복잡도와, 변경 불가능한 `tuple`, 정수 시퀀스 `range`를 다룬다.

---

## 시퀀스 공통 특징

> **시퀀스** : 여러 값을 **순서대로** 나열해 저장하는 자료형 (`str`, `list`, `tuple`, `range`)

| 특징 | 설명 |
|------|------|
| 순서 | 넣은 순서대로 저장 (정렬된다는 뜻은 아님) |
| 인덱싱 · 슬라이싱 | `x[i]`, `x[a:b:k]` ([03. 문자열](03.python_string.md)과 같은 규칙) |
| 길이 | `len(x)` |
| 포함 여부 | `v in x` |
| 반복 | `for v in x:` |

| 공통 메서드 | 설명 | 예시 | 결과 |
|-------------|------|------|------|
| `.index(v)` | `v`의 첫 위치 (없으면 에러) | `[1, 2, 3].index(2)` | `1` |
| `.count(v)` | `v`의 개수 | `[1, 1, 2].count(1)` | `2` |

## 리스트 (list)

> 여러 값을 순서대로 저장하는 **변경 가능한(mutable)** 시퀀스. 어떤 타입이든 섞어 담을 수 있다.

```python
fruits = ["apple", "banana", "cherry"]
mixed = [1, "hello", 3.14, True]

fruits[0]       # 'apple'
fruits[-1]      # 'cherry'
fruits[0:2]     # ['apple', 'banana']

fruits[0] = "mango"               # 인덱싱으로 수정
fruits[0:2] = ["kiwi", "pear"]    # 슬라이싱으로 여러 값 한 번에 교체

matrix = [[1, 2, 3], [4, 5, 6]]   # 중첩 리스트 (2차원)
matrix[1][2]                      # 6
```

> ⚠️ 2차원 리스트는 `[[0] * m for _ in range(n)]`으로 만든다. `[[0] * m] * n`은 모든 행이 같은 리스트를 공유하는 버그가 생긴다. ([06. 참조 · 복사](06.python_reference_copy.md))

### 추가 · 삭제

> 리스트 메서드는 **원본을 직접 수정**하고, 대부분 `None`을 반환한다.

| 메서드 | 설명 | 예시 |
|--------|------|------|
| `.append(x)` | 끝에 `x` 하나 추가 | `lst.append(4)` |
| `.extend(iter)` | 끝에 여러 개 추가 | `lst.extend([4, 5])` |
| `.insert(i, x)` | `i` 위치에 `x` 삽입 | `lst.insert(0, 9)` |
| `.remove(x)` | 값 `x`의 첫 항목 삭제 (없으면 에러) | `lst.remove(2)` |
| `.pop(i)` | `i`번 항목 삭제 후 **반환** (생략 시 마지막) | `lst.pop()` |
| `del lst[i]` | `i`번 항목 삭제 (문법) | `del lst[0]` |
| `.clear()` | 전체 삭제 | `lst.clear()` |

```python
lst = [1, 2, 3]
lst.append(4)        # [1, 2, 3, 4]
lst.extend([5, 6])   # [1, 2, 3, 4, 5, 6]
lst.insert(0, 0)     # [0, 1, 2, 3, 4, 5, 6]

lst.remove(3)        # 값 3 삭제     → [0, 1, 2, 4, 5, 6]
x = lst.pop()        # 마지막 꺼냄    → x = 6
y = lst.pop(0)       # 인덱스 0 꺼냄  → y = 0
del lst[0]           # [2, 4, 5]
```

> ⚠️ `.append([4, 5])`는 리스트를 **통째로 한 원소**로 넣고, `.extend([4, 5])`는 **풀어서** 넣는다.
> ```python
> a = [1, 2]; a.append([3, 4])   # [1, 2, [3, 4]]
> b = [1, 2]; b.extend([3, 4])   # [1, 2, 3, 4]
> ```

### 정렬

| 메서드/함수 | 설명 | 원본 |
|-------------|------|------|
| `lst.sort()` | 리스트 자체를 정렬 | ✅ 바뀜, `None` 반환 |
| `sorted(x)` | 정렬된 **새 리스트** 반환 (어떤 반복 가능 객체든) | ❌ 그대로 |
| `lst.reverse()` / `reversed(x)` | 순서 뒤집기 | 바뀜 / 그대로 |

```python
nums = [3, 1, 2]
nums.sort()                  # [1, 2, 3]
nums.sort(reverse=True)      # [3, 2, 1]  (내림차순)

original = [3, 1, 2]
result = sorted(original)    # result = [1, 2, 3], original = [3, 1, 2]

words = ["banana", "kiwi", "apple"]
words.sort(key=len)          # 길이순 → ['kiwi', 'apple', 'banana']
```

> ⚠️ `.sort()`는 리스트를 고치고 **`None`을 반환**한다. `nums = nums.sort()`라고 쓰면 `nums`가 `None`이 된다.

**여러 기준으로 정렬** — `key`가 **튜플**을 돌려주면 첫째 값으로 정렬하고, 같으면 둘째 값으로 정렬한다. 숫자 기준을 내림차순으로 바꿀 땐 `-`를 붙인다.

```python
people = [("kim", 30), ("lee", 25), ("park", 30)]

# 나이 내림차순, 나이가 같으면 이름 오름차순
sorted(people, key=lambda p: (-p[1], p[0]))
# [('kim', 30), ('park', 30), ('lee', 25)]
```

> 💡 파이썬 정렬은 **안정 정렬**이다. 기준이 같은 원소끼리는 원래 순서가 유지된다.

### ⚠️ 순회하면서 지우지 마라

> `for`로 도는 리스트에서 원소를 지우면 인덱스가 당겨져 **원소를 건너뛴다.**

```python
nums = [1, 2, 2, 3]
for x in nums:
    if x == 2:
        nums.remove(x)
print(nums)                       # [1, 2, 3]  ← 2가 하나 남음!

nums = [1, 2, 2, 3]
nums = [x for x in nums if x != 2]   # ✅ 남길 것만 모아 새 리스트 → [1, 3]
```

### 시간 복잡도 (코딩테스트)

| 연산 | 복잡도 | 비고 |
|------|--------|------|
| `lst[i]`, `lst[i] = x` | O(1) | |
| `lst.append(x)`, `lst.pop()` | O(1) | 끝에서의 추가·삭제 |
| `lst.insert(0, x)`, `lst.pop(0)` | **O(n)** | 앞에서의 추가·삭제 → 뒤 원소를 전부 민다 |
| `x in lst`, `lst.index(x)`, `lst.remove(x)` | **O(n)** | 처음부터 하나씩 확인 |
| `lst.sort()`, `sorted(lst)` | O(n log n) | |

> 💡 앞에서 넣고 빼는 일이 많으면(큐, BFS) `collections.deque`를, 존재 확인이 많으면 `set`을 쓴다. ([10. 모듈 · 표준 라이브러리](10.python_modules.md), [05. 딕셔너리 · 세트](05.python_dict_set.md))

## 리스트 컴프리헨션

> 반복문으로 리스트를 만드는 코드를 **한 줄로** 쓰는 문법. `[표현식 for 변수 in 반복가능객체 if 조건]`

```python
squares = [x ** 2 for x in range(5)]            # [0, 1, 4, 9, 16]
evens = [x for x in range(10) if x % 2 == 0]    # [0, 2, 4, 6, 8]
labels = ["짝" if x % 2 == 0 else "홀" for x in range(4)]   # ['짝', '홀', '짝', '홀']
grid = [[0] * 3 for _ in range(2)]              # [[0, 0, 0], [0, 0, 0]] (2차원)

# 일반 for문으로 쓰면
result = []
for x in range(5):
    result.append(x ** 2)
```

> ⚠️ 조건 위치에 주의하자. **거르기**는 뒤에(`for ... if 조건`), **값 바꾸기**는 앞에(`A if 조건 else B for ...`) 쓴다. 너무 복잡하면 일반 `for`문이 더 읽기 쉽다.

## 튜플 (tuple)

> 여러 값을 순서대로 저장하는 **변경 불가능한** 시퀀스. 한 번 만들면 원소를 바꿀 수 없다.

```python
t1 = (1, 2, 3)
t2 = 1, 2, 3        # 괄호 생략 가능
t3 = (42,)          # 원소 하나: 쉼표 필수!
t4 = (42)           # ❌ 이건 그냥 int 42
# t1[0] = 10        # ❌ TypeError
```

**튜플은 어디에 쓰이는가?**

```python
x, y = 10, 20                   # 여러 변수에 한 번에 할당
x, y = y, x                     # 값 교환

def min_max(nums):
    return min(nums), max(nums) # 여러 값 반환 → 튜플로 묶여 반환

lo, hi = min_max([3, 1, 4, 1, 5])

visited = {(0, 0), (1, 2)}      # 좌표를 세트·딕셔너리 키로 (리스트는 불가)
```

> 💡 바뀌면 안 되는 묶음(좌표, 설정값)은 튜플로 두자. 불변이라 **딕셔너리 키·세트 원소로 쓸 수 있다**는 게 리스트와의 큰 차이다.

## range

> 연속된 정수 시퀀스를 만드는 **변경 불가능한** 자료형. 실제 숫자를 다 만들어두지 않아 메모리를 거의 쓰지 않는다.

```python
range(5)          # 0, 1, 2, 3, 4        (stop만)
range(1, 5)       # 1, 2, 3, 4           (start, stop)
range(0, 10, 2)   # 0, 2, 4, 6, 8        (start, stop, step)
range(5, 0, -1)   # 5, 4, 3, 2, 1        (역순)

list(range(3))    # [0, 1, 2]  (리스트로 만들어 확인)
```

> ⚠️ `stop` 값은 **포함되지 않는다.** 1부터 n까지는 `range(1, n + 1)`.
