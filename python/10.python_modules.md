# 🐍 파이썬 모듈 — import · 패키지 · 표준 라이브러리

> **모듈** : 함수, 변수, 클래스 등을 모아 둔 **하나의 `.py` 파일**. 코드를 나눠 재사용하고 관리하기 쉽게 만든다. 이 문서 후반에는 코딩테스트에서 자주 쓰는 **표준 라이브러리**(`collections`, `heapq`, `bisect`, `itertools`, `functools`)를 정리한다.

---

## 모듈 가져오기 (import)

```python
import math

print(math.pi)         # 3.141592653589793
print(math.sqrt(16))   # 4.0
```

| 방식 | 문법 | 사용 예시 |
|------|------|-----------|
| 모듈 전체 | `import math` | `math.sqrt(16)` |
| 특정 기능만 | `from math import sqrt` | `sqrt(16)` |
| 여러 개 | `from math import pi, sqrt` | `pi`, `sqrt(16)` |
| 별칭 | `import math as m` | `m.sqrt(16)` |
| 전체 가져오기 | `from math import *` | `sqrt(16)` |

> ⚠️ `from math import *`는 어떤 이름이 들어왔는지 추적하기 어렵고 내 변수와 **이름이 충돌**할 수 있어 권장하지 않는다.

> ⚠️ 내 파일 이름을 `random.py`, `math.py`처럼 **표준 모듈과 같게 짓지 마라.** `import random`이 표준 모듈 대신 내 파일을 가져와서 `AttributeError`가 난다.

### 사용자 정의 모듈

> 직접 만든 `.py` 파일도 같은 폴더에 있으면 모듈로 가져올 수 있다.

```python
# my_module.py
def add(a, b):
    return a + b

PI = 3.14
```

```python
# main.py (같은 폴더)
import my_module

print(my_module.add(3, 5))   # 8
print(my_module.PI)          # 3.14
```

### `if __name__ == "__main__":`

> 모듈을 `import`하면 그 파일의 코드가 **위에서부터 한 번 실행**된다. 파일을 **직접 실행할 때만** 돌아야 하는 코드(테스트, 실행 진입점)는 이 조건 아래에 둔다.

```python
# my_module.py
def add(a, b):
    return a + b

if __name__ == "__main__":
    print("직접 실행할 때만:", add(1, 2))   # import할 때는 실행 안 됨
```

| 실행 방법 | `__name__` 값 | 블록 실행 |
|-----------|---------------|-----------|
| `python my_module.py` (직접 실행) | `"__main__"` | ✅ |
| 다른 파일에서 `import my_module` | `"my_module"` | ❌ |

> 💡 같은 모듈을 여러 번 `import`해도 코드는 **처음 한 번만** 실행되고, 그 뒤로는 이미 불러온 모듈을 재사용한다.

## 패키지 (Package)

> **패키지** : 여러 모듈을 **폴더 단위로** 묶은 것.

```text
my_package/
├── __init__.py      # 패키지 초기화 파일 (패키지를 import할 때 실행됨)
├── module_a.py
└── module_b.py
```

```python
from my_package import module_a
from my_package.module_b import some_func
```

> 💡 3.3부터는 `__init__.py`가 없어도 폴더를 패키지로 가져올 수 있지만, 일반적으로는 넣어 둔다.

### 외부 패키지 설치 (pip · 가상 환경)

> 표준 라이브러리에 없는 패키지는 **PyPI**에서 `pip`로 설치한다. 프로젝트마다 패키지 버전이 섞이지 않도록 **가상 환경(venv)**을 만들어 그 안에 설치하는 게 정석이다.

```bash
python -m venv .venv               # 가상 환경 만들기 (프로젝트 폴더에서 한 번)
.venv\Scripts\activate             # 켜기 (Windows)
source .venv/bin/activate          # 켜기 (macOS / Linux)

python -m pip install requests     # 패키지 설치
python -m pip freeze > requirements.txt   # 설치 목록 저장
python -m pip install -r requirements.txt # 목록대로 설치
```

> 💡 `pip install` 대신 `python -m pip install`을 쓰면, 지금 쓰는 그 파이썬에 정확히 설치된다(파이썬이 여러 개 깔려 있을 때 헷갈림 방지).

| 구분 | 설명 |
|------|------|
| 표준 라이브러리 | 파이썬에 기본 포함 (설치 불필요) |
| 외부 패키지 | `pip`로 별도 설치 |

## 표준 라이브러리 (Python Standard Library)

| 모듈 | 용도 | 예시 |
|------|------|------|
| `math` | 수학 함수 | `math.sqrt(16)`, `math.gcd(12, 18)`, `math.inf` |
| `random` | 난수 | `random.randint(1, 6)`, `random.choice(lst)` |
| `datetime` | 날짜·시간 | `datetime.date.today()` |
| `os` / `pathlib` | 파일·폴더·경로 | `os.getcwd()`, `Path("a.txt").exists()` |
| `sys` | 인터프리터 제어 | `sys.argv`, `sys.stdin.readline` |
| `collections` | 특수 자료구조 | `Counter`, `deque`, `defaultdict` |
| `heapq` | 힙 (우선순위 큐) | `heapq.heappush(h, x)` |
| `bisect` | 정렬된 리스트 이분 탐색 | `bisect.bisect_left(a, x)` |
| `itertools` | 순열·조합 등 반복 도구 | `itertools.combinations(a, 2)` |
| `functools` | 함수 도구 | `functools.lru_cache` |

```python
import random
print(random.randint(1, 6))        # 1~6 중 랜덤 정수
print(random.choice(["a", "b"]))   # 리스트에서 랜덤 선택

import datetime
print(datetime.date.today())       # 오늘 날짜
```

## 코딩테스트에 자주 쓰는 표준 라이브러리

### Counter — 개수 세기

```python
from collections import Counter

c = Counter("banana")
c["a"]              # 3
c["z"]              # 0   (없는 key도 에러 없이 0)
c.most_common(1)    # [('a', 3)]  (가장 많은 것부터)
Counter("aab") + Counter("bc")    # Counter({'a': 2, 'b': 2, 'c': 1})
```

### deque — 양쪽에서 빠르게 넣고 빼기 (큐 · BFS)

> 리스트의 `pop(0)`·`insert(0, x)`는 O(n)이지만, `deque`는 양쪽 끝 모두 **O(1)**이다. **큐와 BFS에는 반드시 `deque`**를 쓴다.

```python
from collections import deque

q = deque([1, 2, 3])
q.append(4)         # 오른쪽에 추가 → [1, 2, 3, 4]
q.appendleft(0)     # 왼쪽에 추가   → [0, 1, 2, 3, 4]
q.popleft()         # 왼쪽에서 꺼냄 → 0
q.pop()             # 오른쪽에서 꺼냄 → 4
q.rotate(1)         # 오른쪽으로 한 칸 회전 → [3, 1, 2]

# BFS 뼈대
def bfs(start, graph):
    visited = {start}
    q = deque([start])
    while q:
        node = q.popleft()
        for nxt in graph[node]:
            if nxt not in visited:
                visited.add(nxt)
                q.append(nxt)
    return visited
```

### heapq — 최솟값을 빠르게 꺼내기 (우선순위 큐)

> 리스트를 **최소 힙**으로 다룬다. 넣기·꺼내기 O(log n), 최솟값 확인 `h[0]`은 O(1). 다익스트라·"매번 가장 작은 것 꺼내기"에 쓴다.

```python
import heapq

h = []
heapq.heappush(h, 3)
heapq.heappush(h, 1)
heapq.heappush(h, 2)
heapq.heappop(h)       # 1   (가장 작은 값)
h[0]                   # 2   (꺼내지 않고 최솟값 확인)

arr = [5, 1, 3]
heapq.heapify(arr)     # 기존 리스트를 힙으로 (O(n))

heapq.heappush(h, (2, "b"))   # 튜플은 첫 값 기준 → (거리, 정점) 형태로 다익스트라
```

> ⚠️ `heapq`는 **최소 힙만** 있다. 최대 힙이 필요하면 **부호를 뒤집어** 넣고 꺼낼 때 다시 뒤집는다: `heappush(h, -x)`, `-heappop(h)`.

### bisect — 정렬된 리스트에서 이분 탐색

```python
import bisect

a = [1, 2, 2, 3, 5]                  # 반드시 정렬된 상태
bisect.bisect_left(a, 2)             # 1   (2 이상이 처음 나오는 위치)
bisect.bisect_right(a, 2)            # 3   (2 초과가 처음 나오는 위치)
bisect.bisect_right(a, 2) - bisect.bisect_left(a, 2)   # 2  (값 2의 개수)

bisect.insort(a, 4)                  # 정렬을 유지하며 삽입 → [1, 2, 2, 3, 4, 5]
```

### itertools — 순열 · 조합 · 곱집합

```python
from itertools import permutations, combinations, product, accumulate

list(permutations([1, 2, 3], 2))   # 순서 O, 중복 X → (1,2) (1,3) (2,1) ... 6개
list(combinations("abc", 2))       # 순서 X → [('a','b'), ('a','c'), ('b','c')]
list(product([0, 1], repeat=3))    # 중복 허용 모든 경우 → 8개
list(accumulate([1, 2, 3, 4]))     # 누적합 → [1, 3, 6, 10]
```

> 💡 완전탐색에서 직접 재귀를 짜는 대신 쓸 수 있다. 경우의 수가 폭발하니(n개 중 순열은 n!) 크기를 먼저 계산해 보자.

### functools.lru_cache — 결과 기억하기 (메모이제이션)

```python
from functools import lru_cache

@lru_cache(maxsize=None)        # 같은 인자의 결과를 저장해 두고 재사용
def fib(n):
    return n if n < 2 else fib(n - 1) + fib(n - 2)

fib(80)    # 23416728348467685  (캐시 없이는 사실상 끝나지 않음)
```

> ⚠️ 인자가 리스트처럼 해시 불가능한 값이면 쓸 수 없다. 튜플로 바꿔 넘기자. 데코레이터 문법은 [12. 객체 지향 심화](12.python_oop_advanced.md)에서 다룬다.
