# 🐍 파이썬 파일 입출력 — with · 인코딩 · pathlib · JSON · CSV

> 프로그램이 끝나도 남는 데이터를 다루려면 **파일**에 읽고 써야 한다. 파일을 안전하게 여닫는 **`with` 문**, 한글이 깨지지 않게 하는 **인코딩**, 경로를 다루는 **`pathlib`**, 그리고 자주 쓰는 데이터 형식인 **JSON**과 **CSV**를 다룬다.

---

## with — 자원을 알아서 정리

> `with`로 연 파일은 블록이 끝나면 **예외가 나도 자동으로 닫힌다.** 파일은 항상 `with`로 열자. (`finally`로 닫으려다 생기는 실수는 [13. 예외 처리](13.python_exception.md) 참고)

```python
with open("data.txt", "w", encoding="utf-8") as f:   # 쓰기 (없으면 만들고, 있으면 덮어씀)
    f.write("안녕\n")
    f.write("둘째 줄\n")

with open("data.txt", encoding="utf-8") as f:        # 읽기 (기본 모드 "r")
    content = f.read()            # 파일 전체를 문자열 하나로

with open("data.txt", encoding="utf-8") as f:
    for line in f:                # 한 줄씩 (큰 파일도 메모리 걱정 없음)
        print(line.rstrip("\n"))  # 줄 끝의 \n 제거
# 여기서 f는 이미 닫혀 있다 (f.closed == True)
```

> 💡 `with`는 파일 말고도 "열었으면 닫아야 하는" 자원(네트워크 연결, 잠금 등)에 두루 쓰인다. 이런 객체를 **컨텍스트 매니저**라고 한다.

---

## 열기 모드와 읽기 · 쓰기 메서드

| 모드 | 의미 |
|------|------|
| `"r"` | 읽기 (기본값). 파일이 없으면 `FileNotFoundError` |
| `"w"` | 쓰기. **기존 내용을 지운다** |
| `"a"` | 이어 쓰기 (끝에 추가) |
| `"x"` | 새로 만들기. 이미 있으면 에러 |
| `"b"` 추가 | 바이너리 (`"rb"`, `"wb"` — 이미지 등 텍스트가 아닌 파일) |

| 메서드 | 결과 |
|--------|------|
| `f.read()` | 전체를 문자열 하나로 |
| `f.readline()` | 한 줄 (`\n` 포함) |
| `f.readlines()` | 모든 줄을 리스트로 (`\n` 포함) |
| `for line in f:` | 한 줄씩 순회 (권장) |
| `f.write(s)` | 문자열 쓰기 (줄바꿈은 직접 `\n`) |
| `print(..., file=f)` | `print`로 파일에 쓰기 (자동 줄바꿈) |

```python
with open("log.txt", "a", encoding="utf-8") as f:
    print("한 줄 추가", file=f)                # print도 file=로 파일에 쓸 수 있다
    f.writelines(["a\n", "b\n"])               # 여러 줄 한 번에
```

## ⚠️ 인코딩 — 항상 utf-8을 적어라

> 파일은 결국 바이트다. 글자를 바이트로 바꾸는 규칙이 **인코딩**이고, 쓸 때와 읽을 때 규칙이 다르면 글자가 깨진다.

> ⚠️ `open()`에 `encoding`을 생략하면 운영체제의 기본 인코딩을 쓰는데, 한국어 Windows에서는 보통 **cp949**다. UTF-8로 저장된 한글 파일을 읽으면 `UnicodeDecodeError`가 나거나 글자가 깨지고, 반대로 내가 쓴 파일이 다른 컴퓨터에서 깨지기도 한다. **텍스트 파일은 항상 `encoding="utf-8"`을 명시하자.**

```python
with open("data.txt", encoding="utf-8") as f:   # ✅
    ...
```

## 경로 다루기 — pathlib

> `pathlib.Path`는 파일·폴더 경로를 객체로 다룬다. 운영체제마다 다른 경로 구분자(`\`, `/`)를 신경 쓰지 않아도 된다.

```python
from pathlib import Path

p = Path("data") / "report.txt"    # / 로 경로 이어 붙이기 → data/report.txt
p.parent.mkdir(parents=True, exist_ok=True)   # 폴더가 없으면 만들기

p.write_text("내용\n", encoding="utf-8")       # 짧은 파일은 한 줄로 쓰기
text = p.read_text(encoding="utf-8")           # 한 줄로 읽기

p.exists()      # True   (존재 여부)
p.name          # 'report.txt'
p.suffix        # '.txt'
p.stem          # 'report'

for f in Path("data").glob("*.txt"):           # 폴더 안의 .txt 파일 전부
    print(f.name)
```

> 💡 상대 경로(`"data.txt"`)는 **프로그램을 실행한 위치(작업 디렉터리)** 기준이다. 스크립트 파일 옆의 파일을 읽고 싶으면 `Path(__file__).parent / "data.txt"`처럼 스크립트 위치 기준으로 경로를 만든다.

## JSON — 딕셔너리 · 리스트를 파일로

> **JSON**은 딕셔너리·리스트 구조를 텍스트로 저장하는 형식이다. 설정 파일, 웹 API 응답 등에 널리 쓰인다. `json` 모듈이 파이썬 객체와 JSON 텍스트를 서로 바꿔 준다.

```python
import json

data = {"name": "건석", "age": 25, "langs": ["Python", "C++"]}

with open("data.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)   # 파일로 저장

with open("data.json", encoding="utf-8") as f:
    loaded = json.load(f)                              # 파일에서 읽기
print(loaded["langs"])                                 # ['Python', 'C++']

text = json.dumps(data, ensure_ascii=False)            # 객체 → 문자열
obj = json.loads(text)                                 # 문자열 → 객체
```

| 함수 | 변환 |
|------|------|
| `json.dump(obj, f)` / `json.load(f)` | 객체 ↔ **파일** |
| `json.dumps(obj)` / `json.loads(s)` | 객체 ↔ **문자열** (s = string) |

> 💡 `ensure_ascii=False`를 주지 않으면 한글이 `건`처럼 저장된다. `indent=2`는 사람이 읽기 좋게 들여쓴다.

> ⚠️ JSON으로 저장되는 건 `dict`, `list`, `str`, `int`, `float`, `bool`, `None`뿐이다. 튜플은 리스트로 바뀌고, 세트나 직접 만든 클래스 객체는 그대로 저장할 수 없다.

## CSV — 표 형태 데이터

> **CSV**는 쉼표로 칸을 나눈 표 데이터 형식이다. 엑셀에서 열고 저장할 수 있다. `csv` 모듈을 쓰면 칸 안의 쉼표·따옴표 처리를 알아서 해 준다.

```python
import csv

rows = [["이름", "점수"], ["kim", 90], ["lee", 85]]

with open("scores.csv", "w", encoding="utf-8", newline="") as f:
    csv.writer(f).writerows(rows)              # 여러 줄 한 번에 쓰기

with open("scores.csv", encoding="utf-8", newline="") as f:
    for row in csv.reader(f):                  # 한 줄씩 리스트로
        print(row)                             # ['이름', '점수'] → ['kim', '90'] → ['lee', '85']

with open("scores.csv", encoding="utf-8", newline="") as f:
    for row in csv.DictReader(f):              # 첫 줄을 key로 쓰는 딕셔너리로
        print(row["이름"], int(row["점수"]))   # kim 90 → lee 85
```

> ⚠️ CSV 파일을 열 땐 `newline=""`을 함께 주자. 빠뜨리면 Windows에서 줄마다 빈 줄이 끼어 저장된다. 또 읽은 값은 **전부 문자열**이라 숫자는 `int()`로 바꿔야 한다.

> 💡 엑셀에서 바로 열 CSV라면 `encoding="utf-8-sig"`로 저장해야 한글이 깨지지 않는다(엑셀이 BOM으로 UTF-8을 알아본다).
