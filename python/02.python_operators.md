# 🐍 파이썬 기초 — 연산자

> 산술·비교·논리 연산자와, 파이썬만의 규칙인 **Truthy/Falsy**, **`is`와 `==`의 차이**, **비교 연산자 연결**을 다룬다.

---

## 산술 연산자

| 연산자 | 의미 | 예시 | 결과 |
|--------|------|------|------|
| `+` | 덧셈 | `3 + 2` | `5` |
| `-` | 뺄셈 | `3 - 2` | `1` |
| `*` | 곱셈 | `3 * 2` | `6` |
| `/` | 나눗셈 (항상 float) | `7 / 2` | `3.5` |
| `//` | 몫 (내림) | `7 // 2` | `3` |
| `%` | 나머지 | `7 % 2` | `1` |
| `**` | 거듭제곱 | `2 ** 3` | `8` |

```python
q, r = divmod(17, 5)   # (3, 2)  몫과 나머지를 한 번에
abs(-5)                # 5
```

> ⚠️ **`**`는 단항 `-`보다 먼저 계산된다.** `-2 ** 2`는 `(-2) ** 2 = 4`가 아니라 `-(2 ** 2) = -4`다.

### ⚠️ 음수의 몫과 나머지

> `//`는 0 쪽이 아니라 **항상 아래(음의 무한대 쪽)로 내림**한다. 그래서 음수에서 C++·Java와 결과가 다르다. 대신 `%`의 결과가 항상 나누는 수와 같은 부호(양수로 나누면 양수)라서 편하다.

```python
-7 // 2     # -4   (C++은 -3)
-7 % 2      # 1    (C++은 -1)
```

### ⚠️ round는 사사오입이 아니다

> `round()`는 정확히 `.5`일 때 **가장 가까운 짝수**로 반올림한다(은행가 반올림). 실수 오차 때문에 예상과 다른 값이 나오기도 한다.

```python
round(2.5)        # 2   (3이 아님!)
round(3.5)        # 4
round(2.675, 2)   # 2.67 (2.675가 실제로는 2.67499...로 저장되어 있음)
```

> 💡 "0.5 이상이면 올림"이 꼭 필요하면 `int(x + 0.5)`(양수일 때)나 `decimal` 모듈을 쓴다. 출력만 반올림하려면 `f"{x:.2f}"` 형식을 쓴다.

### 복합 대입 연산자

| 연산자 | 의미 |
|--------|------|
| `x += 3` | `x = x + 3` |
| `x -= 3` | `x = x - 3` |
| `x *= 2` | `x = x * 2` |
| `x /= 2` | `x = x / 2` |
| `x //= 2` | `x = x // 2` |
| `x %= 2` | `x = x % 2` |
| `x **= 2` | `x = x ** 2` |

> 💡 파이썬에는 `++`, `--`가 없다. `x += 1`을 쓴다.

## 비교 연산자

| 연산자 | 의미 | 예시 | 결과 |
|--------|------|------|------|
| `==` | 같음 | `3 == 3` | `True` |
| `!=` | 다름 | `3 != 4` | `True` |
| `>` / `<` | 초과 / 미만 | `5 > 3` | `True` |
| `>=` / `<=` | 이상 / 이하 | `5 >= 5` | `True` |

> 💡 **비교 연산자를 이어 쓸 수 있다.** 수학식처럼 읽힌다.
> ```python
> x = 5
> 1 < x < 10      # True  (1 < x and x < 10 과 같음)
> 0 <= i < n      # 인덱스 범위 검사에 자주 쓴다
> ```

## 논리 연산자

| 연산자 | 의미 | 예시 | 결과 |
|--------|------|------|------|
| `and` | 둘 다 참 | `True and False` | `False` |
| `or` | 하나라도 참 | `True or False` | `True` |
| `not` | 반전 | `not True` | `False` |

### 단축 평가 (Short-circuit evaluation)

```python
# and: 앞이 거짓이면 뒤를 평가하지 않음
False and print("실행 안됨")   # False

# or: 앞이 참이면 뒤를 평가하지 않음
True or print("실행 안됨")     # True
```

> 💡 **`and`/`or`는 `True`/`False`가 아니라 피연산자 값 자체를 돌려준다.** 결과를 결정한 쪽의 값이 나온다.
> ```python
> 0 or "기본값"     # "기본값"  (0이 거짓이라 뒤의 값)
> "" and 5          # ""        (앞이 거짓이라 앞의 값)
> 3 and 5           # 5         (둘 다 참이면 마지막 값)
>
> name = None
> result = name or "익명"   # name이 거짓(None)이므로 "익명"
> ```

### Truthy · Falsy

> 조건문에는 `bool`이 아닌 값도 들어갈 수 있다. 파이썬은 아래 값들을 **거짓(Falsy)**으로, 나머지는 전부 **참(Truthy)**으로 본다.

| Falsy 값 | 설명 |
|----------|------|
| `False`, `None` | 거짓, 값 없음 |
| `0`, `0.0` | 숫자 0 |
| `""` | 빈 문자열 |
| `[]`, `()`, `{}`, `set()` | 빈 컬렉션 |

```python
nums = []
if nums:            # if len(nums) > 0: 과 같음 (파이썬다운 방식)
    print("있음")
else:
    print("비었음")  # 출력됨

bool("False")       # True  (비어 있지 않은 문자열)
bool([0])           # True  (원소가 하나 있는 리스트)
```

## 멤버십 · 식별 연산자

### in / not in

| 연산자 | 의미 | 예시 | 결과 |
|--------|------|------|------|
| `in` | 포함 여부 | `"a" in "apple"` | `True` |
| `not in` | 미포함 여부 | `5 not in [1, 2, 3]` | `True` |

> 💡 `x in 리스트`는 처음부터 하나씩 확인해서 O(n)이고, `x in 세트`·`x in 딕셔너리`는 해시 덕분에 평균 O(1)이다. 존재 확인을 반복하면 세트로 바꾸자. ([05. 딕셔너리 · 세트](05.python_dict_set.md) 참고)

### is / is not — 같은 객체인가

> `==`는 **값이 같은지**, `is`는 **같은 객체(메모리상의 같은 것)인지**를 비교한다.

```python
a = [1, 2]
b = [1, 2]
c = a

a == b      # True   (값이 같음)
a is b      # False  (서로 다른 리스트 객체)
a is c      # True   (같은 객체를 가리킴)
```

> ⚠️ **`None`과 비교할 때만 `is`를 쓰고(`x is None`), 값 비교는 항상 `==`를 써라.** 작은 정수나 짧은 문자열은 파이썬이 객체를 재사용해서 `is`가 우연히 `True`가 되기도 하는데, 이걸 믿으면 안 된다. (변수와 객체의 관계는 [06. 참조 · 복사](06.python_reference_copy.md) 참고)

## 비트 연산자

> 정수를 이진수로 보고 비트 단위로 계산한다. 집합 표현(비트마스크)·홀짝 판정 등에 쓴다.

| 연산자 | 의미 | 예시 | 결과 |
|--------|------|------|------|
| `&` | AND | `6 & 3` | `2` |
| `\|` | OR | `6 \| 3` | `7` |
| `^` | XOR | `6 ^ 3` | `5` |
| `~` | NOT | `~6` | `-7` |
| `<<` | 왼쪽 시프트 | `1 << 4` | `16` (2⁴) |
| `>>` | 오른쪽 시프트 | `16 >> 2` | `4` |

```python
if x & 1: ...           # 홀수 판정
mask |= 1 << i          # i번째 비트 켜기
if mask & (1 << i): ... # i번째 비트 확인
bin(10)                 # '0b1010'  (2진수 문자열)
```

## 시퀀스 연산자

```python
[1, 2] + [3, 4]   # [1, 2, 3, 4]   (+: 이어붙이기)
"hi" * 3          # "hihihi"       (*: 반복)
[0] * 5           # [0, 0, 0, 0, 0]
```

> ⚠️ 2차원 리스트를 `[[0] * 3] * 2`로 만들면 안 된다. 모든 행이 **같은 리스트를 공유**한다. ([06. 참조 · 복사](06.python_reference_copy.md)의 2차원 리스트 함정 참고)

## 연산자 우선순위 (높음 → 낮음)

| 우선순위 | 연산자 |
|----------|--------|
| 1 (높음) | `**` |
| 2 | `-x`, `+x`, `~x` (단항) |
| 3 | `*`, `/`, `//`, `%` |
| 4 | `+`, `-` |
| 5 | `<<`, `>>` |
| 6 | `&` |
| 7 | `^` |
| 8 | `\|` |
| 9 | `==`, `!=`, `>`, `<`, `>=`, `<=`, `in`, `not in`, `is`, `is not` |
| 10 | `not` |
| 11 | `and` |
| 12 (낮음) | `or` |

> 💡 헷갈리면 괄호로 묶어라. 특히 비트 연산은 `+`, `-`보다 낮아서 `1 << n - 1`은 `1 << (n - 1)`로 계산된다.
