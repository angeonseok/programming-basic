# 🐍 파이썬 제어문 — 조건문 · 반복문

> **제어문** : 코드의 **실행 흐름을 조절**하는 문법. 조건에 따라 분기하거나(조건문), 반복해서 실행한다(반복문).

| 종류 | 키워드 | 역할 |
|------|--------|------|
| 조건문 | `if`, `elif`, `else`, `match` | 조건에 따라 분기 |
| 반복문 | `for`, `while` | 코드를 반복 실행 |
| 반복 제어 | `break`, `continue`, `pass` | 반복 흐름 제어 |

---

## 조건문 (if)

> 조건이 **참**일 때만 해당 블록을 실행한다. 조건 뒤에 콜론(`:`), 블록은 들여쓰기.

```python
score = 85

if score >= 90:
    print("A")
elif score >= 80:
    print("B")     # 출력됨
else:
    print("C")
```

| 키워드 | 설명 |
|--------|------|
| `if` | 첫 조건 (필수) |
| `elif` | 추가 조건 (여러 개 가능, 선택) |
| `else` | 모든 조건이 거짓일 때 (선택) |

> 💡 조건에는 `bool`이 아닌 값도 쓸 수 있다. `if nums:`는 "리스트가 비어 있지 않으면"이다. ([02. 연산자](02.python_operators.md)의 Truthy · Falsy)

### 중첩 조건문

```python
age = 20
if age >= 18:
    if age >= 65:
        print("경로")
    else:
        print("성인")   # 출력됨
```

> 💡 중첩이 깊어지면 `and`로 합치거나(`if age >= 18 and age < 65:`), 비교 연결(`if 18 <= age < 65:`)로 평평하게 만들자.

### 조건 표현식 (삼항 연산자)

> `참값 if 조건 else 거짓값` — 한 줄로 분기한다.

```python
result = "성인" if age >= 18 else "미성년자"
```

### match — 패턴 매칭 (3.10+)

> 값 하나를 여러 경우와 비교해 분기한다. C++·Java의 `switch`와 비슷하지만, 튜플·리스트의 **모양**까지 비교할 수 있다.

```python
def command(cmd):
    match cmd:
        case "start":
            return "시작"
        case "stop" | "quit":        # 여러 값 중 하나
            return "종료"
        case _:                      # 그 외 전부 (default)
            return "알 수 없음"

def where(point):
    match point:
        case (0, 0):
            return "원점"
        case (x, 0):                 # 모양이 맞으면 x에 값이 담긴다
            return f"x축 위 {x}"
        case (x, y):
            return f"{x}, {y}"

where((3, 0))    # 'x축 위 3'
```

> ⚠️ `match`는 3.10부터다. 채점 환경이 그보다 오래된 버전이면 `if/elif`를 쓰자.

## 반복문

### for

> 반복 가능한 객체(리스트, 문자열, range 등)의 원소를 **하나씩 순서대로** 꺼내 반복한다.

```python
for fruit in ["apple", "banana"]:
    print(fruit)        # apple → banana

for i in range(3):
    print(i)            # 0 → 1 → 2

for ch in "abc":
    print(ch)           # a → b → c

for key, value in {"a": 1, "b": 2}.items():
    print(key, value)   # a 1 → b 2
```

### while

> 조건이 **참인 동안** 계속 반복한다.

```python
count = 0
while count < 3:
    print(count)        # 0 → 1 → 2
    count += 1          # 종료 조건을 향해 변화시켜야 함
```

> ⚠️ 조건이 계속 참이면 **무한 루프**에 빠진다. 반드시 조건을 변화시키는 코드가 있어야 한다.

| 구분 | for | while |
|------|-----|-------|
| 사용 시점 | 반복할 대상(횟수)이 정해짐 | 조건에 따라 반복 |
| 대상 | 반복 가능한 객체 | 조건식 |

### break · continue · pass

| 키워드 | 동작 |
|--------|------|
| `break` | 반복문을 **즉시 종료** |
| `continue` | 이번 반복을 건너뛰고 **다음 반복으로** |
| `pass` | 아무것도 하지 않음 (문법상 자리만 채움) |

```python
for i in range(10):
    if i == 3:
        break
    print(i)        # 0 → 1 → 2

for i in range(5):
    if i % 2 == 0:
        continue
    print(i)        # 1 → 3

def todo():
    pass            # 나중에 구현할 함수의 자리 채우기
```

> 💡 중첩 반복문에서 `break`는 **안쪽 반복문만** 빠져나간다. 바깥까지 한 번에 나가려면 함수로 빼서 `return`하는 게 가장 깔끔하다.

### for-else / while-else

> 반복문이 `break` **없이 끝까지 돌면** `else` 블록이 실행된다. "찾았으면 `break`, 끝까지 못 찾으면 `else`" 패턴에 쓴다.

```python
nums = [1, 3, 5]
for n in nums:
    if n % 2 == 0:
        print("짝수 발견:", n)
        break
else:
    print("짝수 없음")    # break를 안 만났으므로 실행
```

## 반복을 돕는 함수

### enumerate — 인덱스와 값을 함께

```python
fruits = ["apple", "banana", "cherry"]

for i, fruit in enumerate(fruits):
    print(i, fruit)              # 0 apple → 1 banana → 2 cherry

for i, fruit in enumerate(fruits, start=1):
    print(i, fruit)              # 1 apple → 2 banana → 3 cherry
```

> 💡 `for i in range(len(fruits)):` 후 `fruits[i]`로 꺼내는 것보다 `enumerate`가 더 파이썬다운 방식이다.

### zip — 여러 시퀀스를 짝지어

```python
names = ["건석", "철수"]
ages = [25, 30]

for name, age in zip(names, ages):
    print(f"{name}: {age}")      # 건석: 25 → 철수: 30

list(zip(names, ages))           # [('건석', 25), ('철수', 30)]
dict(zip(names, ages))           # {'건석': 25, '철수': 30}
```

> ⚠️ 길이가 다르면 **짧은 쪽에 맞춰 조용히 잘린다.** 길이가 반드시 같아야 하면 `zip(a, b, strict=True)`(3.10+)로 다를 때 에러를 내게 할 수 있다.

### 역순 · 정렬 순서로 돌기

```python
for x in reversed([1, 2, 3]):   # 3 → 2 → 1
    ...
for x in sorted([3, 1, 2]):     # 1 → 2 → 3 (원본은 그대로)
    ...
```

## 참고

### 바다코끼리 연산자 `:=` (3.8+)

> 값을 **대입하면서 동시에 그 값을 식으로** 쓴다. 조건에서 계산한 값을 다시 쓰고 싶을 때 줄을 아낀다.

```python
data = [1, 2, 3, 4]
if (n := len(data)) > 3:
    print(f"원소가 {n}개로 많다")

while (line := input()) != "end":   # "end"가 나올 때까지 입력 받기
    print(line)
```

### 반복문 안에서 리스트·딕셔너리 수정 주의

> 순회 중인 리스트에서 원소를 지우면 원소를 건너뛰고, 딕셔너리는 에러가 난다. 새 리스트를 만들거나 복사본을 순회하자. ([04. 리스트 · 튜플](04.python_list_tuple.md), [05. 딕셔너리 · 세트](05.python_dict_set.md))
