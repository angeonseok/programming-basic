# C++ Basic

이 디렉토리는 **C++17 기준**으로 정리한 C++ 학습 노트입니다.

입문서처럼 **언어의 기초 → 메모리 → 객체 지향 → 템플릿과 STL → 프로그램 완성** 순서로 구성했습니다. 문법 설명과 예제 코드로 개념을 익히고, 각 문서의 ⚠️(함정)·💡(팁) 상자로 실수하기 쉬운 부분을 짚습니다. 코딩테스트(알고리즘 문제 풀이)에 필요한 내용은 본문과 분리해 **부록**에 모았습니다.

구조적 바인딩, 초기화문이 있는 `if`, CTAD, `std::optional`, `std::string_view`처럼 C++17에서 추가된 문법에는 **(C++17)** 표시를 붙였습니다.

> ⚠️ 컴파일러가 C++14 이하로 설정되어 있으면 **(C++17)** 표시가 붙은 문법은 컴파일되지 않습니다. `-std=c++17` 옵션을 확인하세요.
