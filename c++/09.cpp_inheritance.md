# 🔷 09. 상속과 다형성

> 기존 클래스를 물려받아 새 클래스를 만드는 **상속**과, 같은 호출이 객체의 실제 타입에 따라 다르게 동작하는 **다형성(`virtual`)**을 다룬다.

---

## 상속과 다형성

### 상속 기본

> 부모 클래스의 멤버를 물려받는다. `: public 부모`로 표기. (파이썬 `class Dog(Animal)`)

```cpp
class Animal {
public:
    void eat() { cout << "먹는다\n"; }
};

class Dog : public Animal {    // Animal 상속
public:
    void bark() { cout << "멍멍\n"; }
};

Dog d;
d.eat();   // 부모에게서 물려받음
d.bark();  // 자식 고유
```

> 💡 대부분 `public` 상속을 쓴다. `protected`/`private` 상속은 드물게 쓰인다.

### 부모 생성자 호출

> 자식 생성자에서 부모 생성자를 호출하려면 **초기화 리스트**에 적는다. (파이썬 `super().__init__()`)

```cpp
class Dog : public Animal {
    string name;
public:
    Dog(string n) : Animal(), name(n) {   // 부모 생성자 명시 호출
        // 부모에 인자 필요하면 : Animal(n), name(n)
    }
};
```

### virtual / 오버라이딩

> 부모 메서드를 `virtual`로 두면, 자식이 재정의했을 때 **실제 객체 타입의 메서드가 호출**된다(다형성). 파이썬은 기본이 이 동작이다.

```cpp
class Animal {
public:
    virtual void speak() { cout << "...\n"; }   // virtual
    virtual ~Animal() {}                        // 가상 소멸자 (다형성 쓰면 필수)
};

class Dog : public Animal {
public:
    void speak() override { cout << "멍멍\n"; }  // override
};

Animal* a = new Dog();
a->speak();   // "멍멍"  (포인터는 Animal이지만 실제는 Dog → 다형성)
delete a;
```

> ⚠️ `virtual`을 안 붙이면 **포인터 타입 기준**으로 호출돼 `"..."`이 나온다. 다형성을 원하면 `virtual` 필수다.

> 💡 실제 코드에선 `new`/`delete` 대신 스마트 포인터를 쓴다([07. 참조와 메모리 관리](07.cpp_memory.md) 참고). 다형성은 그대로 동작하고 `delete`를 잊을 일이 없다.
> ```cpp
> unique_ptr<Animal> b = make_unique<Dog>();
> b->speak();   // "멍멍"  (b가 사라질 때 자동 delete)
> ```

> ⚠️ 상속·다형성을 쓸 클래스의 소멸자는 **반드시 `virtual`**로. 아니면 부모 포인터로 `delete`할 때 자식 소멸자가 안 불려 누수가 난다.

### 추상 클래스 / 순수 가상 함수

> `= 0`으로 선언한 **순수 가상 함수**가 있으면 그 클래스는 **추상 클래스**(객체 생성 불가, 자식이 반드시 구현). (파이썬 ABC에 대응)

```cpp
class Shape {
public:
    virtual double area() = 0;   // 순수 가상 함수
    virtual ~Shape() = default;  // 가상 소멸자 (= default: 기본 동작 그대로)
};

class Circle : public Shape {
    double r;
public:
    Circle(double r) : r(r) {}
    double area() override { return 3.14 * r * r; }  // 반드시 구현
};

// Shape s;    ❌ 추상 클래스라 생성 불가
Circle c(5);   // ✅
```

## 다형성 더 알아보기

### 다형성은 포인터 · 참조로만 동작한다

> 부모 타입의 **값**에 자식 객체를 담으면 자식 부분이 잘려 나가고 부모 부분만 복사된다(**객체 슬라이싱**). 다형성을 쓰려면 반드시 **포인터나 참조**로 다뤄야 한다.

```cpp
void speakRef(Animal& a) { a.speak(); }   // 참조: 실제 타입(Dog)의 speak
void speakVal(Animal a)  { a.speak(); }   // 값: Dog 부분이 잘려 Animal의 speak

Dog d;
speakRef(d);   // "멍멍"
speakVal(d);   // "..."  ← 슬라이싱!
```

### 여러 자식 객체를 한 컨테이너에

```cpp
#include <memory>
class Cat : public Animal {
public:
    void speak() override { cout << "야옹\n"; }
};

vector<unique_ptr<Animal>> zoo;
zoo.push_back(make_unique<Dog>());
zoo.push_back(make_unique<Cat>());

for (const auto& a : zoo) a->speak();   // 멍멍 → 야옹 (각자 실제 타입의 speak)
```

> 💡 `vector<Animal>`로는 안 된다(슬라이싱). **부모 포인터(`unique_ptr<Animal>`)를 담는 것**이 여러 타입을 한 컨테이너에 넣는 정석이다.

### override · final

```cpp
class Dog : public Animal {
public:
    void speak() override { }         // 부모에 같은 virtual 함수가 없으면 컴파일 에러 → 오타 방지
};

class Puppy final : public Dog { };   // final 클래스: 더 이상 상속할 수 없음
```

> ⚠️ `override`를 빼고 `void speek()`처럼 오타를 내면, 컴파일러는 그냥 새 함수로 보고 넘어간다. 부모 함수를 재정의할 땐 항상 `override`를 붙이자.
