# 🔷 C++ 기초 문법 — 문자열 (string)

> 문자열 처리는 코테 최다 출제 영역 중 하나다. `std::string`의 조작 함수, **문자 산술**, **한 줄 입력(getline)**, **stringstream 파싱**을 실전 위주로 다룬다.

---

## std::string 기초

### 선언과 기본 연산

> C 스타일 `char[]`도 있지만, 코테에선 **`std::string`**을 쓴다. 가변 길이에 편리한 함수가 많고 파이썬 str에 가장 가깝다.

```cpp
#include <string>
string s = "hello";

s += " world";        // 이어붙이기 → "hello world"
s.push_back('!');     // 문자 하나 추가 → "hello world!"
cout << s[0];         // 'h'  (인덱싱, 0부터)
cout << s.size();     // 12   (길이, .length()도 동일)
cout << s.back();     // '!'  (마지막 문자)
cout << s.front();    // 'h'  (첫 문자)
```

> ⚠️ 파이썬 문자열은 **불변**이라 수정 시 새 객체였지만, C++ `string`은 **가변**이다. `s[0] = 'H'`로 직접 고칠 수 있다.

```cpp
string t = "hello";
t[0] = 'H';           // "Hello"  (직접 수정 가능)
```

### 빈 문자열 · 순회

```cpp
string s = "abc";

if (s.empty()) { }              // 비었는지 검사
for (char c : s) cout << c;     // 범위 기반 for로 문자 순회
for (int i = 0; i < (int)s.size(); i++) cout << s[i];  // 인덱스 순회
```

> ⚠️ `s.size()`는 **부호 없는 정수(`size_t`)**를 반환한다. `for (int i = 0; i < s.size() - 1; ...)`에서 `s`가 비면 `size()-1`이 **엄청 큰 양수**가 되어 무한 루프에 빠진다. `(int)s.size()`로 캐스팅하거나 조건을 조심하라.

## 문자 산술 (코테 필수 테크닉)

> C++에서 `char`는 사실상 **작은 정수(아스키 코드)**다. 문자끼리 빼거나 정수를 더할 수 있어, 알파벳·숫자 인덱싱에 아주 유용하다.

```cpp
char c = 'A';
cout << (int)c;         // 65   ('A'의 아스키 코드)

// 숫자 문자 → 정수
char d = '7';
int n = d - '0';        // 7    (문자 '7'을 숫자 7로)

// 알파벳 → 0~25 인덱스
char ch = 'c';
int idx = ch - 'a';     // 2    (알파벳 순서)

// 대문자 ↔ 소문자
char lower = 'A' + ('a' - 'A');   // 'a'
char upper = 'z' - ('a' - 'A');   // 'Z'
```

| 관용구 | 의미 | 예시 |
|--------|------|------|
| `c - '0'` | 숫자 문자 → 정수 | `'5' - '0'` → `5` |
| `c - 'a'` | 소문자 → 0~25 | `'c' - 'a'` → `2` |
| `c - 'A'` | 대문자 → 0~25 | `'C' - 'A'` → `2` |
| `'a' + i` | 0~25 → 소문자 | `'a' + 2` → `'c'` |

> 💡 **알파벳 빈도수 세기**는 이 테크닉의 대표 활용이다. 26칸 배열의 인덱스로 문자를 바로 매핑한다.
> ```cpp
> int cnt[26] = {};
> for (char c : s) cnt[c - 'a']++;   // 각 소문자 등장 횟수
> ```

### 문자 판별 함수 (`<cctype>`)

| 함수 | 판별 | 예시 |
|------|------|------|
| `isdigit(c)` | 숫자 0~9 | `isdigit('5')` → 참 |
| `isalpha(c)` | 알파벳 | `isalpha('a')` → 참 |
| `isalnum(c)` | 알파벳+숫자 | |
| `isupper(c)` / `islower(c)` | 대/소문자 | |
| `toupper(c)` / `tolower(c)` | 대/소문자 변환 | `toupper('a')` → `'A'` |

```cpp
#include <cctype>
string s = "aB3";
for (char& c : s) c = toupper(c);   // "AB3" (원본 대문자화)
```

> ⚠️ **`toupper`/`tolower`는 `int`를 반환한다.** `cout << toupper('a');`는 `A`가 아니라 **`65`**를 출력한다. 위처럼 `char` 변수에 다시 담거나 `(char)toupper(c)`로 바꿔 출력하라.

> 💡 `<cctype>` 함수에 한글 같은 비(非)ASCII 바이트(음수 `char`)를 넘기면 정의되지 않은 동작이다. 그런 입력이 섞일 수 있으면 `isalpha((unsigned char)c)`처럼 넘긴다.

## 주요 문자열 함수

| 함수 | 설명 | 예시 → 결과 |
|------|------|-------------|
| `.size()` / `.length()` | 길이 | `s.size()` |
| `.substr(i, n)` | `i`부터 `n`개 부분 문자열 | `"hello".substr(1, 3)` → `"ell"` |
| `.substr(i)` | `i`부터 끝까지 | `"hello".substr(2)` → `"llo"` |
| `.find("x")` | `x` 위치, 없으면 `npos` | `"hello".find("l")` → `2` |
| `.find("x", pos)` | `pos`부터 찾기 | `"hello".find("l", 3)` → `3` |
| `.rfind("x")` | 뒤에서부터 찾기 | `"hello".rfind("l")` → `3` |
| `.replace(i, n, str)` | `i`부터 `n`개를 `str`로 | |
| `.insert(i, str)` | `i` 위치에 삽입 | |
| `.erase(i, n)` | `i`부터 `n`개 삭제 | |
| `+`, `+=` | 이어붙이기 | `"a" + b` |

```cpp
string s = "hello world";

cout << s.substr(0, 5);      // "hello"
cout << s.substr(6);         // "world"

size_t pos = s.find("world"); // 6
if (s.find("xyz") == string::npos) {   // 못 찾으면 npos
    cout << "없음";
}
```

> ⚠️ `.find()`는 못 찾으면 **`string::npos`**(`size_t`의 최댓값)를 반환한다. 반드시 `== string::npos` / `!= string::npos`로 판정하라. 아래 두 습관은 틀린다.
> ```cpp
> if (s.find(x))       // ❌ 0번 위치에서 찾으면 거짓, 못 찾으면(npos) 참 → 반대로 동작
> if (s.find(x) >= 0)  // ❌ size_t는 음수가 없어 항상 참
> ```

> 💡 **모든 등장 위치 찾기**는 `find(x, pos)`로 이어서 찾는다.
> ```cpp
> string t = "abcabc";
> for (size_t p = t.find("bc"); p != string::npos; p = t.find("bc", p + 1))
>     cout << p << " ";   // 1 4
> ```

### 뒤집기 · 정렬

> 문자열도 컨테이너라 `<algorithm>` 함수를 그대로 쓸 수 있다. (자세한 건 `06.cpp_stl_algorithm` 참고)

```cpp
#include <algorithm>
string s = "dbca";

reverse(s.begin(), s.end());   // "acbd"
sort(s.begin(), s.end());      // "abcd" (문자 오름차순 정렬)
```

> 💡 애너그램 판정: 두 문자열을 각각 정렬해 같으면 애너그램이다.

### 문자열 만들기 · 이어붙이기 함정

```cpp
string a(3, 'x');            // "xxx"  (파이썬 'x' * 3)
string b = string("ab") + "cd";  // "abcd"
string c = "ab";
c += 'z';                    // "abz"  (문자 하나 붙이기)

// string d = "ab" + "cd";   // ❌ 컴파일 에러: 리터럴 둘은 string이 아니라 const char*
```

> ⚠️ **반복문 안에서 `s = s + c`를 쓰지 마라.** `s + c`가 매번 **새 문자열을 통째로 복사**해서 만들기 때문에 길이 n이면 전체 O(n²)이 된다. `s += c`(또는 `push_back`)는 끝에 덧붙이기만 해서 평균 O(1)이다.
> ```cpp
> for (char ch : src) res = res + ch;   // ❌ 매번 복사 → 10만 글자면 시간 초과
> for (char ch : src) res += ch;        // ✅
> ```

## 입력 다루기 (getline & 버퍼)

### 한 줄 전체 입력

> `cin >>`은 공백에서 끊기므로, **공백 포함 한 줄**은 `getline`으로 받는다.

```cpp
string line;
getline(cin, line);            // 줄 전체 입력 (공백 포함)
```

### ⚠️ `cin >>` 다음 `getline` 함정 — 코테 단골 버그

> `cin >> n`은 숫자만 읽고 **줄바꿈(`\n`)을 버퍼에 남긴다.** 곧바로 `getline`하면 그 남은 줄바꿈을 읽어 **빈 줄**이 들어온다.

```cpp
int n;
cin >> n;
cin.ignore();          // ✅ 남은 줄바꿈 하나 버리기 (핵심!)

string line;
getline(cin, line);    // 이제 정상적으로 다음 줄을 읽음
```

| 상황 | 해결 |
|------|------|
| `cin >>` 뒤에 `getline` | 사이에 `cin.ignore();` |
| `getline`만 여러 번 | 그냥 반복 (문제 없음) |

> 💡 `cin.ignore()`는 버퍼에서 문자 하나(줄바꿈)를 버린다. 남은 게 여러 개면 `cin.ignore(numeric_limits<streamsize>::max(), '\n');`으로 줄 끝까지 버린다(`#include <limits>`). 숫자 뒤에 공백이 남아 있을 수 있는 입력이면 이 방법이 더 안전하다.

### 여러 줄 반복 입력

```cpp
string line;
while (getline(cin, line)) {   // EOF까지 줄 단위로
    // line 처리
}
```

## 문자열 파싱 (stringstream)

> **한 줄에 여러 값이 공백/기호로 구분**되어 들어올 때, `stringstream`으로 잘라 읽는다. 파이썬 `split()`에 대응하는 코테 핵심 도구다.

### 공백 기준 분리

```cpp
#include <sstream>
string line = "10 20 30 40";
stringstream ss(line);

int x;
vector<int> nums;
while (ss >> x) {          // 공백 단위로 하나씩 (자동으로 int 변환)
    nums.push_back(x);     // {10, 20, 30, 40}
}
```

```cpp
// 단어 단위로 자르기
string sentence = "hello world cpp";
stringstream ss(sentence);
string word;
while (ss >> word) {       // 공백 단위 단어
    cout << word << "\n";  // hello / world / cpp
}
```

### 특정 구분자로 분리 (getline + delim)

> 쉼표(`,`)처럼 **공백이 아닌 구분자**로 자를 땐 `getline`의 세 번째 인자에 구분자를 준다.

```cpp
string line = "apple,banana,cherry";
stringstream ss(line);
string token;
vector<string> tokens;

while (getline(ss, token, ',')) {   // ',' 기준 분리
    tokens.push_back(token);        // {"apple", "banana", "cherry"}
}
```

| 목적 | 방법 |
|------|------|
| 공백으로 분리 | `stringstream ss(line); ss >> x;` |
| 특정 문자로 분리 | `getline(ss, token, 구분자);` |

> 💡 숫자 여러 개를 문자열로 이어 만들 때도 `stringstream`이 편하다.
> ```cpp
> stringstream out;
> out << a << " " << b;      // 값을 문자열로 조립
> string result = out.str(); // 완성된 문자열 얻기
> ```

## 참고

### 문자열 ↔ 숫자 변환

```cpp
int    n  = stoi("42");      // string → int
long long ll = stoll("10000000000");  // string → long long
double d  = stod("3.14");    // string → double
string s  = to_string(255);  // 숫자 → string → "255"
```

> ⚠️ `stoi`는 `int` 범위를 넘는 문자열엔 예외를 던진다. 큰 수 문자열은 `stoll`을 써라. 반대로 `stoi("12abc")`는 에러 없이 **앞의 숫자 부분만 읽어 `12`**를 돌려준다.

> ⚠️ `to_string(3.14)`는 `"3.14"`가 아니라 **`"3.140000"`**이다(소수점 아래 6자리 고정). 실수를 원하는 형식으로 문자열로 만들려면 `stringstream`에 `fixed << setprecision(n)`을 써라.

> 💡 **`from_chars` (C++17, `<charconv>`)** — 예외를 던지지 않고, 변환 성공 여부를 반환값으로 알려주는 가장 빠른 문자열→숫자 변환이다.
> ```cpp
> #include <charconv>
> string s = "12345";
> int value;
> auto [ptr, ec] = from_chars(s.data(), s.data() + s.size(), value);
> if (ec == errc()) { /* 성공: value = 12345 */ }
> ```
> 코테에선 `stoi`로 충분하다. 실무에서 대량의 숫자를 파싱하거나 예외를 쓰지 않는 코드에서 만난다.

### 문자열 비교

> `string`은 `==`, `<`, `>`로 바로 비교된다. 사전순(사전식) 비교다.

```cpp
string a = "apple", b = "banana";
if (a < b) { }        // 사전순 → apple이 앞 (참)
if (a == "apple") { } // 내용 비교 (참)
```

> 💡 그래서 `vector<string>`을 `sort`하면 사전순으로 정렬된다.

### string_view — 복사 없는 읽기 전용 문자열 (C++17)

> `string_view`는 문자열을 **복사하지 않고 가리키기만** 하는 읽기 전용 뷰다. (`#include <string_view>`) 매개변수로 쓰면 `string`과 문자열 리터럴을 모두 복사 없이 받고, `substr`도 새 문자열을 만들지 않아 O(1)이다.

```cpp
#include <string_view>
bool startsWithA(string_view s) {        // string, "리터럴" 모두 받음
    return !s.empty() && s[0] == 'A';
}

string_view sv = "hello world";
string_view first = sv.substr(0, 5);     // "hello" (복사 없음)
string owned(first);                     // 필요하면 string으로 복사
```

> ⚠️ `string_view`는 원본을 **가리키기만** 한다. 원본 `string`이 사라지거나 수정되면 댕글링이 된다. 지역 `string`으로 만든 `string_view`를 반환하거나, 임시 문자열(`s + "x"` 등)로 `string_view`를 만들어 보관하면 안 된다.

> 💡 코테에선 `const string&`로 충분하다. "읽기만 하는 문자열" 매개변수로 실무 코드에서 자주 보인다.

### 숫자를 자릿수로 다루기

> 정수의 각 자릿수를 처리할 땐 문자열로 바꾸거나 `% 10`을 반복한다.

```cpp
// 방법 1: 문자열로 변환
int n = 12345;
string s = to_string(n);
int digitSum = 0;
for (char c : s) digitSum += c - '0';   // 자릿수 합 → 15

// 방법 2: 나머지 연산
int m = 12345, sum = 0;
while (m > 0) {
    sum += m % 10;    // 마지막 자리
    m /= 10;          // 자리 하나 제거
}
```

### string과 char의 차이

| | `char` | `string` |
|--|--------|----------|
| 따옴표 | `'a'` (작은따옴표) | `"a"` (큰따옴표) |
| 크기 | 1개 문자 | 여러 문자 |
| 비교 | 아스키 정수로 | 사전순 |

> ⚠️ `'a'`(문자)와 `"a"`(문자열)는 **완전히 다른 타입**이다. `char c = "a";` ❌, `char c = 'a';` ✅.
