# 🔷 C++ 기초 문법 — STL 컨테이너

> **코테 C++의 핵심.** 문제 풀이의 절반은 "어떤 컨테이너를 쓰느냐"로 결정된다. `vector`·`map`·`set`·`priority_queue`를 특히 깊게, 실전 패턴 위주로 다룬다.

---

## vector — 가변 배열 (제일 많이 씀)

> 크기가 자동으로 늘어나는 배열. **C++에서 가장 많이 쓰는 컨테이너.** 파이썬 list라고 보면 된다. (`#include <vector>`)

### 선언과 초기화

```cpp
vector<int> v;                 // 빈 벡터
vector<int> v = {1, 2, 3};     // 초기값
vector<int> v(5);              // 크기 5, 전부 0
vector<int> v(5, 7);           // 크기 5, 전부 7 → {7,7,7,7,7}
vector<int> v2(v);             // v 복사
```

### 주요 연산

```cpp
vector<int> v = {1, 2, 3};

v.push_back(4);      // 끝에 추가 → {1,2,3,4}
v.pop_back();        // 끝 제거    → {1,2,3}
v[0] = 10;           // 인덱싱 수정
cout << v.size();    // 3   (원소 개수)
cout << v.back();    // 3   (마지막 원소)
cout << v.front();   // 10  (첫 원소)
v.clear();           // 전부 삭제 → 빈 벡터
if (v.empty()) { }   // 비었는지 검사
```

| 연산 | 설명 | 복잡도 |
|------|------|--------|
| `push_back(x)` | 끝에 추가 | 평균 O(1) |
| `pop_back()` | 끝 제거 | O(1) |
| `v[i]` | 인덱스 접근 | O(1) |
| `size()` | 개수 | O(1) |
| `back()` / `front()` | 마지막 / 첫 원소 | O(1) |
| `insert(it, x)` | 중간 삽입 | O(n) |
| `erase(it)` | 중간 삭제 | O(n) |

> ⚠️ **빈 벡터에 `back()`/`front()`/`pop_back()`을 호출하면** 정의되지 않은 동작(런타임 에러/쓰레기 값)이다. 항상 `!v.empty()` 확인 후 접근하라.

### 순회

```cpp
vector<int> v = {1, 2, 3};

for (int x : v) cout << x << " ";        // 범위 기반 (복사)
for (int& x : v) x *= 2;                 // 참조 → 원본 수정
for (int i = 0; i < (int)v.size(); i++)  // 인덱스 순회
    cout << v[i];
```

### 크기 조정

```cpp
vector<int> v = {1, 2, 3};
v.resize(5);         // 크기 5로 (늘어난 칸은 0) → {1,2,3,0,0}
v.resize(2);         // 크기 2로 (뒤는 잘림)   → {1,2}
v.assign(4, 9);      // 크기 4, 전부 9로 재설정 → {9,9,9,9}
```

### 2차원 vector (격자 문제 필수)

> `N×M` 크기의 2차원 배열을 만들 때 가장 흔한 관용구.

```cpp
int N = 3, M = 4;
vector<vector<int>> grid(N, vector<int>(M, 0));  // 3×4, 전부 0

grid[1][2] = 5;                  // 접근
cout << grid.size();             // 3  (행 개수)
cout << grid[0].size();          // 4  (열 개수)

// 순회
for (int r = 0; r < N; r++)
    for (int c = 0; c < M; c++)
        cout << grid[r][c];
```

> 💡 `vector<vector<int>> grid(N, vector<int>(M, 0))`을 통째로 외워두면 좋다. 안쪽 `vector<int>(M, 0)`이 "M칸짜리 0 행"이고, 그걸 N개 복제한다.

## pair — 두 값 묶기

> 두 값을 하나로 묶는다. 좌표 `(r, c)`, "값-인덱스" 쌍 등에 필수. (`#include <utility>`, `<vector>`에도 딸려 옴)

```cpp
pair<int, int> p = {1, 2};
cout << p.first << " " << p.second;   // 1 2

p = make_pair(3, 4);                  // make_pair로도 생성
p.first = 10;                         // 수정

auto [x, y] = p;                      // 구조적 바인딩 (C++17) → x = 10, y = 4

// 좌표를 벡터에 담기 (BFS 큐 등에서 흔함)
vector<pair<int,int>> points;
points.push_back({1, 2});
points.emplace_back(3, 4);            // 안에서 바로 생성
```

> 💡 `pair`는 `<`로 비교하면 **first 먼저, 같으면 second** 순으로 비교된다. 그래서 `sort`하면 first 기준 정렬이 공짜다.

```cpp
vector<pair<int,int>> v = {{3,1}, {1,2}, {1,1}};
sort(v.begin(), v.end());   // {1,1}, {1,2}, {3,1}  (first→second 순)
```

### tuple — 세 값 이상 묶기

```cpp
#include <tuple>
tuple<int, int, int> t = {1, 2, 3};
cout << get<0>(t) << get<1>(t) << get<2>(t);   // 1 2 3

// 구조적 바인딩으로 한 번에 꺼내기 (C++17)
auto [a, b, c] = t;   // a=1, b=2, c=3

// 이미 선언된 변수에 넣을 땐 tie
int x, y, z;
tie(x, y, z) = t;     // x=1, y=2, z=3
```

> 💡 구조적 바인딩은 **새 변수를 선언**한다. 이미 있는 변수에 값을 넣으려면 `tie(...)`를, 값 하나만 필요하면 `get<i>(t)`를 쓴다.

## map / unordered_map — 키-값 (≈ 파이썬 dict)

> 키로 값을 저장·조회. **`map`은 키가 정렬**(트리)되고, **`unordered_map`은 해시**(더 빠름, 순서 없음)다.

### 기본 사용

```cpp
#include <map>
map<string, int> age;

age["건석"] = 25;            // 추가/수정
age["철수"] = 30;
cout << age["건석"];         // 25   (접근)
cout << age.size();          // 2

age.erase("철수");           // 삭제
```

### 키 존재 확인 (중요)

```cpp
if (age.count("건석")) { }               // 있으면 1, 없으면 0
if (age.find("건석") != age.end()) { }   // find로도 확인

// 찾은 값을 바로 쓸 땐 초기화문 if (C++17)
if (auto it = age.find("건석"); it != age.end()) {
    cout << it->second;                  // 25
}
```

> ⚠️ **`map`은 없는 키를 `[]`로 접근하면 그 키를 값 0으로 자동 생성한다**(파이썬 KeyError와 다름). 단순 조회에 `[]`를 쓰면 원치 않는 키가 늘어난다. **존재 확인은 `.count()`나 `.find()`로 하라.**
> ```cpp
> map<string,int> m;
> if (m["x"] > 0) { }   // ❌ "x"가 값 0으로 생겨버림
> if (m.count("x")) { } // ✅ 안전
> ```

### 빈도수 세기 (map의 대표 활용)

> 없는 키를 `[]`로 접근하면 0에서 시작하므로, `++`로 바로 카운트할 수 있다. (파이썬 `defaultdict(int)`와 유사)

```cpp
map<string, int> cnt;
vector<string> words = {"a", "b", "a", "a"};
for (const string& w : words) cnt[w]++;   // a:3, b:1
```

### 순회

> **구조적 바인딩(C++17)**으로 키와 값에 이름을 붙여 받는다. 구조적 바인딩 없이 `p.first`(키), `p.second`(값)로 접근해도 된다.

```cpp
for (const auto& [name, value] : age) {
    cout << name << " : " << value << "\n";
}

for (auto& p : age) {                    // 구조적 바인딩 없이
    cout << p.first << " : " << p.second << "\n";
}
// map은 키 오름차순으로 순회됨 (건석 → 철수)
```

> 💡 값을 고치려면 `auto& [name, value]`로 받는다. 키는 `const`라 바꿀 수 없다.

### map vs unordered_map

| | `map` | `unordered_map` |
|--|-------|------------------|
| 내부 | 트리(균형 이진) | 해시 테이블 |
| 순서 | 키 오름차순 정렬 | 순서 없음 |
| 조회/삽입 | O(log n) | 평균 O(1), 최악 O(n) |
| 언제 | 키 정렬·범위가 필요 | 빠른 조회만 필요 |

> 💡 **기본은 `unordered_map`이 빠르다.** 키 정렬 순회가 필요하거나 키가 pair/tuple처럼 해시가 까다로운 타입이면 `map`을 쓴다. (파이썬 dict는 `unordered_map`에 가깝다)

## set — 중복 없는 집합 (≈ 파이썬 set)

> 중복을 허용하지 않고 자동 정렬되는 집합. 원소 존재 확인·중복 제거에 쓴다. (`#include <set>`)

```cpp
#include <set>
set<int> s = {3, 1, 2, 1};   // 중복 제거 → {1, 2, 3} (오름차순)

s.insert(5);                 // 추가 → {1,2,3,5}
s.erase(1);                  // 삭제 → {2,3,5}
if (s.count(2)) { }          // 존재 확인 (0 또는 1)
cout << s.size();            // 3

for (int x : s) cout << x;   // 1 2 3 5  (정렬 순)
```

| | `set` | `unordered_set` | `multiset` |
|--|-------|------------------|------------|
| 정렬 | ✅ 오름차순 | ❌ 없음 | ✅ 오름차순 |
| 중복 | ❌ 불가 | ❌ 불가 | ✅ **허용** |
| 조회 | O(log n) | 평균 O(1) | O(log n) |

> 💡 `set`은 정렬 상태를 유지하므로 `*s.begin()`(최솟값), `*s.rbegin()`(최댓값)을 O(1)에 얻는다. 중복을 허용하며 정렬이 필요하면 `multiset`을 쓴다.

> ⚠️ `set`에서 특정 값을 지울 때 `s.erase(값)`은 그 값을 지우지만, `multiset`에서 `s.erase(값)`은 **같은 값 전부**를 지운다. 하나만 지우려면 `s.erase(s.find(값))`처럼 반복자로 지워야 한다.

## stack / queue / deque

### stack — 후입선출(LIFO)

> 마지막에 넣은 게 먼저 나온다. DFS(반복 버전)·괄호 검사·후위 표기 등에 쓴다. (`#include <stack>`)

```cpp
#include <stack>
stack<int> st;
st.push(1); st.push(2); st.push(3);
cout << st.top();    // 3   (마지막에 넣은 것)
st.pop();            // 3 제거 (pop은 값을 반환 안 함!)
cout << st.top();    // 2
cout << st.size();   // 2
if (st.empty()) { }
```

> ⚠️ **`pop()`은 제거만 하고 값을 반환하지 않는다.** 값이 필요하면 `top()`으로 먼저 읽고 `pop()`으로 지운다(파이썬 `list.pop()`과 다름).
> ```cpp
> int x = st.top(); st.pop();   // 값 꺼내고 제거하는 관용구
> ```

### queue — 선입선출(FIFO)

> 먼저 넣은 게 먼저 나온다. **BFS의 필수 도구.** (`#include <queue>`)

```cpp
#include <queue>
queue<int> q;
q.push(1); q.push(2); q.push(3);
cout << q.front();   // 1   (먼저 넣은 것)
cout << q.back();    // 3   (마지막에 넣은 것)
q.pop();             // 앞(1) 제거
```

### deque — 양쪽 삽입/삭제

> 앞뒤 모두 O(1)로 넣고 뺀다. 슬라이딩 윈도우·0-1 BFS 등에 쓴다. (`#include <deque>`)

```cpp
#include <deque>
deque<int> dq;
dq.push_back(1);     // 뒤에 추가
dq.push_front(0);    // 앞에 추가 → {0, 1}
dq.pop_front();      // 앞 제거
dq.pop_back();       // 뒤 제거
cout << dq[0];       // 인덱스 접근도 가능
```

### BFS 뼈대 (queue 활용)

> 격자 최단거리의 표준 틀. `queue`에 좌표를 넣고, 꺼내며 인접 칸을 탐색한다.

```cpp
int dr[4] = {-1,1,0,0}, dc[4] = {0,0,-1,1};
vector<vector<int>> dist(N, vector<int>(M, -1));   // -1 = 미방문
queue<pair<int,int>> q;

q.push({sr, sc});
dist[sr][sc] = 0;
while (!q.empty()) {
    auto [r, c] = q.front(); q.pop();              // 구조적 바인딩 (C++17)
    for (int d = 0; d < 4; d++) {
        int nr = r + dr[d], nc = c + dc[d];
        if (nr < 0 || nr >= N || nc < 0 || nc >= M) continue;
        if (dist[nr][nc] != -1) continue;          // 이미 방문
        dist[nr][nc] = dist[r][c] + 1;             // 거리 갱신
        q.push({nr, nc});
    }
}
```

> ⚠️ `auto [r, c] = q.front();`는 **복사**라서 바로 `pop()`해도 안전하다. `auto& [r, c] = q.front();`처럼 참조로 받은 뒤 `pop()`하면 지워진 원소를 가리키게 된다.

## priority_queue — 우선순위 큐 (힙)

> 항상 **가장 큰(또는 작은) 값이 top에 오는** 큐. 다익스트라·그리디·"매번 최댓/최솟값 꺼내기"에 필수. (`#include <queue>`)

### 최대 힙 (기본)

```cpp
priority_queue<int> pq;         // 기본: 최대 힙 (top이 최댓값)
pq.push(3); pq.push(1); pq.push(5);
cout << pq.top();    // 5   (최댓값)
pq.pop();            // 5 제거
cout << pq.top();    // 3
```

### 최소 힙 (자주 씀)

> `greater<int>`를 넣으면 top이 최솟값이 된다. 다익스트라에서 이 형태를 쓴다.

```cpp
priority_queue<int, vector<int>, greater<int>> pq;   // 최소 힙
pq.push(3); pq.push(1); pq.push(5);
cout << pq.top();    // 1   (최솟값)
```

| 선언 | top |
|------|-----|
| `priority_queue<int>` | 최댓값 (최대 힙) |
| `priority_queue<int, vector<int>, greater<int>>` | 최솟값 (최소 힙) |

> ⚠️ 최소 힙 선언은 세 인자를 다 써야 한다: `priority_queue<자료형, vector<자료형>, greater<자료형>>`. 자주 틀리는 부분이라 통째로 외우자.

### pair를 담은 우선순위 큐 (다익스트라)

> `pair`를 담으면 **first 기준**으로 정렬된다. 다익스트라는 `{거리, 정점}`을 최소 힙에 넣어, 거리가 가장 짧은 정점을 매번 꺼낸다.

```cpp
// {거리, 정점} 최소 힙 → 거리가 가장 짧은 것이 top
priority_queue<pair<int,int>, vector<pair<int,int>>, greater<pair<int,int>>> pq;

pq.push({0, start});
while (!pq.empty()) {
    auto [d, u] = pq.top();      // {거리, 정점} (C++17 구조적 바인딩, 복사)
    pq.pop();
    // u의 인접 정점 완화(relax)...
}
```

> 💡 거리를 **음수로 넣어 최대 힙을 최소 힙처럼** 쓰는 편법도 있지만(`pq.push({-dist, v})`), `greater`를 쓰는 정석이 실수가 적다.

### 사용자 정의 우선순위 (구조체/람다)

> 정렬 기준이 복잡하면 비교 구조체를 정의한다. (자세한 정렬 비교는 `06`, `08` 참고)

```cpp
struct Cmp {
    bool operator()(const pair<int,int>& a, const pair<int,int>& b) {
        return a.second > b.second;   // second 작은 게 우선 (최소 힙 방향)
    }
};
priority_queue<pair<int,int>, vector<pair<int,int>>, Cmp> pq;
```

> ⚠️ 비교 함수의 부등호 방향이 헷갈린다. **`priority_queue`는 `sort`와 반대로**, 비교가 "참"이면 그 원소가 **뒤로** 간다. `a < b`(오름차순 sort용)를 넣으면 **최대 힙**이 된다.

## 참고

### 컨테이너 선택 가이드

| 필요한 것 | 컨테이너 |
|-----------|----------|
| 순서 있는 가변 배열 | `vector` |
| 키-값 (빠른 조회) | `unordered_map` |
| 키-값 (키 정렬) | `map` |
| 중복 제거 / 존재 확인 | `unordered_set` / `set` |
| LIFO (DFS·괄호) | `stack` |
| FIFO (BFS) | `queue` |
| 양쪽 삽입/삭제 | `deque` |
| 매번 최대/최소 꺼내기 | `priority_queue` |

### emplace vs push

> `push`/`push_back`은 **만들어진 객체를 넣고**, `emplace`/`emplace_back`은 **컨테이너 안에서 바로 생성**해 약간 효율적이다.

```cpp
vector<pair<int,int>> v;
v.push_back({1, 2});      // pair를 만들어 넣음
v.emplace_back(1, 2);     // 안에서 바로 생성 (인자만 전달)
```

> 💡 코테에선 `push_back`으로 충분하다. `emplace_back`은 "인자를 바로 넘겨 생성하는 더 효율적인 버전" 정도로 알아두면 된다.

### 반복자 (iterator)

> 컨테이너 원소를 가리키는 포인터 같은 것. `begin()`(첫 원소), `end()`(마지막 **다음**)를 가리킨다. `sort`·`find` 등 STL 알고리즘이 반복자 구간을 받는다.

```cpp
vector<int> v = {1, 2, 3};
sort(v.begin(), v.end());          // 구간 전체 정렬

auto it = v.begin();               // 첫 원소를 가리킴
cout << *it;                       // 1  (역참조로 값)

vector<int>::iterator it2 = find(v.begin(), v.end(), 2);
if (it2 != v.end()) { /* 찾음 */ } // end면 못 찾은 것
```

> 💡 대부분은 **범위 기반 for**로 반복자를 감출 수 있다. 반복자는 `sort`·`lower_bound`·`erase` 같은 함수에 구간을 넘길 때 주로 만난다.
