# 🔷 01. C++ 시작하기

> C++ 프로그램의 기본 구조와 컴파일·실행 방법, 그리고 화면에 출력하고 키보드로 입력받는 **표준 입출력(`cin`/`cout`)**의 기초를 다룬다.
>
> 💡 C++은 C 언어를 바탕으로 **객체 지향**과 **일반화 프로그래밍(템플릿)**을 더한 언어다. 메모리를 직접 다루는 저수준 제어와 STL 같은 고수준 라이브러리를 함께 쓸 수 있어서, 성능이 중요한 게임·시스템·임베디드·알고리즘 분야에서 널리 쓰인다.

---

## 프로그램 구조

### 기본 골격

> C++은 **컴파일 언어**다. 소스(`.cpp`)를 기계어로 번역(컴파일)한 뒤 실행한다.

```cpp
#include <iostream>   // 입출력 기능 가져오기

using namespace std;  // std:: 생략 (작은 예제용, 16장 참고)

int main() {          // 프로그램의 시작점
    cout << "Hello, World!" << "\n";
    return 0;         // 정상 종료
}
```

| 구성 요소 | 의미 |
|-----------|------|
| `#include <iostream>` | 입출력 라이브러리 포함 (전처리) |
| `using namespace std;` | `std::` 생략 가능하게 함 |
| `int main()` | 실행이 시작되는 함수 (필수) |
| `;` | 모든 문장의 끝 (필수) |
| `return 0;` | main 종료, `0` = 정상 |

컴파일 & 실행 (터미널):
```bash
g++ -std=c++17 -O2 -Wall -Wextra sol.cpp -o sol   # C++17로 컴파일 (경고 켜기)
./sol                                             # 실행
```

> 💡 `-Wall -Wextra`는 **경고를 켜는 옵션**이다. `if (x = 5)`, 초기화 안 한 변수, `size_t`와 `int` 비교 같은 실수를 컴파일러가 미리 알려준다. 독학할 땐 항상 켜두자. (Visual Studio의 MSVC라면 `cl /std:c++17 /EHsc /W4 sol.cpp`)

## 주석 · 문장 · 블록

```cpp
// 한 줄 주석: // 뒤는 무시된다

/* 여러 줄 주석
   이 사이는 전부 무시된다 */

int x = 5;           // 문장(statement)은 세미콜론으로 끝난다
{                    // 중괄호 { } = 블록: 여러 문장을 하나로 묶는다
    int y = x + 1;   // 블록 안에서 선언한 변수는 블록 밖에서 쓸 수 없다
}
```

> 💡 C++은 들여쓰기나 줄바꿈으로 문법을 구분하지 않는다(파이썬과 다름). 문장의 끝은 `;`, 블록의 범위는 `{ }`가 정한다. 들여쓰기는 사람이 읽기 위한 것이다.

## 입력 (cin)

> `cin`에 `>>`로 입력을 받는다. 변수 타입에 맞춰 **알아서 변환**해준다. 공백·줄바꿈을 기준으로 값을 끊는다.

```cpp
int n;
cin >> n;              // 정수 하나

int a, b;
cin >> a >> b;         // 공백/줄바꿈으로 구분된 두 값

int arr[100], k;
cin >> k;
for (int i = 0; i < k; i++) cin >> arr[i];   // k개 반복 입력
```

> ⚠️ `cin >>`은 **공백·줄바꿈에서 끊는다.** 공백 포함 문자열은 첫 단어만 읽힌다.
> ```cpp
> string s;
> cin >> s;   // "hello world" 입력 → s = "hello" (world 누락)
> ```

공백 포함 **한 줄 전체**는 `getline`으로 받는다.
```cpp
string line;
getline(cin, line);    // 줄 전체 → "hello world"
```

> ⚠️ **`cin >>` 다음에 `getline`을 쓰는 함정.** `cin >> n`은 줄바꿈을 버퍼에 남긴다. 곧바로 `getline`하면 **빈 줄**이 먼저 읽힌다. 사이에 `cin.ignore()`를 넣어 남은 줄바꿈을 버려라. (자세한 건 [14. 입출력 스트림](14.cpp_stream_io.md) 참고)

EOF까지 계속 읽기 (입력 개수가 안 주어질 때):
```cpp
int x;
while (cin >> x) {     // 더 읽을 게 없으면 false → 종료
    // x 처리
}
```

## 출력 (cout)

> `cout`에 `<<`로 값을 흘려보낸다. `<<`는 여러 개를 **연달아** 이어 쓸 수 있다.

```cpp
cout << "이름: " << name << ", 나이: " << age << "\n";
cout << 1 + 2 << "\n";   // 3 (식도 바로 출력)
```

### 실수 출력 형식 (`<iomanip>`)

> "소수점 아래 N자리까지" 출력해야 할 때가 많다. `fixed`와 `setprecision`을 함께 쓴다.

```cpp
#include <iomanip>
double d = 3.14159265;

cout << fixed << setprecision(2) << d << "\n";   // 3.14
cout << fixed << setprecision(6) << d << "\n";   // 3.141593
```

| 조작자 | 의미 |
|--------|------|
| `fixed` | 고정 소수점 표기 |
| `setprecision(n)` | (fixed와 함께) 소수점 아래 n자리 |
| `setw(n)` | 출력 폭 n칸 확보 (오른쪽 정렬) |

> ⚠️ `setprecision`만 쓰면 "**전체** 유효숫자"가 되고, `fixed`와 함께 써야 "소수점 **아래** 자리"가 된다. 보통 `fixed << setprecision(n)` 세트로 기억하자.

> 💡 **`endl`과 `"\n"`의 차이.** 둘 다 줄을 바꾸지만 `endl`은 출력 버퍼를 **즉시 비우는(flush)** 동작까지 한다. 출력이 많으면 `endl`이 눈에 띄게 느려지므로, 평소엔 `"\n"`을 쓰고 즉시 화면에 보여야 할 때만 `endl`을 쓴다. 많은 양을 빠르게 입출력하는 설정은 [부록 A. 코딩테스트 준비](A.cpp_coding_test.md)에 있다.
