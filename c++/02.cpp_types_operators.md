## 자료형

### 기본 자료형

> C++은 **정적 타입** 언어다. 변수를 쓰기 전에 **타입을 명시해 선언**해야 한다.

```cpp
int    age  = 25;      // 정수
long long big = 10000000000LL;  // 큰 정수 (뒤에 LL)
double pi   = 3.14;    // 실수
char   grade = 'A';    // 문자 1개 (작은따옴표!)
bool   isOk = true;    // 참/거짓
string name = "건석";  // 문자열 (#include <string>)
```

| 타입 | 용도 | 크기 | 범위(대략) |
|------|------|------|------------|
| `int` | 기본 정수 | 4 byte | 약 ±2.1×10⁹ (21억) |
| `long long` | 큰 정수 | 8 byte | 약 ±9.2×10¹⁸ |
| `unsigned int` | 음수 없는 정수 | 4 byte | 0 ~ 약 42억 |
| `double` | 실수 | 8 byte | 유효숫자 ~15자리 |
| `char` | 문자 1개 | 1 byte | -128 ~ 127 |
| `bool` | 참/거짓 | 1 byte | `true` / `false` |
| `string` | 문자열 | 가변 | — |

> ⚠️ **`long`은 쓰지 마라.** `long`은 Linux(채점 서버)에선 8 byte지만 **Windows에선 4 byte**(`int`와 같음)다. 내 PC에선 맞는데 서버에선 틀리는(또는 그 반대) 원인이 된다. 큰 정수는 항상 `long long`.

> 💡 각 타입의 최댓값·최솟값은 상수로 얻을 수 있다.
> ```cpp
> #include <climits>   // INT_MAX, INT_MIN, LLONG_MAX ...
> #include <limits>    // numeric_limits
> cout << INT_MAX << "\n";                         // 2147483647
> cout << LLONG_MAX << "\n";                       // 9223372036854775807
> cout << numeric_limits<int>::max() << "\n";      // 2147483647 (C++ 방식)
> ```

### ⚠️ 정수 오버플로 — 코테 1순위 실수

> 파이썬 `int`는 무한히 커지지만, C++ `int`는 약 **21억**에서 넘쳐 **값이 망가진다**(음수 등 쓰레기 값). 표준상으로는 **정의되지 않은 동작(UB)**이라 어떤 결과가 나올지 보장도 없다. 합·곱으로 큰 수가 나오는 문제는 반드시 `long long`을 써야 한다.

```cpp
int a = 2'000'000'000;
int b = a + a;                    // ❌ 오버플로 → 쓰레기 값
long long c = (long long)a + a;   // ✅ 4000000000 정상
```

> 💡 **판단 기준:** "N개(최대 10⁵)의 수, 각 10⁹ 이하"의 **합**이면 결과가 10¹⁴까지 간다 → `int`(±21억) 초과 → `long long` 필수. "두 수의 곱"도 각각 10⁵만 넘으면 10¹⁰이라 `int` 초과다.

> ⚠️ **곱셈 중간 오버플로 함정.** 아래처럼 `int`끼리 곱하면 **결과를 `long long`에 담아도** 곱 계산 자체가 이미 `int`로 되어 넘친다.
> ```cpp
> int x = 100000, y = 100000;
> long long z = x * y;              // ❌ x*y가 int로 계산됨 → 오버플로
> long long z2 = (long long)x * y;  // ✅ 한쪽을 먼저 캐스팅
> ```

> 💡 숫자 리터럴에 `'`(작은따옴표)를 넣어 자릿수를 끊어 읽을 수 있다 (C++14). `2'000'000'000`처럼. 값에는 영향 없고 가독성만 좋아진다.

### auto 타입 추론

> `auto`를 쓰면 초기값을 보고 타입을 **자동 추론**한다. 긴 타입 이름(반복자 등)을 줄일 때 특히 유용하다.

```cpp
auto w = 5;        // int
auto d = 3.14;     // double
auto s = "hi";     // const char* (주의: string 아님)

vector<int> v = {1, 2, 3};
for (auto x : v) { }   // x는 int로 추론
```

> 💡 C++17부터 `pair`·`tuple`·구조체를 **구조적 바인딩**으로 한 번에 풀어 받을 수 있다. `auto [a, b] = p;` (자세한 건 [06. 컨테이너](06.cpp_containers.md) 참고)

### 초기화 방식

```cpp
int x = 5;       // 복사 초기화
int y{5};        // 중괄호 초기화 (좁힘 변환 방지)
int z;           // ⚠️ 초기화 안 함 → 지역변수는 쓰레기 값!
int arr[5] = {}; // 배열 전부 0
```

> ⚠️ C++ 지역 변수는 초기화하지 않으면 **쓰레기 값**이 들어 있다(파이썬엔 없던 상태). 카운터·합 변수는 반드시 `= 0`으로 시작하라.

### 타입 별칭 (using / typedef)

> 긴 타입 이름에 **짧은 별명**을 붙인다. 코테 코드 맨 위에 자주 보인다.

```cpp
using ll = long long;               // C++11 방식 (권장)
typedef long long ll;               // C 방식 (같은 의미, 옛 코드에서 보임)
using pii = pair<int, int>;
using Grid = vector<vector<int>>;

ll big = 1e18;
vector<pii> edges;
Grid g(3, vector<int>(4));
```

> 💡 옛 코드의 `#define ll long long`도 같은 목적이지만, 매크로는 단순 텍스트 치환이라 예상 못 한 곳까지 바뀔 수 있다. `using`을 쓰자([14. 프로그램 구조](14.cpp_program_structure.md) 참고).

### 열거형 (enum class)

> "정해진 몇 개의 값 중 하나"를 이름으로 표현한다. 숫자 `0, 1, 2, 3` 대신 `Dir::Up`처럼 의미가 드러난다.

```cpp
enum class Dir { Up, Down, Left, Right };   // C++11: 값은 차례로 0, 1, 2, 3

Dir d = Dir::Left;                          // 반드시 Dir:: 를 붙인다
switch (d) {
    case Dir::Up:   /* ... */ break;
    case Dir::Left: /* ... */ break;
    default: break;
}
int idx = static_cast<int>(d);              // 2  (정수가 필요하면 명시적 변환)
```

| | 옛 `enum` | `enum class` (C++11) |
|--|-----------|----------------------|
| 사용 | `RED` | `Color::Red` |
| 이름 범위 | 바깥으로 샌다 → 다른 enum과 이름이 겹치면 에러 | enum 안에 갇힘 |
| `int`로 자동 변환 | 된다 (`int n = RED;`) | 안 된다 (`static_cast` 필요) |

> 💡 새 코드는 `enum class`를 쓴다. 다만 방향 배열 인덱스(`dr[d]`)처럼 정수로 바로 쓰고 싶다면 코테에선 그냥 `int`나 옛 `enum`이 편하다.

## const 상수

> 값이 바뀌지 않는 상수는 `const`로 선언한다. 배열 크기·좌표 경계 등에 쓴다.

```cpp
const int MAX = 1'000'000;
const int INF = 1e9;          // 큰 수 (도달 불가 거리의 초기값 등)
const long long LINF = 1e18;  // long long용 무한대
```

> 💡 `INF`를 `INT_MAX`(약 21억)로 두면 `INF + INF`가 오버플로한다. 더하기 연산이 섞이는 최단거리 문제는 `1e9` 정도로 여유 있게 잡는 게 안전하다.

> 💡 **`constexpr`** 는 "**컴파일 시점에** 값이 정해지는 상수"다(C++11). 배열 크기처럼 컴파일러가 미리 알아야 하는 값에 쓴다. 상수 값이 리터럴이면 `const`와 사실상 같지만, 의도를 더 분명히 보여준다.
> ```cpp
> constexpr int MAXN = 100'001;
> int cnt[MAXN];                 // 배열 크기로 사용 가능
> ```

## 연산자

### 산술 연산자

| 연산자 | 의미 | 예시 | 결과 |
|--------|------|------|------|
| `+` `-` `*` | 덧·뺄·곱 | `3 * 2` | `6` |
| `/` | 나눗셈 | `7 / 2` | `3` ⚠️ |
| `%` | 나머지 | `7 % 2` | `1` |
| `++` `--` | 증가·감소 | `x++` | `x = x + 1` |

> ⚠️ **정수끼리 `/`는 몫만 남기고 소수부를 버린다(정수 나눗셈).** 파이썬 `//`에 해당한다.
> ```cpp
> 7 / 2      // 3    (파이썬 / 는 3.5)
> 7.0 / 2    // 3.5  (한쪽이 실수면 실수 나눗셈)
> 7 % 2      // 1
> ```

> 💡 **`i++`와 `++i`의 차이.** 단독으로 쓰면(`i++;`, `for`의 증감식) 결과가 같다. 식 안에서 값을 쓸 때만 다르다.
> ```cpp
> int i = 5;
> int a = i++;   // a = 5, i = 6  (후위: 쓰고 나서 증가)
> int b = ++i;   // b = 7, i = 7  (전위: 증가하고 나서 사용)
> ```
> 헷갈리면 증감은 한 줄에 따로 쓰자. `v[i++] = i;`처럼 한 식에서 같은 변수를 바꾸고 읽는 코드는 피하라.

> ⚠️ **음수 나머지 주의.** C++에서 `-7 % 3`은 `-1`이다(파이썬은 `2`). 나머지를 항상 양수로 만들려면 `((a % m) + m) % m` 관용구를 쓴다.
> ```cpp
> -7 % 3            // -1
> ((-7 % 3) + 3) % 3   // 2  (항상 양수 나머지)
> ```

### 비교 · 논리 연산자

비교 연산자 `==` `!=` `>` `<` `>=` `<=` — 결과는 `bool`. 파이썬과 동일.

논리 연산자:

| 연산자 | 의미 | 파이썬 대응 | 예시 |
|--------|------|-------------|------|
| `&&` | 그리고 | `and` | `a > 0 && b > 0` |
| `\|\|` | 또는 | `or` | `a > 0 \|\| b > 0` |
| `!` | 부정 | `not` | `!flag` |

> ⚠️ C++ 논리 연산자는 기호(`&&` `\|\|` `!`)다. 파이썬의 `and`/`or`/`not` 키워드 습관이 남으면 컴파일 에러가 난다. (앞이 결과를 결정하면 뒤를 평가 안 하는 **단축 평가**는 파이썬과 동일)

복합 대입 연산자 `+=` `-=` `*=` `/=` `%=` — 파이썬과 동일.

### 연산자 우선순위

| 우선순위 | 연산자 |
|----------|--------|
| 높음 | `!`, `++`, `--`, 단항 `-` |
| | `*`, `/`, `%` |
| | `+`, `-` |
| | `<<`, `>>` (시프트) |
| | `<`, `<=`, `>`, `>=` |
| | `==`, `!=` |
| | `&` → `^` → `\|` (비트 연산) |
| | `&&` |
| | `\|\|` |
| 낮음 | `?:`, `=`, `+=` 등 대입 |

> ⚠️ 헷갈리면 괄호로 묶어라. 대표적인 함정 두 가지:
> ```cpp
> if (x & 1 == 0)     // ❌ & 가 == 보다 낮음 → x & (1 == 0) → 항상 0
> if ((x & 1) == 0)   // ✅ 짝수 판정
>
> 1 << n - 1          // 1 << (n - 1)  ← 시프트가 +, - 보다 낮음
> (1 << n) - 1        // n개 비트가 전부 1인 마스크를 원했다면 괄호 필수
> ```

## 비트 연산 (코테 활용)

> 정수를 이진수로 보고 비트 단위로 처리한다. 집합 표현·홀짝 판정·2의 거듭제곱 등에 쓴다.

| 연산자 | 의미 | 예시 | 결과 |
|--------|------|------|------|
| `&` | AND | `6 & 3` | `2` |
| `\|` | OR | `6 \| 3` | `7` |
| `^` | XOR | `6 ^ 3` | `5` |
| `<<` | 왼쪽 시프트 | `1 << 4` | `16` (2⁴) |
| `>>` | 오른쪽 시프트 | `16 >> 2` | `4` |

```cpp
if (x & 1) { }          // 홀수 판정 (마지막 비트가 1)
int half = x >> 1;      // x / 2  (2로 나눈 몫)
int pow2 = 1 << k;      // 2의 k제곱

// 비트마스크: i번째 원소 포함 여부
int mask = 0;
mask |= (1 << i);       // i번째 비트 켜기
if (mask & (1 << i)) {} // i번째 비트 확인
```

> 💡 `1 << k`에서 `k`가 31 이상이면 `int`를 넘친다. 큰 시프트는 `1LL << k`로 `long long` 시프트를 써야 한다.

## 수학 함수 (`<cmath>`)

```cpp
#include <cmath>
abs(-5);         // 5      (long long도 abs로 OK)
sqrt(16.0);      // 4.0
pow(2, 10);      // 1024.0 (⚠️ double 반환)
floor(2.7);      // 2.0    내림
ceil(2.1);       // 3.0    올림
round(2.5);      // 3.0    반올림 (0에서 먼 쪽)
```

> ⚠️ **`pow`는 정수 거듭제곱에 쓰지 마라.** 결과가 `double`이라 `(int)pow(10, 2)`가 환경에 따라 `99`가 될 수 있고, `long long` 범위의 큰 값은 정밀도가 모자라 틀린다. 정수 거듭제곱은 반복문으로 곱하거나, 비트 연산(`1LL << k`)을 써라.

> 💡 **정수 올림 나눗셈** (양수 `a`, `b`에서 `⌈a / b⌉`): `ceil((double)a / b)` 대신 정수 연산만 쓰는 관용구가 안전하다.
> ```cpp
> int q = (a + b - 1) / b;   // 7, 2 → 4
> ```

> ⚠️ **실수는 `==`로 비교하지 마라.** `0.1 + 0.2 == 0.3`은 거짓이다(부동소수 오차). 아주 작은 오차(`eps`)를 허용해 비교한다.
> ```cpp
> const double EPS = 1e-9;
> if (fabs(a - b) < EPS) { }   // a와 b가 "같다"
> ```
