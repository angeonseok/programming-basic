# 🔷 11. 순차 컨테이너

> **STL(Standard Template Library)**은 C++ 표준 라이브러리의 핵심으로, 자료구조(**컨테이너**), 컨테이너를 훑는 **반복자**, 정렬·탐색 같은 **알고리즘**으로 이루어진다.
>
> 이 장에서는 원소를 **넣은 순서대로** 관리하는 **순차 컨테이너**(`vector`, `deque`, `list`)와, 이를 감싸 넣고 빼는 방식을 제한한 **컨테이너 어댑터**(`stack`, `queue`, `priority_queue`)를 다룬다.

---

## vector — 가변 배열

> 크기가 자동으로 늘어나는 배열. **C++에서 가장 많이 쓰는 컨테이너.** 파이썬 list라고 보면 된다. (`#include <vector>`)

### 선언과 초기화

```cpp
vector<int> v1;                // 빈 벡터
vector<int> v2 = {1, 2, 3};    // 초기값
vector<int> v3(5);             // 크기 5, 전부 0
vector<int> v4(5, 7);          // 크기 5, 전부 7 → {7,7,7,7,7}
vector<int> v5(v2);            // v2 복사
```

> ⚠️ **소괄호와 중괄호는 뜻이 다르다.** `vector<int> a(5);`는 "크기 5(전부 0)", `vector<int> b{5};`는 "원소 `5` 하나"다. 크기를 정할 땐 소괄호를 쓴다.

### 주요 연산

```cpp
vector<int> v = {1, 2, 3};

v.push_back(4);      // 끝에 추가 → {1,2,3,4}
v.pop_back();        // 끝 제거    → {1,2,3}
v[0] = 10;           // 인덱싱 수정
cout << v.size();    // 3   (원소 개수)
cout << v.back();    // 3   (마지막 원소)
cout << v.front();   // 10  (첫 원소)
v.clear();           // 전부 삭제 → 빈 벡터
if (v.empty()) { }   // 비었는지 검사
```

| 연산 | 설명 | 복잡도 |
|------|------|--------|
| `push_back(x)` | 끝에 추가 | 평균 O(1) |
| `pop_back()` | 끝 제거 | O(1) |
| `v[i]` | 인덱스 접근 | O(1) |
| `size()` | 개수 | O(1) |
| `back()` / `front()` | 마지막 / 첫 원소 | O(1) |
| `insert(it, x)` | 중간 삽입 | O(n) |
| `erase(it)` | 중간 삭제 | O(n) |

> ⚠️ **빈 벡터에 `back()`/`front()`/`pop_back()`을 호출하면** 정의되지 않은 동작(런타임 에러/쓰레기 값)이다. 항상 `!v.empty()` 확인 후 접근하라.

### 순회

```cpp
vector<int> v = {1, 2, 3};

for (int x : v) cout << x << " ";        // 범위 기반 (복사)
for (int& x : v) x *= 2;                 // 참조 → 원본 수정
for (int i = 0; i < (int)v.size(); i++)  // 인덱스 순회
    cout << v[i];
```

### 크기 조정

```cpp
vector<int> v = {1, 2, 3};
v.resize(5);         // 크기 5로 (늘어난 칸은 0) → {1,2,3,0,0}
v.resize(2);         // 크기 2로 (뒤는 잘림)   → {1,2}
v.assign(4, 9);      // 크기 4, 전부 9로 재설정 → {9,9,9,9}
```

### 2차원 vector

> `N×M` 크기의 2차원 배열을 만들 때 가장 흔한 관용구.

```cpp
int N = 3, M = 4;
vector<vector<int>> grid(N, vector<int>(M, 0));  // 3×4, 전부 0

grid[1][2] = 5;                  // 접근
cout << grid.size();             // 3  (행 개수)
cout << grid[0].size();          // 4  (열 개수)

// 순회
for (int r = 0; r < N; r++)
    for (int c = 0; c < M; c++)
        cout << grid[r][c];
```

> 💡 `vector<vector<int>> grid(N, vector<int>(M, 0))`을 통째로 외워두면 좋다. 안쪽 `vector<int>(M, 0)`이 "M칸짜리 0 행"이고, 그걸 N개 복제한다.

## deque — 양쪽 삽입/삭제

> 앞뒤 모두 O(1)로 넣고 뺀다. 슬라이딩 윈도우·0-1 BFS 등에 쓴다. (`#include <deque>`)

```cpp
#include <deque>
deque<int> dq;
dq.push_back(1);     // 뒤에 추가
dq.push_front(0);    // 앞에 추가 → {0, 1}
dq.pop_front();      // 앞 제거
dq.pop_back();       // 뒤 제거
cout << dq[0];       // 인덱스 접근도 가능
```

## 그 밖의 순차 컨테이너

| 컨테이너 | 특징 | 언제 |
|----------|------|------|
| `array<T, N>` | 크기 고정 배열 ([05. 배열과 문자열](05.cpp_array_string.md)) | 크기가 컴파일 시 정해질 때 |
| `vector<T>` | 끝에서 추가·삭제 O(1), 임의 접근 O(1) | **기본 선택** |
| `deque<T>` | 앞·뒤 모두 추가·삭제 O(1), 임의 접근 O(1) | 양쪽 끝을 다룰 때 |
| `list<T>` | 이중 연결 리스트. 위치를 알면 어디서든 삽입·삭제 O(1), 임의 접근 불가 | 중간 삽입·삭제가 아주 잦을 때 |

```cpp
#include <list>
list<int> lst = {1, 2, 3};
lst.push_front(0);                 // {0, 1, 2, 3}
auto it = next(lst.begin(), 2);    // 앞에서 2칸 이동한 위치 (lst[2] 같은 인덱스 접근은 불가)
lst.insert(it, 9);                 // {0, 1, 9, 2, 3}  (위치를 알면 O(1))
```

> 💡 대부분의 경우 `vector`가 가장 빠르다. 메모리가 연속이라 CPU 캐시를 잘 활용하기 때문에, 이론상 `list`가 유리해 보이는 경우에도 `vector`가 이기는 일이 많다. 확실한 이유가 없으면 `vector`부터 쓰자.

## pair — 두 값 묶기

> 두 값을 하나로 묶는다. 좌표 `(r, c)`, "값-인덱스" 쌍 등에 필수. (`#include <utility>`, `<vector>`에도 딸려 옴)

```cpp
pair<int, int> p = {1, 2};
cout << p.first << " " << p.second;   // 1 2

p = make_pair(3, 4);                  // make_pair로도 생성
p.first = 10;                         // 수정

auto [x, y] = p;                      // 구조적 바인딩 (C++17) → x = 10, y = 4

// 좌표를 벡터에 담기 (BFS 큐 등에서 흔함)
vector<pair<int,int>> points;
points.push_back({1, 2});
points.emplace_back(3, 4);            // 안에서 바로 생성
```

> 💡 `pair`는 `<`로 비교하면 **first 먼저, 같으면 second** 순으로 비교된다. 그래서 `sort`하면 first 기준 정렬이 공짜다.

```cpp
vector<pair<int,int>> v = {{3,1}, {1,2}, {1,1}};
sort(v.begin(), v.end());   // {1,1}, {1,2}, {3,1}  (first→second 순)
```

### tuple — 세 값 이상 묶기

```cpp
#include <tuple>
tuple<int, int, int> t = {1, 2, 3};
cout << get<0>(t) << get<1>(t) << get<2>(t);   // 1 2 3

// 구조적 바인딩으로 한 번에 꺼내기 (C++17)
auto [a, b, c] = t;   // a=1, b=2, c=3

// 이미 선언된 변수에 넣을 땐 tie
int x, y, z;
tie(x, y, z) = t;     // x=1, y=2, z=3
```

> 💡 구조적 바인딩은 **새 변수를 선언**한다. 이미 있는 변수에 값을 넣으려면 `tie(...)`를, 값 하나만 필요하면 `get<i>(t)`를 쓴다.

## 컨테이너 어댑터 — stack · queue

> **컨테이너 어댑터**는 `deque`·`vector` 같은 컨테이너를 감싸서 **정해진 방식으로만** 넣고 빼게 만든 것이다. 반복자가 없어서 중간 원소에는 접근할 수 없다.

### stack — 후입선출(LIFO)

> 마지막에 넣은 게 먼저 나온다. DFS(반복 버전)·괄호 검사·후위 표기 등에 쓴다. (`#include <stack>`)

```cpp
#include <stack>
stack<int> st;
st.push(1); st.push(2); st.push(3);
cout << st.top();    // 3   (마지막에 넣은 것)
st.pop();            // 3 제거 (pop은 값을 반환 안 함!)
cout << st.top();    // 2
cout << st.size();   // 2
if (st.empty()) { }
```

> ⚠️ **`pop()`은 제거만 하고 값을 반환하지 않는다.** 값이 필요하면 `top()`으로 먼저 읽고 `pop()`으로 지운다(파이썬 `list.pop()`과 다름).
> ```cpp
> int x = st.top(); st.pop();   // 값 꺼내고 제거하는 관용구
> ```

### queue — 선입선출(FIFO)

> 먼저 넣은 게 먼저 나온다. **BFS의 필수 도구.** (`#include <queue>`)

```cpp
#include <queue>
queue<int> q;
q.push(1); q.push(2); q.push(3);
cout << q.front();   // 1   (먼저 넣은 것)
cout << q.back();    // 3   (마지막에 넣은 것)
q.pop();             // 앞(1) 제거
```

## priority_queue — 우선순위 큐 (힙)

> 항상 **가장 큰(또는 작은) 값이 top에 오는** 큐. 다익스트라·그리디·"매번 최댓/최솟값 꺼내기"에 필수. (`#include <queue>`)

### 최대 힙 (기본)

```cpp
priority_queue<int> pq;         // 기본: 최대 힙 (top이 최댓값)
pq.push(3); pq.push(1); pq.push(5);
cout << pq.top();    // 5   (최댓값)
pq.pop();            // 5 제거
cout << pq.top();    // 3
```

### 최소 힙

> `greater<int>`를 넣으면 top이 최솟값이 된다. 다익스트라에서 이 형태를 쓴다.

```cpp
priority_queue<int, vector<int>, greater<int>> pq;   // 최소 힙
pq.push(3); pq.push(1); pq.push(5);
cout << pq.top();    // 1   (최솟값)
```

| 선언 | top |
|------|-----|
| `priority_queue<int>` | 최댓값 (최대 힙) |
| `priority_queue<int, vector<int>, greater<int>>` | 최솟값 (최소 힙) |

> ⚠️ 최소 힙 선언은 세 인자를 다 써야 한다: `priority_queue<자료형, vector<자료형>, greater<자료형>>`. 자주 틀리는 부분이라 통째로 외우자.

### 사용자 정의 우선순위 (구조체/람다)

> 정렬 기준이 복잡하면 비교 구조체를 정의한다. (자세한 정렬 비교는 [13. STL 알고리즘](13.cpp_algorithm.md), [08. 클래스](08.cpp_class.md) 참고)

```cpp
struct Cmp {
    bool operator()(const pair<int,int>& a, const pair<int,int>& b) const {
        return a.second > b.second;   // second 작은 게 우선 (최소 힙 방향)
    }
};
priority_queue<pair<int,int>, vector<pair<int,int>>, Cmp> pq;
```

> 💡 `operator()` 뒤의 **`const`를 붙이는 습관**을 들이자. 같은 비교 구조체를 `set<T, Cmp>`에 쓰면 `const`가 없을 때 컴파일 에러가 난다.

람다로도 쓸 수 있다. 람다는 타입 이름이 없어서 `decltype`으로 타입을 꺼내 넘긴다.

```cpp
auto cmp = [](const pair<int,int>& a, const pair<int,int>& b) { return a.second > b.second; };
priority_queue<pair<int,int>, vector<pair<int,int>>, decltype(cmp)> pq(cmp);   // 생성자에도 cmp 전달
```

> ⚠️ 비교 함수의 부등호 방향이 헷갈린다. **`priority_queue`는 `sort`와 반대로**, 비교가 "참"이면 그 원소가 **뒤로** 간다. `a < b`(오름차순 sort용)를 넣으면 **최대 힙**이 된다.

## 참고

### emplace vs push

> `push`/`push_back`은 **만들어진 객체를 넣고**, `emplace`/`emplace_back`은 **컨테이너 안에서 바로 생성**해 약간 효율적이다.

```cpp
vector<pair<int,int>> v;
v.push_back({1, 2});      // pair를 만들어 넣음
v.emplace_back(1, 2);     // 안에서 바로 생성 (인자만 전달)
```

> 💡 대부분은 `push_back`으로 충분하다. `emplace_back`은 "인자를 바로 넘겨 생성하는 더 효율적인 버전" 정도로 알아두면 된다.
