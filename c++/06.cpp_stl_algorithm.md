# 🔷 C++ 기초 문법 — STL 알고리즘

> `<algorithm>`·`<numeric>`이 제공하는 함수들. **정렬·비교 기준·이분탐색·순열**은 코테에서 매 문제 나온다고 봐도 된다. 여기가 실전의 핵심이다.

> 대부분 함수는 **반복자 구간 `[begin, end)`**를 받는다. `end`는 마지막 원소의 **다음**을 가리킨다는 점을 기억하자.

---

## 정렬 (sort) — 가장 많이 씀

### 기본 정렬

> `<algorithm>`의 `sort`는 구간을 **오름차순**으로 정렬한다. 평균 O(n log n).

```cpp
#include <algorithm>
vector<int> v = {3, 1, 2};
sort(v.begin(), v.end());              // 오름차순 → {1, 2, 3}

int arr[5] = {5, 2, 4, 1, 3};
sort(arr, arr + 5);                    // C 배열도 정렬 → {1,2,3,4,5}
```

### 내림차순 정렬

```cpp
sort(v.begin(), v.end(), greater<int>());   // 내림차순 → {3, 2, 1}

// 또는 정렬 후 뒤집기
sort(v.begin(), v.end());
reverse(v.begin(), v.end());
```

### 사용자 정의 비교 (람다) — 필수

> 세 번째 인자로 **비교 함수**를 넘겨 정렬 기준을 바꾼다. `cmp(a, b)`가 **참이면 `a`가 `b`보다 앞**에 온다.

```cpp
vector<int> v = {3, 1, 2};

// 내림차순
sort(v.begin(), v.end(), [](int a, int b) {
    return a > b;    // a가 b보다 크면 a가 앞 → 내림차순
});
```

### 다중 기준 정렬 (코테 단골)

> "첫째 기준으로 정렬하되, 같으면 둘째 기준으로" — pair·구조체 정렬의 핵심 패턴.

```cpp
vector<pair<int,int>> v = {{1,3}, {1,1}, {2,2}};

sort(v.begin(), v.end(), [](const pair<int,int>& a, const pair<int,int>& b) {
    if (a.first != b.first) return a.first < b.first;  // 1순위: first 오름차순
    return a.second > b.second;                        // 2순위: second 내림차순
});
// 결과: {1,3}, {1,1}, {2,2}
```

> ⚠️ **비교 함수는 "같을 때 false"를 반환해야 한다**(strict weak ordering). `a.first <= b.first`처럼 `<=`를 쓰면 같은 값에서 참이 되어 **런타임 에러**가 날 수 있다. 반드시 `<`(또는 `>`)만 쓰고, 같으면 다음 기준으로 넘겨라.

> 💡 `pair`는 비교 함수 없이 `sort`만 해도 **first→second** 순으로 정렬된다(`05` 참고). 기본 순서면 비교 함수가 필요 없다.

### stable_sort — 안정 정렬

> 같은 값의 **원래 순서를 보존**한다. "동점이면 입력 순서 유지"가 필요할 때 쓴다.

```cpp
stable_sort(v.begin(), v.end(), cmp);   // 같은 값끼리 입력 순서 유지
```

### 부분 정렬 (nth_element / partial_sort)

> 상위 k개만 필요할 때 전체 정렬보다 빠르다.

```cpp
// k번째로 작은 원소만 제자리에 (그 앞은 더 작음, 뒤는 더 큼)
nth_element(v.begin(), v.begin() + k, v.end());

// 앞 k개만 정렬
partial_sort(v.begin(), v.begin() + k, v.end());
```

## 이분 탐색 (lower_bound / upper_bound)

> **정렬된** 구간에서 O(log n)에 위치를 찾는다. "정렬 후 이분탐색"은 코테 필수 패턴이다.

| 함수 | 반환 | 의미 |
|------|------|------|
| `lower_bound(b, e, x)` | 첫 위치 반복자 | `x` **이상**이 처음 나오는 곳 |
| `upper_bound(b, e, x)` | 첫 위치 반복자 | `x` **초과**가 처음 나오는 곳 |
| `binary_search(b, e, x)` | `bool` | `x`가 있는지 여부 |

```cpp
vector<int> v = {1, 2, 2, 3, 5};   // 반드시 정렬 상태여야 함!

// 값 2가 처음 나오는 인덱스
int lo = lower_bound(v.begin(), v.end(), 2) - v.begin();   // 1
// 값 2를 초과하는 첫 인덱스
int hi = upper_bound(v.begin(), v.end(), 2) - v.begin();   // 3

int cnt2 = hi - lo;                // 값 2의 개수 → 2
bool has3 = binary_search(v.begin(), v.end(), 3);   // true
```

> 💡 **반복자에서 인덱스로:** `반복자 - v.begin()`을 빼면 정수 인덱스가 된다. 위치가 필요하면 이 관용구를 쓴다.

> 💡 **활용 정리:**
> - 특정 값의 **개수** = `upper_bound - lower_bound`
> - `x` **이상**인 첫 원소 위치 = `lower_bound`
> - `x` **이하**인 마지막 원소 = `upper_bound(...) - 1` (구간에 있을 때)

> ⚠️ 구간이 **정렬돼 있지 않으면** 결과가 틀린다. `lower_bound` 전에 반드시 `sort`. 또한 못 찾으면 `end()`를 반환하니 역참조 전에 확인하라.

### set/map에서의 이분 탐색

> `set`·`map`은 트리라서 전역 `lower_bound` 대신 **멤버 함수**를 써야 O(log n)이 나온다.

```cpp
set<int> s = {1, 3, 5, 7};
auto it = s.lower_bound(4);   // 4 이상 첫 원소 → 5를 가리킴
if (it != s.end()) cout << *it;   // 5
```

## 최대 · 최소 · 합

### min / max / min_element / max_element

```cpp
int a = max(3, 7);            // 7
int b = min(3, 7);            // 3
int c = max({3, 7, 1, 9});    // 9   (초기화 리스트로 여러 개)

vector<int> v = {3, 1, 4, 1, 5};
int mx = *max_element(v.begin(), v.end());   // 5  (반복자라 * 필요)
int mn = *min_element(v.begin(), v.end());   // 1

int mxIdx = max_element(v.begin(), v.end()) - v.begin();  // 최댓값 인덱스 → 4
```

> ⚠️ `max_element`/`min_element`는 **반복자**를 반환한다. 값이 필요하면 `*`로 역참조하라. `max`/`min`(값 두 개 비교)과 헷갈리지 말 것.

### accumulate — 합계 (`<numeric>`)

> 구간의 합을 구한다. **세 번째 인자가 초기값이자 타입**을 결정한다.

```cpp
#include <numeric>
vector<int> v = {1, 2, 3, 4};
int sum = accumulate(v.begin(), v.end(), 0);    // 10
```

> ⚠️ **오버플로 함정.** 초기값을 `0`(int)으로 주면 합도 `int`로 누적된다. 합이 21억을 넘길 수 있으면 초기값을 **`0LL`(long long)**로 줘야 한다.
> ```cpp
> long long sum = accumulate(v.begin(), v.end(), 0LL);   // ✅ long long 누적
> ```

### 개수 세기 (count / count_if)

```cpp
vector<int> v = {1, 2, 2, 3, 2};
int c = count(v.begin(), v.end(), 2);                        // 값 2의 개수 → 3
int e = count_if(v.begin(), v.end(), [](int x){ return x % 2 == 0; });  // 짝수 개수 → 3
```

## 순열 (next_permutation) — 완전탐색

> 구간을 **다음 사전순 순열**로 바꾸고, 더 없으면 false. 정렬 상태에서 시작해 `do-while`로 **모든 순열**을 만든다. 브루트포스에 유용.

```cpp
vector<int> v = {1, 2, 3};
sort(v.begin(), v.end());        // 오름차순으로 시작해야 전체를 돈다
do {
    for (int x : v) cout << x;    // 123 / 132 / 213 / 231 / 312 / 321
    cout << "\n";
} while (next_permutation(v.begin(), v.end()));
```

> 💡 **조합**은 순열보다 자주 나온다. `next_permutation`으로 조합을 만들려면 "뽑을 개수만큼 1, 나머지 0" 배열을 순열 돌린다.
> ```cpp
> vector<int> sel = {1, 1, 0, 0};   // 4개 중 2개 선택
> sort(sel.begin(), sel.end());     // {0,0,1,1}부터
> do {
>     for (int i = 0; i < 4; i++)
>         if (sel[i]) cout << i;    // 선택된 인덱스
>     cout << "\n";
> } while (next_permutation(sel.begin(), sel.end()));
> ```

## 채우기 · 변형

### fill / iota

```cpp
vector<int> v(5);
fill(v.begin(), v.end(), 7);        // 전부 7 → {7,7,7,7,7}

iota(v.begin(), v.end(), 1);        // 1씩 증가 채움 → {1,2,3,4,5} (<numeric>)
```

> 💡 배열 초기화는 `memset`도 쓴다. 단 `memset(arr, 0, sizeof(arr))`(0으로)나 `memset(arr, -1, sizeof(arr))`(-1로)처럼 **0/-1에만 안전**하다. `memset(arr, 1, ...)`은 1이 아니라 각 바이트가 1이라 이상한 값이 된다. (`<cstring>`)

### unique — 중복 제거 (연속된 것만)

> **정렬된** 구간에서 연속 중복을 제거하고, "쓸모없어진 뒤쪽"의 시작 반복자를 반환한다. 보통 `erase`와 세트로 쓴다.

```cpp
vector<int> v = {1, 1, 2, 3, 3, 3};
sort(v.begin(), v.end());                          // 먼저 정렬
v.erase(unique(v.begin(), v.end()), v.end());      // 중복 제거 → {1, 2, 3}
```

> ⚠️ `unique`는 **연속된** 중복만 없앤다. 반드시 **먼저 `sort`**해야 전체 중복이 제거된다. `unique`만으로는 뒤 원소가 그대로 남는다.

> 💡 이 `sort + unique + erase` 3단 콤보는 **좌표 압축**·중복 제거의 표준 관용구다.

### reverse / rotate

```cpp
vector<int> v = {1, 2, 3, 4};
reverse(v.begin(), v.end());              // {4, 3, 2, 1}
rotate(v.begin(), v.begin() + 1, v.end()); // 왼쪽으로 1칸 회전
```

## 참고

### 최대공약수 / 최소공배수 (C++14)

> C++17의 `std::gcd`는 C++14에 **없다.** GCC 확장 `__gcd`를 쓰거나 직접 구현한다.

```cpp
int g = __gcd(12, 18);          // 6   (GCC 내장, <algorithm>에 딸려 옴)

// 직접 구현 (이식성 있음)
int gcd(int a, int b) { return b == 0 ? a : gcd(b, a % b); }

// 최소공배수 (오버플로 주의 → long long)
long long lcm = (long long)a / gcd(a, b) * b;   // 먼저 나누고 곱해야 안전
```

> ⚠️ 최소공배수 `a * b / gcd`는 `a * b`에서 오버플로할 수 있다. **`a / gcd * b`** 순서로 먼저 나눈 뒤 곱하라.

### 값 범위 제한 (clamp 대용)

> C++17의 `std::clamp`도 C++14엔 없다. `min`/`max` 조합으로 대신한다.

```cpp
// x를 [lo, hi] 범위로 가두기
int y = max(lo, min(x, hi));
```

### 자주 쓰는 함수 요약

| 함수 | 헤더 | 용도 |
|------|------|------|
| `sort` | `<algorithm>` | 정렬 |
| `lower_bound` / `upper_bound` | `<algorithm>` | 이분 탐색 (정렬 필요) |
| `binary_search` | `<algorithm>` | 존재 여부 |
| `max_element` / `min_element` | `<algorithm>` | 최대/최소 위치 |
| `count` / `count_if` | `<algorithm>` | 개수 세기 |
| `unique` | `<algorithm>` | 연속 중복 제거 |
| `reverse` | `<algorithm>` | 뒤집기 |
| `next_permutation` | `<algorithm>` | 순열 완전탐색 |
| `fill` | `<algorithm>` | 값 채우기 |
| `accumulate` | `<numeric>` | 합계 |
| `iota` | `<numeric>` | 연속값 채우기 |
| `__gcd` | `<algorithm>` | 최대공약수 |

> 💡 `#include <bits/stdc++.h>` 하나면 위 헤더가 전부 포함된다(GCC). 헤더 고민 없이 함수를 바로 쓸 수 있어 코테에서 편하다.
