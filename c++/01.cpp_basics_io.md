# 🔷 C++ 기초 문법 — 프로그램 구조 · 입출력 · 형변환

> 코딩테스트 관점에서 **가장 먼저 세팅해야 하는 것**들을 모았다. 빠른 입출력, 자료형 선택(오버플로 회피), 정수 나눗셈 함정이 핵심이다.

## 프로그램 구조

### 기본 골격

> C++은 **컴파일 언어**다. 소스(`.cpp`)를 기계어로 번역(컴파일)한 뒤 실행한다.

```cpp
#include <iostream>   // 입출력 기능 가져오기

using namespace std;  // std:: 생략 (코테용 단일 파일에선 편함)

int main() {          // 프로그램의 시작점
    cout << "Hello, World!" << "\n";
    return 0;         // 정상 종료
}
```

| 구성 요소 | 의미 |
|-----------|------|
| `#include <iostream>` | 입출력 라이브러리 포함 (전처리) |
| `using namespace std;` | `std::` 생략 가능하게 함 |
| `int main()` | 실행이 시작되는 함수 (필수) |
| `;` | 모든 문장의 끝 (필수) |
| `return 0;` | main 종료, `0` = 정상 |

컴파일 & 실행 (터미널):
```bash
g++ -std=c++17 -O2 -Wall -Wextra sol.cpp -o sol   # C++17로 컴파일 (경고 켜기)
./sol                                             # 실행
```

> 💡 `-Wall -Wextra`는 **경고를 켜는 옵션**이다. `if (x = 5)`, 초기화 안 한 변수, `size_t`와 `int` 비교 같은 실수를 컴파일러가 미리 알려준다. 독학할 땐 항상 켜두자. (Visual Studio의 MSVC라면 `cl /std:c++17 /EHsc /W4 sol.cpp`)

> 💡 코테 채점 서버는 보통 `bits/stdc++.h` 하나로 모든 표준 헤더를 한 번에 포함할 수 있다. 헤더를 일일이 안 써도 돼서 편하다.
> ```cpp
> #include <bits/stdc++.h>   // 모든 표준 헤더 포함 (GCC 전용)
> using namespace std;
> ```
> ⚠️ 단 컴파일이 느려지고 표준이 아니라서 일부 환경(MSVC 등)에선 안 된다. 개별 헤더(`<vector>` 등)를 쓰는 습관도 알아두자.

### 코테 기본 템플릿

> 아래 내용(빠른 입출력, `long long` 등)을 합친 **매 문제 시작 틀**이다. 각 줄의 이유는 이 문서와 [02. 자료형 · 연산자](02.cpp_types_operators.md)에서 하나씩 설명한다.

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;
    vector<long long> a(n);
    for (auto& x : a) cin >> x;

    long long sum = 0;
    for (long long x : a) sum += x;
    cout << sum << "\n";
    return 0;
}
```

## 빠른 입출력 (코테 필수)

> C++의 `cin`/`cout`은 기본 설정에서 C의 `scanf`/`printf`와 동기화되어 **느리다.** 입력이 수십만 줄 이상이면 이것만으로 시간 초과가 날 수 있다.

```cpp
int main() {
    ios_base::sync_with_stdio(false);   // C 입출력과 동기화 해제
    cin.tie(nullptr);                   // cin↔cout 묶음 해제

    // 이후 cin/cout이 훨씬 빨라진다
}
```

| 설정 | 효과 |
|------|------|
| `sync_with_stdio(false)` | C stdio와 분리 → cin/cout 가속 |
| `cin.tie(nullptr)` | 입력 전 자동 flush 제거 → 추가 가속 |

> 💡 옛 코드에선 `cin.tie(NULL)`이나 `cin.tie(0)`도 자주 보인다. 같은 의미다. C++11 이후로는 `nullptr`가 정석이다([09. 포인터](09.cpp_pointer.md) 참고).

> ⚠️ `sync_with_stdio(false)`를 켜면 **`cin`/`cout`과 `scanf`/`printf`를 섞어 쓰면 안 된다.** 출력 순서가 꼬인다. C++ 스트림만 쓰거나 C 함수만 쓰거나 하나로 통일하라.

> 💡 **출력엔 `endl` 대신 `"\n"`**을 써라. `endl`은 매번 버퍼를 비워(flush) 느리다. 위 가속 설정을 하고도 `endl`을 남발하면 효과가 반감된다.

```cpp
cout << ans << endl;   // ❌ 매번 flush → 느림
cout << ans << "\n";   // ✅ 빠름
```

## 입력 (cin)

> `cin`에 `>>`로 입력을 받는다. 변수 타입에 맞춰 **알아서 변환**해준다. 공백·줄바꿈을 기준으로 값을 끊는다.

```cpp
int n;
cin >> n;              // 정수 하나

int a, b;
cin >> a >> b;         // 공백/줄바꿈으로 구분된 두 값

int arr[100], k;
cin >> k;
for (int i = 0; i < k; i++) cin >> arr[i];   // k개 반복 입력
```

> ⚠️ `cin >>`은 **공백·줄바꿈에서 끊는다.** 공백 포함 문자열은 첫 단어만 읽힌다.
> ```cpp
> string s;
> cin >> s;   // "hello world" 입력 → s = "hello" (world 누락)
> ```

공백 포함 **한 줄 전체**는 `getline`으로 받는다.
```cpp
string line;
getline(cin, line);    // 줄 전체 → "hello world"
```

> ⚠️ **`cin >>` 다음에 `getline`을 쓰는 함정.** `cin >> n`은 줄바꿈을 버퍼에 남긴다. 곧바로 `getline`하면 **빈 줄**이 먼저 읽힌다. 사이에 `cin.ignore()`를 넣어 남은 줄바꿈을 버려라. (자세한 건 [05. 문자열](05.cpp_string.md) 참고)

EOF까지 계속 읽기 (입력 개수가 안 주어질 때):
```cpp
int x;
while (cin >> x) {     // 더 읽을 게 없으면 false → 종료
    // x 처리
}
```

## 출력 (cout)

> `cout`에 `<<`로 값을 흘려보낸다. `<<`는 여러 개를 **연달아** 이어 쓸 수 있다.

```cpp
cout << "이름: " << name << ", 나이: " << age << "\n";
cout << 1 + 2 << "\n";   // 3 (식도 바로 출력)
```

### 실수 출력 형식 (`<iomanip>`)

> 코테에서 "소수점 아래 N자리까지" 요구가 흔하다. `fixed`와 `setprecision`을 함께 쓴다.

```cpp
#include <iomanip>
double d = 3.14159265;

cout << fixed << setprecision(2) << d << "\n";   // 3.14
cout << fixed << setprecision(6) << d << "\n";   // 3.141593
```

| 조작자 | 의미 |
|--------|------|
| `fixed` | 고정 소수점 표기 |
| `setprecision(n)` | (fixed와 함께) 소수점 아래 n자리 |
| `setw(n)` | 출력 폭 n칸 확보 (오른쪽 정렬) |

> ⚠️ `setprecision`만 쓰면 "**전체** 유효숫자"가 되고, `fixed`와 함께 써야 "소수점 **아래** 자리"가 된다. 보통 `fixed << setprecision(n)` 세트로 기억하자.

## 형변환

### 문자열 ↔ 숫자

```cpp
int    n = stoi("42");         // string → int    → 42
long long ll = stoll("100");   // string → long long
double d = stod("3.14");       // string → double → 3.14
string t = to_string(100);     // 숫자   → string → "100"
```

| 함수 | 변환 | 헤더 |
|------|------|------|
| `stoi` | string → int | `<string>` |
| `stoll` | string → long long | `<string>` |
| `stod` | string → double | `<string>` |
| `to_string` | 숫자 → string | `<string>` |

### 명시적 형변환 (캐스팅)

```cpp
int a = 7, b = 2;
double r  = (double)a / b;              // C 스타일      → 3.5
double r2 = static_cast<double>(a) / b; // C++ 권장 방식 → 3.5
```

> 💡 정수끼리 나누면 소수부가 사라진다([02. 자료형 · 연산자](02.cpp_types_operators.md)의 산술 연산자 참고). 실수 결과가 필요하면 **한쪽을 `double`로 캐스팅**해야 한다.

### 암시적 형변환 (자동)

```cpp
double x = 3 + 1.5;    // int 3 → double → 4.5
int y = 3.9;           // double → int → 3  (⚠️ 반올림 아님, 소수부 버림)
```
