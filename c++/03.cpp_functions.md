# 🔷 C++ 기초 문법 — 함수

> 코테에서 함수는 **재귀(DFS/백트래킹)**, **정렬 비교 기준(람다)**, **큰 데이터 참조 전달**에 집중적으로 쓰인다. 이 세 가지를 특히 자세히 다룬다.

---

## 함수 기초

### 함수 구조

> 특정 작업을 묶어 이름 붙인 코드. C++은 **반환 타입을 명시**해야 한다.

```cpp
int add(int a, int b) {   // 반환타입 함수이름(매개변수)
    return a + b;
}

void greet(string name) { // void = 반환값 없음
    cout << "Hi, " << name << "\n";
}
```

| 구성 | 의미 |
|------|------|
| 반환 타입 | 돌려줄 값의 타입 (`int`, `double`, `bool`...) |
| `void` | 반환값 없음 |
| 매개변수 | 받을 입력 (타입 명시 필수) |
| `return` | 결과 반환 + 함수 즉시 종료 |

### 선언과 정의 분리 (프로토타입)

> C++은 함수를 **호출하기 전에 알고 있어야** 한다. 정의가 `main` 아래에 있으면 위에 **선언(프로토타입)**만 먼저 적는다.

```cpp
int add(int a, int b);   // 선언 — 본문 없이 세미콜론

int main() {
    cout << add(3, 5);   // 정의가 아래 있어도 OK
}

int add(int a, int b) {  // 정의
    return a + b;
}
```

> 💡 코테에선 보통 함수를 `main` **위에** 정의해 프로토타입을 생략한다. 재귀·전역 배열과 함께 위쪽에 몰아 쓰는 스타일이 흔하다.

## 매개변수 전달 방식

### 값 / 참조 / const 참조 (코테 핵심)

> C++은 인자를 넘기는 방식에 따라 **원본을 바꿀 수 있느냐**와 **복사 비용**이 갈린다. 코테에선 특히 **큰 컨테이너를 복사 없이 넘기는 것**이 성능에 직결된다.

**① 값 전달 (복사)** — 원본 안 바뀜. 큰 데이터엔 비효율.
```cpp
void f(int x) { x = 100; }   // 복사본만 변경
int a = 5;
f(a);
cout << a;   // 5  (원본 그대로)
```

**② 참조 전달 (`&`)** — 원본을 직접 가리킴. 바뀜.
```cpp
void f(int& x) { x = 100; }  // 원본 변경
int a = 5;
f(a);
cout << a;   // 100  (바뀜!)
```

**③ const 참조 (`const &`)** — 복사 없이 넘기되 수정은 막음. **큰 데이터 읽기 전용 전달의 표준.**
```cpp
long long sum(const vector<int>& v) {   // 벡터를 복사 없이 참조
    long long s = 0;
    for (int x : v) s += x;
    return s;
}
```

| 방식 | 문법 | 원본 변경 | 복사 비용 | 용도 |
|------|------|-----------|-----------|------|
| 값 | `int x` | ❌ | 있음 | 작은 값 단순 입력 |
| 참조 | `vector<int>& v` | ✅ | 없음 | 원본 수정 |
| const 참조 | `const vector<int>& v` | ❌ | 없음 | **큰 데이터 읽기 전용** |

> ⚠️ **`vector`·`string`을 값으로 넘기면 통째로 복사된다.** 원소가 10만 개면 호출마다 10만 번 복사 → 시간 초과의 숨은 원인이다. 수정할 거면 `&`, 읽기만 하면 `const &`로 넘겨라.

> 💡 **2차원 벡터를 여러 함수가 공유**한다면 전역 변수로 두거나 `&`로 넘긴다. 값 복사는 절대 피한다.

### 기본 인자

> 인자를 생략하면 기본값 사용. 단 **뒤쪽 매개변수부터** 기본값을 줘야 한다.

```cpp
int power(int base, int exp = 2) {   // exp 기본값 2
    int r = 1;
    for (int i = 0; i < exp; i++) r *= base;
    return r;
}
power(3);      // 9  (3^2)
power(3, 3);   // 27 (3^3)
```

> ⚠️ 기본값 있는 매개변수는 **반드시 뒤쪽**에. `int f(int a = 1, int b)` ❌

### 함수 오버로딩

> **같은 이름** 함수를 매개변수 구성만 다르게 여러 개 정의. 컴파일러가 인자 타입·개수를 보고 알맞은 버전을 고른다.

```cpp
int    add(int a, int b)       { return a + b; }
double add(double a, double b)  { return a + b; }

add(1, 2);       // int 버전 → 3
add(1.5, 2.5);   // double 버전 → 4.0
```

## 재귀 함수 (코테 핵심)

### 기본 구조

> 자기 자신을 호출하는 함수. **종료 조건(기저 조건)**이 반드시 있어야 한다. DFS·백트래킹·분할정복의 토대다.

```cpp
int factorial(int n) {
    if (n <= 1) return 1;          // 기저 조건 (종료점)
    return n * factorial(n - 1);   // 자기 자신 호출
}
factorial(5);   // 120
```

| 요소 | 설명 |
|------|------|
| 기저 조건 | 재귀를 멈추는 조건 (필수) |
| 재귀 호출 | 더 작은 문제로 자기 자신 호출 |

> ⚠️ 파이썬은 재귀 한도(`RecursionError`)로 막아줬지만, C++은 한도가 없어도 **스택 메모리를 초과(stack overflow)하면 그냥 죽는다**(segfault). 재귀 깊이가 수십만이면 반복문이나 명시적 스택으로 바꾸는 걸 고려하라.

### DFS 뼈대 (격자 탐색)

> 방향 배열(`02` 참고)과 재귀를 합치면 격자 DFS가 된다. **방문 체크 + 경계 검사**가 핵심이다.

```cpp
int N, M;
vector<vector<int>> grid;      // 지도 (전역)
vector<vector<bool>> visited;  // 방문 여부 (전역)
int dr[4] = {-1, 1, 0, 0};
int dc[4] = {0, 0, -1, 1};

void dfs(int r, int c) {
    visited[r][c] = true;               // 현재 칸 방문 처리
    for (int dir = 0; dir < 4; dir++) {
        int nr = r + dr[dir], nc = c + dc[dir];
        if (nr < 0 || nr >= N || nc < 0 || nc >= M) continue;  // 경계
        if (visited[nr][nc]) continue;                          // 이미 방문
        if (grid[nr][nc] == 0) continue;                        // 벽 등 조건
        dfs(nr, nc);                    // 다음 칸으로 재귀
    }
}
```

> 💡 **전역으로 두는 이유:** `grid`·`visited`를 매 재귀 호출마다 값으로 넘기면 복사 폭발이 난다. 전역 변수(또는 `&` 전달)로 공유하는 게 관례다.

### 백트래킹 뼈대

> 모든 경우를 탐색하되, 선택했다가 **되돌리는(원복)** 패턴. 순열·조합·N-Queen 등에 쓴다.

```cpp
vector<int> pick;      // 현재까지 고른 것
vector<bool> used(n);

void backtrack(int depth) {
    if (depth == k) {              // 다 골랐으면 결과 처리
        // pick 사용
        return;
    }
    for (int i = 0; i < n; i++) {
        if (used[i]) continue;
        used[i] = true;            // 선택
        pick.push_back(i);
        backtrack(depth + 1);
        pick.pop_back();           // 되돌리기 (핵심!)
        used[i] = false;
    }
}
```

> ⚠️ 선택 후 반드시 **원복(`pop_back`, `used[i] = false`)**해야 다음 경우를 올바르게 탐색한다. 이 되돌리기를 빠뜨리는 게 백트래킹 최다 실수다.

## 참고

### 람다 표현식 (정렬 비교 기준으로 필수)

> 이름 없는 함수를 그 자리에서 정의한다. `[캡처](매개변수) { 본문 }` 형태. 코테에선 주로 **`sort`의 비교 기준**을 즉석에서 넘길 때 쓴다.

```cpp
auto add = [](int a, int b) { return a + b; };
cout << add(3, 5);   // 8

// sort 비교 기준으로 (가장 흔한 용도)
vector<int> v = {3, 1, 2};
sort(v.begin(), v.end(), [](int a, int b) {
    return a > b;    // 내림차순
});
```

바깥 변수를 **캡처**해 람다 안에서 쓸 수 있다(파이썬 람다보다 강력).

```cpp
int base = 10;
auto addBase = [base](int x) { return x + base; };  // base를 값으로 캡처
cout << addBase(5);  // 15
```

| 캡처 | 의미 |
|------|------|
| `[]` | 캡처 없음 |
| `[base]` | base를 값(복사)으로 캡처 |
| `[&base]` | base를 참조로 캡처 (원본 수정 가능) |
| `[=]` / `[&]` | 바깥 변수 전부 값 / 전부 참조 |

> 💡 C++14부터 **제네릭 람다**가 된다. 매개변수에 `auto`를 쓸 수 있다.
> ```cpp
> auto cmp = [](auto a, auto b) { return a > b; };
> ```

### 참조 반환 주의

> 함수가 **지역 변수의 참조**를 반환하면, 함수가 끝나며 그 변수가 사라져 **댕글링 참조**가 된다.

```cpp
int& bad() {
    int x = 5;
    return x;      // ❌ x는 함수 종료 시 소멸 → 위험
}
```

> 💡 값을 돌려줄 땐 그냥 값으로 반환하라(`int f()`). C++은 반환 시 복사를 최적화(RVO)하므로 대부분 비용 걱정이 없다.

### 반환 타입 추론 (auto)

> C++14부터 함수 반환 타입도 `auto`로 추론할 수 있다.

```cpp
auto multiply(int a, int b) {   // 반환 타입 int로 추론
    return a * b;
}
```

### 여러 값 반환 (구조적 바인딩, C++17)

> `pair`나 `tuple`로 묶어 반환하고, 받는 쪽에서 **구조적 바인딩**으로 바로 푼다. (파이썬 `q, r = divmod(17, 5)`에 대응)

```cpp
pair<int, int> divmod(int a, int b) {
    return {a / b, a % b};
}

auto [q, r] = divmod(17, 5);   // q = 3, r = 2
```

### 값이 없을 수 있는 반환 (optional, C++17)

> "찾으면 값, 못 찾으면 없음"을 `-1` 같은 특수값 대신 `std::optional`로 표현한다. (`#include <optional>`)

```cpp
#include <optional>
optional<int> findIndex(const vector<int>& v, int x) {
    for (int i = 0; i < (int)v.size(); i++)
        if (v[i] == x) return i;
    return nullopt;                         // 값 없음
}

vector<int> v = {1, 3, 5};
if (auto idx = findIndex(v, 3)) {           // 값이 있으면 참
    cout << *idx << "\n";                   // 1  (*로 값 꺼내기)
}
cout << findIndex(v, 9).value_or(-1);       // -1 (없으면 기본값)
```

> 💡 코테에선 `-1` 반환으로 충분한 경우가 많다. 실무 코드에서 자주 보이므로 읽을 수 있을 정도로 알아두자.

### 전역 배열 활용 (코테 관용)

> 큰 배열은 함수 안(스택)이 아니라 **전역(정적 영역)**에 선언하는 게 흔하다. 스택 오버플로를 피하고, 자동으로 0 초기화된다.

```cpp
int arr[1'000'001];        // 전역: 자동으로 전부 0
bool visited[1'000'001];   // 전역: 자동으로 전부 false

int main() { /* ... */ }
```

> ⚠️ **큰 배열을 지역(함수 안)에 두면** 스택 한도(보통 1~8MB)를 넘겨 죽을 수 있다. `int arr[1000000]`을 `main` 안에 두면 위험 → 전역으로 빼거나 `vector`를 써라.
