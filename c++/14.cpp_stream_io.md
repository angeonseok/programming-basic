# 🔷 14. 입출력 스트림

> C++의 입출력은 **스트림(stream)**이라는 하나의 개념으로 통일되어 있다. 화면(`cout`), 키보드(`cin`), 파일(`fstream`), 문자열(`stringstream`)이 모두 같은 `<<`, `>>`, `getline`으로 동작한다. 이 장에서는 줄 단위 입력, 입력 오류 처리, 문자열 스트림, 파일 입출력을 다룬다.

| 스트림 | 헤더 | 대상 |
|--------|------|------|
| `cin` / `cout` / `cerr` | `<iostream>` | 키보드 / 화면 / 화면(에러 메시지용) |
| `ifstream` / `ofstream` / `fstream` | `<fstream>` | 파일 읽기 / 쓰기 / 둘 다 |
| `istringstream` / `ostringstream` / `stringstream` | `<sstream>` | 문자열을 스트림처럼 |

---

## 입력 다루기 (getline & 버퍼)

### 한 줄 전체 입력

> `cin >>`은 공백에서 끊기므로, **공백 포함 한 줄**은 `getline`으로 받는다.

```cpp
string line;
getline(cin, line);            // 줄 전체 입력 (공백 포함)
```

### ⚠️ `cin >>` 다음 `getline` 함정

> `cin >> n`은 숫자만 읽고 **줄바꿈(`\n`)을 버퍼에 남긴다.** 곧바로 `getline`하면 그 남은 줄바꿈을 읽어 **빈 줄**이 들어온다.

```cpp
int n;
cin >> n;
cin.ignore();          // ✅ 남은 줄바꿈 하나 버리기 (핵심!)

string line;
getline(cin, line);    // 이제 정상적으로 다음 줄을 읽음
```

| 상황 | 해결 |
|------|------|
| `cin >>` 뒤에 `getline` | 사이에 `cin.ignore();` |
| `getline`만 여러 번 | 그냥 반복 (문제 없음) |

> 💡 `cin.ignore()`는 버퍼에서 문자 하나(줄바꿈)를 버린다. 남은 게 여러 개면 `cin.ignore(numeric_limits<streamsize>::max(), '\n');`으로 줄 끝까지 버린다(`#include <limits>`). 숫자 뒤에 공백이 남아 있을 수 있는 입력이면 이 방법이 더 안전하다.

### 여러 줄 반복 입력

```cpp
string line;
while (getline(cin, line)) {   // EOF까지 줄 단위로
    // line 처리
}
```

## 스트림 상태와 입력 오류 처리

> `int`를 기대하는 `cin >> n`에 `abc`가 들어오면 읽기에 **실패**하고, 스트림이 **실패 상태**가 되어 이후의 입력이 전부 무시된다. 상태를 확인하고 복구하는 법을 알아두자.

| 확인 · 조작 | 의미 |
|-------------|------|
| `if (cin >> x)` / `while (cin >> x)` | 읽기에 성공했는가 (형식 오류·입력 끝이면 거짓) |
| `cin.fail()` | 형식이 맞지 않아 실패했는가 |
| `cin.eof()` | 입력의 끝(EOF)에 도달했는가 |
| `cin.clear()` | 실패 상태를 정상으로 되돌림 (다시 읽으려면 필수) |
| `cin.ignore(n, '\n')` | 버퍼의 남은 입력을 줄 끝까지 버림 |

```cpp
// 올바른 숫자가 들어올 때까지 다시 묻기
int age;
while (true) {
    cout << "나이: ";
    if (cin >> age) break;                                   // 성공
    if (cin.eof()) return 0;                                 // 입력이 끝났으면 포기
    cout << "숫자를 입력하세요\n";
    cin.clear();                                             // ① 실패 상태 해제
    cin.ignore(numeric_limits<streamsize>::max(), '\n');     // ② 잘못 들어온 줄 버리기
}
```

> ⚠️ `cin.clear()` 없이 다시 읽으면 스트림이 여전히 실패 상태라 **아무것도 읽지 않고** 무한 루프에 빠진다. `clear()`로 상태를 풀고, `ignore()`로 잘못된 입력을 버리는 두 단계가 세트다.

## 문자열 스트림 (stringstream)

> **한 줄에 여러 값이 공백/기호로 구분**되어 들어올 때, `stringstream`으로 잘라 읽는다. 파이썬 `split()`에 대응한다.

### 공백 기준 분리

```cpp
#include <sstream>
string line = "10 20 30 40";
stringstream ss(line);

int x;
vector<int> nums;
while (ss >> x) {          // 공백 단위로 하나씩 (자동으로 int 변환)
    nums.push_back(x);     // {10, 20, 30, 40}
}
```

```cpp
// 단어 단위로 자르기
string sentence = "hello world cpp";
stringstream ss(sentence);
string word;
while (ss >> word) {       // 공백 단위 단어
    cout << word << "\n";  // hello / world / cpp
}
```

### 특정 구분자로 분리 (getline + delim)

> 쉼표(`,`)처럼 **공백이 아닌 구분자**로 자를 땐 `getline`의 세 번째 인자에 구분자를 준다.

```cpp
string line = "apple,banana,cherry";
stringstream ss(line);
string token;
vector<string> tokens;

while (getline(ss, token, ',')) {   // ',' 기준 분리
    tokens.push_back(token);        // {"apple", "banana", "cherry"}
}
```

| 목적 | 방법 |
|------|------|
| 공백으로 분리 | `stringstream ss(line); ss >> x;` |
| 특정 문자로 분리 | `getline(ss, token, 구분자);` |

> 💡 숫자 여러 개를 문자열로 이어 만들 때도 `stringstream`이 편하다.
> ```cpp
> stringstream out;
> out << a << " " << b;      // 값을 문자열로 조립
> string result = out.str(); // 완성된 문자열 얻기
> ```

## 파일 입출력 (fstream)

> `<fstream>`의 `ofstream`(쓰기)과 `ifstream`(읽기)은 `cout`/`cin`과 **똑같은 방식**으로 쓴다. 스트림 객체가 사라질 때 파일도 자동으로 닫힌다(RAII, [07. 참조와 메모리 관리](07.cpp_memory.md)).

```cpp
#include <fstream>

int main() {
    // 쓰기 — 파일이 없으면 만들고, 있으면 내용을 지우고 새로 쓴다
    ofstream out("data.txt");
    out << "hello\n";
    out << 42 << " " << 3.14 << "\n";
    out.close();                          // 생략해도 out이 사라질 때 자동으로 닫힘

    // 읽기 — 열렸는지 반드시 확인
    ifstream in("data.txt");
    if (!in) {                            // 파일이 없거나 열 수 없음
        cerr << "파일을 열 수 없음\n";
        return 1;
    }
    string line;
    while (getline(in, line)) {           // 한 줄씩 끝까지
        cout << line << "\n";             // hello → 42 3.14
    }
}
```

| 열기 방식 | 의미 |
|-----------|------|
| `ofstream f("a.txt")` | 쓰기 (기존 내용 삭제) |
| `ofstream f("a.txt", ios::app)` | 이어 쓰기 (끝에 추가) |
| `ifstream f("a.txt")` | 읽기 |
| `fstream f("a.txt", ios::in \| ios::out)` | 읽기 + 쓰기 |
| `ios::binary`를 함께 지정 | 바이너리 모드 (이미지 등 텍스트가 아닌 파일) |

```cpp
ifstream nums("nums.txt");           // 내용이 "1 2 3\n4 5" 인 파일
int x, total = 0;
while (nums >> x) total += x;        // cin처럼 >> 로 공백 단위 읽기 → total = 15
```

> ⚠️ 상대 경로(`"data.txt"`)는 **프로그램이 실행되는 위치(작업 디렉터리)** 기준이다. IDE에서 실행하면 소스 파일이 있는 폴더가 아닐 수 있다. 파일이 안 열리면 먼저 경로부터 확인하자.
