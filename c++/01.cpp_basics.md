## 프로그램 구조

### 기본 골격

> C++은 **컴파일 언어**다. 소스(`.cpp`)를 기계어로 번역(컴파일)한 뒤 실행한다.

```cpp
#include <iostream>   // 입출력 기능 가져오기

using namespace std;  // std:: 생략 (코테용 단일 파일에선 편함)

int main() {          // 프로그램의 시작점
    cout << "Hello, World!" << "\n";
    return 0;         // 정상 종료
}
```

| 구성 요소 | 의미 |
|-----------|------|
| `#include <iostream>` | 입출력 라이브러리 포함 (전처리) |
| `using namespace std;` | `std::` 생략 가능하게 함 |
| `int main()` | 실행이 시작되는 함수 (필수) |
| `;` | 모든 문장의 끝 (필수) |
| `return 0;` | main 종료, `0` = 정상 |

컴파일 & 실행 (터미널):
```bash
g++ -std=c++17 sol.cpp -o sol   # C++17로 컴파일
./sol                           # 실행
```

> 💡 코테 채점 서버는 보통 `bits/stdc++.h` 하나로 모든 표준 헤더를 한 번에 포함할 수 있다. 헤더를 일일이 안 써도 돼서 편하다.
> ```cpp
> #include <bits/stdc++.h>   // 모든 표준 헤더 포함 (GCC 전용)
> using namespace std;
> ```
> ⚠️ 단 컴파일이 느려지고 표준이 아니라서 일부 환경(MSVC 등)에선 안 된다. 개별 헤더(`<vector>` 등)를 쓰는 습관도 알아두자.

## 빠른 입출력 (코테 필수)

> C++의 `cin`/`cout`은 기본 설정에서 C의 `scanf`/`printf`와 동기화되어 **느리다.** 입력이 수십만 줄 이상이면 이것만으로 시간 초과가 날 수 있다.

```cpp
int main() {
    ios_base::sync_with_stdio(false);   // C 입출력과 동기화 해제
    cin.tie(NULL);                      // cin↔cout 묶음 해제

    // 이후 cin/cout이 훨씬 빨라진다
}
```

| 설정 | 효과 |
|------|------|
| `sync_with_stdio(false)` | C stdio와 분리 → cin/cout 가속 |
| `cin.tie(NULL)` | 입력 전 자동 flush 제거 → 추가 가속 |

> ⚠️ `sync_with_stdio(false)`를 켜면 **`cin`/`cout`과 `scanf`/`printf`를 섞어 쓰면 안 된다.** 출력 순서가 꼬인다. C++ 스트림만 쓰거나 C 함수만 쓰거나 하나로 통일하라.

> 💡 **출력엔 `endl` 대신 `"\n"`**을 써라. `endl`은 매번 버퍼를 비워(flush) 느리다. 위 가속 설정을 하고도 `endl`을 남발하면 효과가 반감된다.

```cpp
cout << ans << endl;   // ❌ 매번 flush → 느림
cout << ans << "\n";   // ✅ 빠름
```

## 자료형

### 기본 자료형

> C++은 **정적 타입** 언어다. 변수를 쓰기 전에 **타입을 명시해 선언**해야 한다.

```cpp
int    age  = 25;      // 정수
long long big = 10000000000LL;  // 큰 정수 (뒤에 LL)
double pi   = 3.14;    // 실수
char   grade = 'A';    // 문자 1개 (작은따옴표!)
bool   isOk = true;    // 참/거짓
string name = "건석";  // 문자열 (#include <string>)
```

| 타입 | 용도 | 크기 | 범위(대략) |
|------|------|------|------------|
| `int` | 기본 정수 | 4 byte | 약 ±2.1×10⁹ (21억) |
| `long long` | 큰 정수 | 8 byte | 약 ±9.2×10¹⁸ |
| `unsigned int` | 음수 없는 정수 | 4 byte | 0 ~ 약 42억 |
| `double` | 실수 | 8 byte | 유효숫자 ~15자리 |
| `char` | 문자 1개 | 1 byte | -128 ~ 127 |
| `bool` | 참/거짓 | 1 byte | `true` / `false` |
| `string` | 문자열 | 가변 | — |

### ⚠️ 정수 오버플로 — 코테 1순위 실수

> 파이썬 `int`는 무한히 커지지만, C++ `int`는 약 **21억**에서 넘쳐 **값이 망가진다**(음수 등 쓰레기 값). 합·곱으로 큰 수가 나오는 문제는 반드시 `long long`을 써야 한다.

```cpp
int a = 2'000'000'000;
int b = a + a;                    // ❌ 오버플로 → 쓰레기 값
long long c = (long long)a + a;   // ✅ 4000000000 정상
```

> 💡 **판단 기준:** "N개(최대 10⁵)의 수, 각 10⁹ 이하"의 **합**이면 결과가 10¹⁴까지 간다 → `int`(±21억) 초과 → `long long` 필수. "두 수의 곱"도 각각 10⁵만 넘으면 10¹⁰이라 `int` 초과다.

> ⚠️ **곱셈 중간 오버플로 함정.** 아래처럼 `int`끼리 곱하면 **결과를 `long long`에 담아도** 곱 계산 자체가 이미 `int`로 되어 넘친다.
> ```cpp
> int x = 100000, y = 100000;
> long long z = x * y;              // ❌ x*y가 int로 계산됨 → 오버플로
> long long z2 = (long long)x * y;  // ✅ 한쪽을 먼저 캐스팅
> ```

> 💡 숫자 리터럴에 `'`(작은따옴표)를 넣어 자릿수를 끊어 읽을 수 있다 (C++14). `2'000'000'000`처럼. 값에는 영향 없고 가독성만 좋아진다.

### auto 타입 추론

> `auto`를 쓰면 초기값을 보고 타입을 **자동 추론**한다. 긴 타입 이름(반복자 등)을 줄일 때 특히 유용하다.

```cpp
auto w = 5;        // int
auto d = 3.14;     // double
auto s = "hi";     // const char* (주의: string 아님)

vector<int> v = {1, 2, 3};
for (auto x : v) { }   // x는 int로 추론
```

> 💡 C++17부터 `pair`·`tuple`·구조체를 **구조적 바인딩**으로 한 번에 풀어 받을 수 있다. `auto [a, b] = p;` (자세한 건 `05.cpp_stl_containers` 참고)

### 초기화 방식

```cpp
int x = 5;       // 복사 초기화
int y{5};        // 중괄호 초기화 (좁힘 변환 방지)
int z;           // ⚠️ 초기화 안 함 → 지역변수는 쓰레기 값!
int arr[5] = {}; // 배열 전부 0
```

> ⚠️ C++ 지역 변수는 초기화하지 않으면 **쓰레기 값**이 들어 있다(파이썬엔 없던 상태). 카운터·합 변수는 반드시 `= 0`으로 시작하라.

## 입력 (cin)

> `cin`에 `>>`로 입력을 받는다. 변수 타입에 맞춰 **알아서 변환**해준다. 공백·줄바꿈을 기준으로 값을 끊는다.

```cpp
int n;
cin >> n;              // 정수 하나

int a, b;
cin >> a >> b;         // 공백/줄바꿈으로 구분된 두 값

int arr[100], k;
cin >> k;
for (int i = 0; i < k; i++) cin >> arr[i];   // k개 반복 입력
```

> ⚠️ `cin >>`은 **공백·줄바꿈에서 끊는다.** 공백 포함 문자열은 첫 단어만 읽힌다.
> ```cpp
> string s;
> cin >> s;   // "hello world" 입력 → s = "hello" (world 누락)
> ```

공백 포함 **한 줄 전체**는 `getline`으로 받는다.
```cpp
string line;
getline(cin, line);    // 줄 전체 → "hello world"
```

> ⚠️ **`cin >>` 다음에 `getline`을 쓰는 함정.** `cin >> n`은 줄바꿈을 버퍼에 남긴다. 곧바로 `getline`하면 **빈 줄**이 먼저 읽힌다. 사이에 `cin.ignore()`를 넣어 남은 줄바꿈을 버려라. (자세한 건 `04.cpp_string` 참고)

EOF까지 계속 읽기 (입력 개수가 안 주어질 때):
```cpp
int x;
while (cin >> x) {     // 더 읽을 게 없으면 false → 종료
    // x 처리
}
```

## 출력 (cout)

> `cout`에 `<<`로 값을 흘려보낸다. `<<`는 여러 개를 **연달아** 이어 쓸 수 있다.

```cpp
cout << "이름: " << name << ", 나이: " << age << "\n";
cout << 1 + 2 << "\n";   // 3 (식도 바로 출력)
```

### 실수 출력 형식 (`<iomanip>`)

> 코테에서 "소수점 아래 N자리까지" 요구가 흔하다. `fixed`와 `setprecision`을 함께 쓴다.

```cpp
#include <iomanip>
double d = 3.14159265;

cout << fixed << setprecision(2) << d << "\n";   // 3.14
cout << fixed << setprecision(6) << d << "\n";   // 3.141593
```

| 조작자 | 의미 |
|--------|------|
| `fixed` | 고정 소수점 표기 |
| `setprecision(n)` | (fixed와 함께) 소수점 아래 n자리 |
| `setw(n)` | 출력 폭 n칸 확보 (오른쪽 정렬) |

> ⚠️ `setprecision`만 쓰면 "**전체** 유효숫자"가 되고, `fixed`와 함께 써야 "소수점 **아래** 자리"가 된다. 보통 `fixed << setprecision(n)` 세트로 기억하자.

## 형변환

### 문자열 ↔ 숫자

```cpp
int    n = stoi("42");         // string → int    → 42
long long ll = stoll("100");   // string → long long
double d = stod("3.14");       // string → double → 3.14
string t = to_string(100);     // 숫자   → string → "100"
```

| 함수 | 변환 | 헤더 |
|------|------|------|
| `stoi` | string → int | `<string>` |
| `stoll` | string → long long | `<string>` |
| `stod` | string → double | `<string>` |
| `to_string` | 숫자 → string | `<string>` |

### 명시적 형변환 (캐스팅)

```cpp
int a = 7, b = 2;
double r  = (double)a / b;              // C 스타일      → 3.5
double r2 = static_cast<double>(a) / b; // C++ 권장 방식 → 3.5
```

> 💡 정수끼리 나누면 소수부가 사라진다(아래 참고). 실수 결과가 필요하면 **한쪽을 `double`로 캐스팅**해야 한다.

### 암시적 형변환 (자동)

```cpp
double x = 3 + 1.5;    // int 3 → double → 4.5
int y = 3.9;           // double → int → 3  (⚠️ 반올림 아님, 소수부 버림)
```

## 연산자

### 산술 연산자

| 연산자 | 의미 | 예시 | 결과 |
|--------|------|------|------|
| `+` `-` `*` | 덧·뺄·곱 | `3 * 2` | `6` |
| `/` | 나눗셈 | `7 / 2` | `3` ⚠️ |
| `%` | 나머지 | `7 % 2` | `1` |
| `++` `--` | 증가·감소 | `x++` | `x = x + 1` |

> ⚠️ **정수끼리 `/`는 몫만 남기고 소수부를 버린다(정수 나눗셈).** 파이썬 `//`에 해당한다.
> ```cpp
> 7 / 2      // 3    (파이썬 / 는 3.5)
> 7.0 / 2    // 3.5  (한쪽이 실수면 실수 나눗셈)
> 7 % 2      // 1
> ```

> ⚠️ **음수 나머지 주의.** C++에서 `-7 % 3`은 `-1`이다(파이썬은 `2`). 나머지를 항상 양수로 만들려면 `((a % m) + m) % m` 관용구를 쓴다.
> ```cpp
> -7 % 3            // -1
> ((-7 % 3) + 3) % 3   // 2  (항상 양수 나머지)
> ```

### 비교 · 논리 연산자

비교 연산자 `==` `!=` `>` `<` `>=` `<=` — 결과는 `bool`. 파이썬과 동일.

논리 연산자:

| 연산자 | 의미 | 파이썬 대응 | 예시 |
|--------|------|-------------|------|
| `&&` | 그리고 | `and` | `a > 0 && b > 0` |
| `\|\|` | 또는 | `or` | `a > 0 \|\| b > 0` |
| `!` | 부정 | `not` | `!flag` |

> ⚠️ C++ 논리 연산자는 기호(`&&` `\|\|` `!`)다. 파이썬의 `and`/`or`/`not` 키워드 습관이 남으면 컴파일 에러가 난다. (앞이 결과를 결정하면 뒤를 평가 안 하는 **단축 평가**는 파이썬과 동일)

복합 대입 연산자 `+=` `-=` `*=` `/=` `%=` — 파이썬과 동일.

### 연산자 우선순위

| 우선순위 | 연산자 |
|----------|--------|
| 높음 | `!`, `++`, `--`, 단항 `-` |
| | `*`, `/`, `%` |
| | `+`, `-` |
| | `<`, `<=`, `>`, `>=` |
| | `==`, `!=` |
| | `&&` |
| 낮음 | `\|\|` |

> 💡 헷갈리면 괄호로 묶어라. 특히 비트 연산(`&`, `\|`, `<<`)은 비교보다 우선순위가 **낮아** `if (x & 1 == 0)`이 의도대로 안 된다 → `if ((x & 1) == 0)`.

## 참고

### const 상수

> 값이 바뀌지 않는 상수는 `const`로 선언한다. 배열 크기·좌표 경계 등에 쓴다.

```cpp
const int MAX = 1'000'000;
const int INF = 1e9;          // 큰 수 (도달 불가 거리의 초기값 등)
const long long LINF = 1e18;  // long long용 무한대
```

> 💡 `INF`를 `INT_MAX`(약 21억)로 두면 `INF + INF`가 오버플로한다. 더하기 연산이 섞이는 최단거리 문제는 `1e9` 정도로 여유 있게 잡는 게 안전하다.

### 비트 연산 (코테 활용)

> 정수를 이진수로 보고 비트 단위로 처리한다. 집합 표현·홀짝 판정·2의 거듭제곱 등에 쓴다.

| 연산자 | 의미 | 예시 | 결과 |
|--------|------|------|------|
| `&` | AND | `6 & 3` | `2` |
| `\|` | OR | `6 \| 3` | `7` |
| `^` | XOR | `6 ^ 3` | `5` |
| `<<` | 왼쪽 시프트 | `1 << 4` | `16` (2⁴) |
| `>>` | 오른쪽 시프트 | `16 >> 2` | `4` |

```cpp
if (x & 1) { }          // 홀수 판정 (마지막 비트가 1)
int half = x >> 1;      // x / 2  (2로 나눈 몫)
int pow2 = 1 << k;      // 2의 k제곱

// 비트마스크: i번째 원소 포함 여부
int mask = 0;
mask |= (1 << i);       // i번째 비트 켜기
if (mask & (1 << i)) {} // i번째 비트 확인
```

> 💡 `1 << k`에서 `k`가 31 이상이면 `int`를 넘친다. 큰 시프트는 `1LL << k`로 `long long` 시프트를 써야 한다.

### sizeof

> 자료형/변수가 차지하는 **바이트 수**를 알려준다.

```cpp
cout << sizeof(int) << "\n";        // 4
cout << sizeof(long long) << "\n";  // 8
```
