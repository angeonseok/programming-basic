# 🔷 C++ 기초 문법 — STL 컨테이너 (stack · queue · deque · priority_queue)

> [06. 컨테이너](06.cpp_containers.md)에 이어, BFS·다익스트라에 쓰이는 **stack · queue · deque · priority_queue**와 반복자를 다룬다.

---

## stack / queue / deque

### stack — 후입선출(LIFO)

> 마지막에 넣은 게 먼저 나온다. DFS(반복 버전)·괄호 검사·후위 표기 등에 쓴다. (`#include <stack>`)

```cpp
#include <stack>
stack<int> st;
st.push(1); st.push(2); st.push(3);
cout << st.top();    // 3   (마지막에 넣은 것)
st.pop();            // 3 제거 (pop은 값을 반환 안 함!)
cout << st.top();    // 2
cout << st.size();   // 2
if (st.empty()) { }
```

> ⚠️ **`pop()`은 제거만 하고 값을 반환하지 않는다.** 값이 필요하면 `top()`으로 먼저 읽고 `pop()`으로 지운다(파이썬 `list.pop()`과 다름).
> ```cpp
> int x = st.top(); st.pop();   // 값 꺼내고 제거하는 관용구
> ```

### queue — 선입선출(FIFO)

> 먼저 넣은 게 먼저 나온다. **BFS의 필수 도구.** (`#include <queue>`)

```cpp
#include <queue>
queue<int> q;
q.push(1); q.push(2); q.push(3);
cout << q.front();   // 1   (먼저 넣은 것)
cout << q.back();    // 3   (마지막에 넣은 것)
q.pop();             // 앞(1) 제거
```

### deque — 양쪽 삽입/삭제

> 앞뒤 모두 O(1)로 넣고 뺀다. 슬라이딩 윈도우·0-1 BFS 등에 쓴다. (`#include <deque>`)

```cpp
#include <deque>
deque<int> dq;
dq.push_back(1);     // 뒤에 추가
dq.push_front(0);    // 앞에 추가 → {0, 1}
dq.pop_front();      // 앞 제거
dq.pop_back();       // 뒤 제거
cout << dq[0];       // 인덱스 접근도 가능
```

### BFS 뼈대 (queue 활용)

> 격자 최단거리의 표준 틀. `queue`에 좌표를 넣고, 꺼내며 인접 칸을 탐색한다.

```cpp
int dr[4] = {-1,1,0,0}, dc[4] = {0,0,-1,1};
vector<vector<int>> dist(N, vector<int>(M, -1));   // -1 = 미방문
queue<pair<int,int>> q;

q.push({sr, sc});
dist[sr][sc] = 0;
while (!q.empty()) {
    auto [r, c] = q.front(); q.pop();              // 구조적 바인딩 (C++17)
    for (int d = 0; d < 4; d++) {
        int nr = r + dr[d], nc = c + dc[d];
        if (nr < 0 || nr >= N || nc < 0 || nc >= M) continue;
        if (dist[nr][nc] != -1) continue;          // 이미 방문
        dist[nr][nc] = dist[r][c] + 1;             // 거리 갱신
        q.push({nr, nc});
    }
}
```

> ⚠️ `auto [r, c] = q.front();`는 **복사**라서 바로 `pop()`해도 안전하다. `auto& [r, c] = q.front();`처럼 참조로 받은 뒤 `pop()`하면 지워진 원소를 가리키게 된다.

## priority_queue — 우선순위 큐 (힙)

> 항상 **가장 큰(또는 작은) 값이 top에 오는** 큐. 다익스트라·그리디·"매번 최댓/최솟값 꺼내기"에 필수. (`#include <queue>`)

### 최대 힙 (기본)

```cpp
priority_queue<int> pq;         // 기본: 최대 힙 (top이 최댓값)
pq.push(3); pq.push(1); pq.push(5);
cout << pq.top();    // 5   (최댓값)
pq.pop();            // 5 제거
cout << pq.top();    // 3
```

### 최소 힙 (자주 씀)

> `greater<int>`를 넣으면 top이 최솟값이 된다. 다익스트라에서 이 형태를 쓴다.

```cpp
priority_queue<int, vector<int>, greater<int>> pq;   // 최소 힙
pq.push(3); pq.push(1); pq.push(5);
cout << pq.top();    // 1   (최솟값)
```

| 선언 | top |
|------|-----|
| `priority_queue<int>` | 최댓값 (최대 힙) |
| `priority_queue<int, vector<int>, greater<int>>` | 최솟값 (최소 힙) |

> ⚠️ 최소 힙 선언은 세 인자를 다 써야 한다: `priority_queue<자료형, vector<자료형>, greater<자료형>>`. 자주 틀리는 부분이라 통째로 외우자.

### pair를 담은 우선순위 큐 (다익스트라)

> `pair`를 담으면 **first 기준**으로 정렬된다. 다익스트라는 `{거리, 정점}`을 최소 힙에 넣어, 거리가 가장 짧은 정점을 매번 꺼낸다.

```cpp
const int INF = 1e9;
vector<vector<pair<int,int>>> adj(n);   // adj[u] = {(v, w), ...}  u → v, 가중치 w
vector<int> dist(n, INF);

// {거리, 정점} 최소 힙 → 거리가 가장 짧은 것이 top
priority_queue<pair<int,int>, vector<pair<int,int>>, greater<pair<int,int>>> pq;

dist[start] = 0;
pq.push({0, start});
while (!pq.empty()) {
    auto [d, u] = pq.top();      // {거리, 정점} (C++17 구조적 바인딩, 복사)
    pq.pop();
    if (d > dist[u]) continue;   // 이미 더 짧은 거리로 처리된 낡은 항목 → 버림
    for (auto [v, w] : adj[u]) {
        if (dist[u] + w < dist[v]) {   // 완화(relax): u를 거쳐 가는 게 더 짧으면 갱신
            dist[v] = dist[u] + w;
            pq.push({dist[v], v});
        }
    }
}
// dist[v] == INF 이면 start에서 v로 갈 수 없음
```

> ⚠️ `if (d > dist[u]) continue;`를 빠뜨리면 답은 맞아도 같은 정점을 여러 번 처리해 **시간 초과**가 날 수 있다. 거리 합이 21억을 넘을 수 있으면 `dist`와 `pq`를 `long long`으로 바꿔라.

> 💡 거리를 **음수로 넣어 최대 힙을 최소 힙처럼** 쓰는 편법도 있지만(`pq.push({-dist, v})`), `greater`를 쓰는 정석이 실수가 적다.

### 사용자 정의 우선순위 (구조체/람다)

> 정렬 기준이 복잡하면 비교 구조체를 정의한다. (자세한 정렬 비교는 [08. 알고리즘](08.cpp_algorithm.md), [11. 객체 지향](11.cpp_oop.md) 참고)

```cpp
struct Cmp {
    bool operator()(const pair<int,int>& a, const pair<int,int>& b) const {
        return a.second > b.second;   // second 작은 게 우선 (최소 힙 방향)
    }
};
priority_queue<pair<int,int>, vector<pair<int,int>>, Cmp> pq;
```

> 💡 `operator()` 뒤의 **`const`를 붙이는 습관**을 들이자. 같은 비교 구조체를 `set<T, Cmp>`에 쓰면 `const`가 없을 때 컴파일 에러가 난다.

람다로도 쓸 수 있다. 람다는 타입 이름이 없어서 `decltype`으로 타입을 꺼내 넘긴다.

```cpp
auto cmp = [](const pair<int,int>& a, const pair<int,int>& b) { return a.second > b.second; };
priority_queue<pair<int,int>, vector<pair<int,int>>, decltype(cmp)> pq(cmp);   // 생성자에도 cmp 전달
```

> ⚠️ 비교 함수의 부등호 방향이 헷갈린다. **`priority_queue`는 `sort`와 반대로**, 비교가 "참"이면 그 원소가 **뒤로** 간다. `a < b`(오름차순 sort용)를 넣으면 **최대 힙**이 된다.

## 반복자 (iterator)

> 컨테이너 원소를 가리키는 포인터 같은 것. `begin()`(첫 원소), `end()`(마지막 **다음**)를 가리킨다. `sort`·`find` 등 STL 알고리즘이 반복자 구간을 받는다.

```cpp
vector<int> v = {1, 2, 3};
sort(v.begin(), v.end());          // 구간 전체 정렬

auto it = v.begin();               // 첫 원소를 가리킴
cout << *it;                       // 1  (역참조로 값)

vector<int>::iterator it2 = find(v.begin(), v.end(), 2);
if (it2 != v.end()) { /* 찾음 */ } // end면 못 찾은 것
```

> 💡 대부분은 **범위 기반 for**로 반복자를 감출 수 있다. 반복자는 `sort`·`lower_bound`·`erase` 같은 함수에 구간을 넘길 때 주로 만난다.

## ⚠️ 반복자 무효화 — 순회하며 지우기

> 원소를 지우거나 추가하면, 그 원소(또는 컨테이너 전체)를 가리키던 반복자·참조가 **무효**가 된다. 무효 반복자를 쓰면 런타임 에러나 이상한 값이 나온다.

```cpp
set<int> s = {1, 2, 3, 4, 5, 6};

// ❌ 범위 기반 for 안에서 erase → 지운 원소의 반복자를 계속 쓰게 됨
// for (int x : s) if (x % 2 == 0) s.erase(x);

// ✅ erase가 돌려주는 "다음 위치"를 받아 이어간다
for (auto it = s.begin(); it != s.end(); ) {
    if (*it % 2 == 0) it = s.erase(it);   // 지우고 다음 위치로
    else ++it;
}
// s = {1, 3, 5}
```

> ⚠️ `vector`는 `push_back`으로 공간이 늘어날 때 **원소 전체가 새 메모리로 옮겨진다.** 그 전에 받아둔 `int& r = v[0];`나 반복자는 전부 무효가 된다. 순회 중에 같은 벡터에 `push_back`하지 마라. `vector`에서 조건에 맞는 원소를 지울 땐 [08. 알고리즘](08.cpp_algorithm.md)의 `erase(remove_if(...))` 관용구를 쓴다.

## 컨테이너 선택 가이드

| 필요한 것 | 컨테이너 |
|-----------|----------|
| 순서 있는 가변 배열 | `vector` |
| 키-값 (빠른 조회) | `unordered_map` |
| 키-값 (키 정렬) | `map` |
| 중복 제거 / 존재 확인 | `unordered_set` / `set` |
| LIFO (DFS·괄호) | `stack` |
| FIFO (BFS) | `queue` |
| 양쪽 삽입/삭제 | `deque` |
| 매번 최대/최소 꺼내기 | `priority_queue` |
