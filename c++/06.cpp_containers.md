# 🔷 C++ 기초 문법 — STL 컨테이너 (vector · pair · map · set)

> **코테 C++의 핵심.** 문제 풀이의 절반은 "어떤 컨테이너를 쓰느냐"로 결정된다. `vector`·`map`·`set`·`priority_queue`를 특히 깊게, 실전 패턴 위주로 다룬다.

---

## vector — 가변 배열 (제일 많이 씀)

> 크기가 자동으로 늘어나는 배열. **C++에서 가장 많이 쓰는 컨테이너.** 파이썬 list라고 보면 된다. (`#include <vector>`)

### 선언과 초기화

```cpp
vector<int> v1;                // 빈 벡터
vector<int> v2 = {1, 2, 3};    // 초기값
vector<int> v3(5);             // 크기 5, 전부 0
vector<int> v4(5, 7);          // 크기 5, 전부 7 → {7,7,7,7,7}
vector<int> v5(v2);            // v2 복사
```

> ⚠️ **소괄호와 중괄호는 뜻이 다르다.** `vector<int> a(5);`는 "크기 5(전부 0)", `vector<int> b{5};`는 "원소 `5` 하나"다. 크기를 정할 땐 소괄호를 쓴다.

### 주요 연산

```cpp
vector<int> v = {1, 2, 3};

v.push_back(4);      // 끝에 추가 → {1,2,3,4}
v.pop_back();        // 끝 제거    → {1,2,3}
v[0] = 10;           // 인덱싱 수정
cout << v.size();    // 3   (원소 개수)
cout << v.back();    // 3   (마지막 원소)
cout << v.front();   // 10  (첫 원소)
v.clear();           // 전부 삭제 → 빈 벡터
if (v.empty()) { }   // 비었는지 검사
```

| 연산 | 설명 | 복잡도 |
|------|------|--------|
| `push_back(x)` | 끝에 추가 | 평균 O(1) |
| `pop_back()` | 끝 제거 | O(1) |
| `v[i]` | 인덱스 접근 | O(1) |
| `size()` | 개수 | O(1) |
| `back()` / `front()` | 마지막 / 첫 원소 | O(1) |
| `insert(it, x)` | 중간 삽입 | O(n) |
| `erase(it)` | 중간 삭제 | O(n) |

> ⚠️ **빈 벡터에 `back()`/`front()`/`pop_back()`을 호출하면** 정의되지 않은 동작(런타임 에러/쓰레기 값)이다. 항상 `!v.empty()` 확인 후 접근하라.

### 순회

```cpp
vector<int> v = {1, 2, 3};

for (int x : v) cout << x << " ";        // 범위 기반 (복사)
for (int& x : v) x *= 2;                 // 참조 → 원본 수정
for (int i = 0; i < (int)v.size(); i++)  // 인덱스 순회
    cout << v[i];
```

### 크기 조정

```cpp
vector<int> v = {1, 2, 3};
v.resize(5);         // 크기 5로 (늘어난 칸은 0) → {1,2,3,0,0}
v.resize(2);         // 크기 2로 (뒤는 잘림)   → {1,2}
v.assign(4, 9);      // 크기 4, 전부 9로 재설정 → {9,9,9,9}
```

### 2차원 vector (격자 문제 필수)

> `N×M` 크기의 2차원 배열을 만들 때 가장 흔한 관용구.

```cpp
int N = 3, M = 4;
vector<vector<int>> grid(N, vector<int>(M, 0));  // 3×4, 전부 0

grid[1][2] = 5;                  // 접근
cout << grid.size();             // 3  (행 개수)
cout << grid[0].size();          // 4  (열 개수)

// 순회
for (int r = 0; r < N; r++)
    for (int c = 0; c < M; c++)
        cout << grid[r][c];
```

> 💡 `vector<vector<int>> grid(N, vector<int>(M, 0))`을 통째로 외워두면 좋다. 안쪽 `vector<int>(M, 0)`이 "M칸짜리 0 행"이고, 그걸 N개 복제한다.

## pair — 두 값 묶기

> 두 값을 하나로 묶는다. 좌표 `(r, c)`, "값-인덱스" 쌍 등에 필수. (`#include <utility>`, `<vector>`에도 딸려 옴)

```cpp
pair<int, int> p = {1, 2};
cout << p.first << " " << p.second;   // 1 2

p = make_pair(3, 4);                  // make_pair로도 생성
p.first = 10;                         // 수정

auto [x, y] = p;                      // 구조적 바인딩 (C++17) → x = 10, y = 4

// 좌표를 벡터에 담기 (BFS 큐 등에서 흔함)
vector<pair<int,int>> points;
points.push_back({1, 2});
points.emplace_back(3, 4);            // 안에서 바로 생성
```

> 💡 `pair`는 `<`로 비교하면 **first 먼저, 같으면 second** 순으로 비교된다. 그래서 `sort`하면 first 기준 정렬이 공짜다.

```cpp
vector<pair<int,int>> v = {{3,1}, {1,2}, {1,1}};
sort(v.begin(), v.end());   // {1,1}, {1,2}, {3,1}  (first→second 순)
```

### tuple — 세 값 이상 묶기

```cpp
#include <tuple>
tuple<int, int, int> t = {1, 2, 3};
cout << get<0>(t) << get<1>(t) << get<2>(t);   // 1 2 3

// 구조적 바인딩으로 한 번에 꺼내기 (C++17)
auto [a, b, c] = t;   // a=1, b=2, c=3

// 이미 선언된 변수에 넣을 땐 tie
int x, y, z;
tie(x, y, z) = t;     // x=1, y=2, z=3
```

> 💡 구조적 바인딩은 **새 변수를 선언**한다. 이미 있는 변수에 값을 넣으려면 `tie(...)`를, 값 하나만 필요하면 `get<i>(t)`를 쓴다.

## map / unordered_map — 키-값 (≈ 파이썬 dict)

> 키로 값을 저장·조회. **`map`은 키가 정렬**(트리)되고, **`unordered_map`은 해시**(더 빠름, 순서 없음)다.

### 기본 사용

```cpp
#include <map>
map<string, int> age;

age["건석"] = 25;            // 추가/수정
age["철수"] = 30;
cout << age["건석"];         // 25   (접근)
cout << age.size();          // 2

age.erase("철수");           // 삭제
```

### 키 존재 확인 (중요)

```cpp
if (age.count("건석")) { }               // 있으면 1, 없으면 0
if (age.find("건석") != age.end()) { }   // find로도 확인

// 찾은 값을 바로 쓸 땐 초기화문 if (C++17)
if (auto it = age.find("건석"); it != age.end()) {
    cout << it->second;                  // 25
}
```

> ⚠️ **`map`은 없는 키를 `[]`로 접근하면 그 키를 값 0으로 자동 생성한다**(파이썬 KeyError와 다름). 단순 조회에 `[]`를 쓰면 원치 않는 키가 늘어난다. **존재 확인은 `.count()`나 `.find()`로 하라.**
> ```cpp
> map<string,int> m;
> if (m["x"] > 0) { }   // ❌ "x"가 값 0으로 생겨버림
> if (m.count("x")) { } // ✅ 안전
> ```

### 빈도수 세기 (map의 대표 활용)

> 없는 키를 `[]`로 접근하면 0에서 시작하므로, `++`로 바로 카운트할 수 있다. (파이썬 `defaultdict(int)`와 유사)

```cpp
map<string, int> cnt;
vector<string> words = {"a", "b", "a", "a"};
for (const string& w : words) cnt[w]++;   // a:3, b:1
```

### 순회

> **구조적 바인딩(C++17)**으로 키와 값에 이름을 붙여 받는다. 구조적 바인딩 없이 `p.first`(키), `p.second`(값)로 접근해도 된다.

```cpp
for (const auto& [name, value] : age) {
    cout << name << " : " << value << "\n";
}

for (auto& p : age) {                    // 구조적 바인딩 없이
    cout << p.first << " : " << p.second << "\n";
}
// map은 키 오름차순으로 순회됨 (건석 → 철수)
```

> 💡 값을 고치려면 `auto& [name, value]`로 받는다. 키는 `const`라 바꿀 수 없다.

### insert 결과 받기 (구조적 바인딩, C++17)

> `map`·`set`의 `insert`는 `{위치 반복자, 새로 넣었는지(bool)}`를 반환한다. 구조적 바인딩으로 받으면 "처음 본 값인지"를 한 번에 확인할 수 있다.

```cpp
set<int> seen;
auto [it, inserted] = seen.insert(5);   // inserted = true  (처음 넣음)
auto [it2, again]   = seen.insert(5);   // again    = false (이미 있음)

if (seen.insert(x).second) { /* x를 처음 봤을 때만 실행 */ }

map<string, int> m;
if (auto [pos, ok] = m.insert({"a", 1}); ok) {   // 초기화문 if와 조합
    cout << "새 키 추가: " << pos->second << "\n";
}
```

> 💡 `insert`는 키가 이미 있으면 **값을 덮어쓰지 않는다.** 덮어쓰려면 `m[key] = value;`를 쓴다.

### map vs unordered_map

| | `map` | `unordered_map` |
|--|-------|------------------|
| 내부 | 트리(균형 이진) | 해시 테이블 |
| 순서 | 키 오름차순 정렬 | 순서 없음 |
| 조회/삽입 | O(log n) | 평균 O(1), 최악 O(n) |
| 언제 | 키 정렬·범위가 필요 | 빠른 조회만 필요 |

> 💡 **기본은 `unordered_map`이 빠르다.** 키 정렬 순회가 필요하거나 키가 pair/tuple처럼 해시가 까다로운 타입이면 `map`을 쓴다. (파이썬 dict는 `unordered_map`에 가깝다)

> ⚠️ `unordered_map<pair<int,int>, int>`는 **컴파일 에러**다. 표준 라이브러리가 `pair`용 해시 함수를 제공하지 않기 때문이다. 키가 `pair`면 `map`을 쓰거나, 좌표를 정수 하나로 바꿔(`r * M + c`) 키로 쓴다.

## set — 중복 없는 집합 (≈ 파이썬 set)

> 중복을 허용하지 않고 자동 정렬되는 집합. 원소 존재 확인·중복 제거에 쓴다. (`#include <set>`)

```cpp
#include <set>
set<int> s = {3, 1, 2, 1};   // 중복 제거 → {1, 2, 3} (오름차순)

s.insert(5);                 // 추가 → {1,2,3,5}
s.erase(1);                  // 삭제 → {2,3,5}
if (s.count(2)) { }          // 존재 확인 (0 또는 1)
cout << s.size();            // 3

for (int x : s) cout << x;   // 1 2 3 5  (정렬 순)
```

| | `set` | `unordered_set` | `multiset` |
|--|-------|------------------|------------|
| 정렬 | ✅ 오름차순 | ❌ 없음 | ✅ 오름차순 |
| 중복 | ❌ 불가 | ❌ 불가 | ✅ **허용** |
| 조회 | O(log n) | 평균 O(1) | O(log n) |

> 💡 `set`은 정렬 상태를 유지하므로 `*s.begin()`(최솟값), `*s.rbegin()`(최댓값)을 O(1)에 얻는다. 중복을 허용하며 정렬이 필요하면 `multiset`을 쓴다.

> ⚠️ `set`에서 특정 값을 지울 때 `s.erase(값)`은 그 값을 지우지만, `multiset`에서 `s.erase(값)`은 **같은 값 전부**를 지운다. 하나만 지우려면 `s.erase(s.find(값))`처럼 반복자로 지워야 한다.

## 참고

### emplace vs push

> `push`/`push_back`은 **만들어진 객체를 넣고**, `emplace`/`emplace_back`은 **컨테이너 안에서 바로 생성**해 약간 효율적이다.

```cpp
vector<pair<int,int>> v;
v.push_back({1, 2});      // pair를 만들어 넣음
v.emplace_back(1, 2);     // 안에서 바로 생성 (인자만 전달)
```

> 💡 코테에선 `push_back`으로 충분하다. `emplace_back`은 "인자를 바로 넘겨 생성하는 더 효율적인 버전" 정도로 알아두면 된다.
