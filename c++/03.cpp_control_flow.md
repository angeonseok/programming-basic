# 🔷 03. 제어문

> 조건에 따라 실행할 코드를 고르는 **조건문**(`if`, `switch`)과, 같은 코드를 되풀이하는 **반복문**(`for`, `while`)을 다룬다.

---

## 조건문

### if / else if / else

> 조건이 **참(true)**일 때 블록을 실행한다. 조건은 **소괄호 `()`**, 블록은 **중괄호 `{}`**로 감싼다.

```cpp
int score = 85;

if (score >= 90) {
    cout << "A\n";
} else if (score >= 80) {
    cout << "B\n";     // 실행됨
} else {
    cout << "C\n";
}
```

| C++ | 파이썬 대응 |
|-----|-------------|
| `if (...)` | `if ...:` |
| `else if` | `elif` |
| `else` | `else` |

> ⚠️ **`=`와 `==` 혼동 주의.** `if (x = 5)`는 비교가 아니라 **대입**이라 항상 참이 된다. 비교는 반드시 `==`.
> ```cpp
> if (x == 5) { }   // ✅ 비교
> if (x = 5)  { }   // ❌ 대입 → 항상 참 (단골 버그)
> ```

> 💡 C++ 조건은 **0이면 거짓, 0이 아니면 참**이다. `if (n)`은 `if (n != 0)`과 같고, `if (!v.empty())`처럼 bool 반환 함수를 바로 쓴다.

> ⚠️ **중괄호 생략 함정.** 블록이 한 문장이면 `{}`를 생략할 수 있다. 하지만 C++은 파이썬과 달리 **들여쓰기를 보지 않는다.** 생략한 채 문장을 추가하면 두 번째 문장은 조건과 무관하게 항상 실행된다.
> ```cpp
> if (a > b) swap(a, b);   // 한 문장이라 OK
>
> if (a > b)
>     swap(a, b);
>     cnt++;               // ❌ 들여쓰기와 달리 if 밖 → 항상 실행
> ```
> 한 문장이어도 `{}`를 붙이는 습관을 권한다.

### 초기화문이 있는 if / switch (C++17)

> 조건 앞에 `초기화; 조건` 형태로 변수를 선언할 수 있다. 그 변수는 **if/else(또는 switch) 블록 안에서만** 살아 있어서 이름이 바깥으로 새지 않는다.

```cpp
map<string, int> m = {{"a", 1}};

if (auto it = m.find("a"); it != m.end()) {
    cout << it->second << "\n";   // 1
} else {
    // else 블록에서도 it 사용 가능
}
// 여기선 it을 쓸 수 없다

switch (int d = n % 4; d) {
    case 0: cout << "나누어떨어짐\n"; break;
    default: cout << "나머지 " << d << "\n";
}
```

> 💡 `find` 결과처럼 **조건 검사에만 쓰고 버릴 변수**를 묶을 때 좋다.

### switch

> 하나의 정수/문자 값을 **여러 경우(case)로 분기**한다.

```cpp
int day = 3;
switch (day) {
    case 1: cout << "월\n"; break;
    case 2: cout << "화\n"; break;
    case 3: cout << "수\n"; break;   // 실행됨
    default: cout << "기타\n";
}
```

> ⚠️ **`break`를 빠뜨리면 다음 case로 줄줄이 실행된다(fall-through).** switch 최대 실수다.
> ```cpp
> switch (x) {
>     case 1: doA();          // break 없음 → case 2도 실행!
>     case 2: doB(); break;
> }
> ```
> (반대로 여러 case를 묶고 싶을 땐 fall-through를 일부러 이용한다.)
>
> C++17부터는 의도한 fall-through 자리에 `[[fallthrough]];`를 적는다. 실수가 아니라는 표시라서 컴파일러 경고도 사라진다.
> ```cpp
> switch (x) {
>     case 1: doA(); [[fallthrough]];   // 의도한 fall-through (C++17)
>     case 2: doB(); break;
> }
> ```

> 💡 `switch`는 정수·문자·`enum` 값 하나를 여러 경우로 나눌 때 읽기 좋다. 범위 조건(`score >= 90`)이나 문자열 비교는 `switch`로 할 수 없으니 `if/else if`를 쓴다.

## 반복문

### for

> C++ `for`는 `(초기화; 조건; 증감)` 세 부분을 직접 제어한다.

```cpp
for (int i = 0; i < 5; i++) {
    cout << i << " ";   // 0 1 2 3 4
}

for (int i = n; i >= 1; i--) { }   // 역순
for (int i = 0; i < n; i += 2) { } // 2칸씩
```

| | 파이썬 | C++ |
|--|--------|-----|
| 형태 | `for i in range(5):` | `for (int i = 0; i < 5; i++)` |
| 제어 | range가 알아서 | 초기화·조건·증감 직접 |

### 범위 기반 for (range-based for)

> 컨테이너의 원소를 **하나씩 순서대로** 꺼낸다. 파이썬 `for x in v`에 가장 가깝다. 인덱스가 필요 없을 때 간결하다.

```cpp
vector<int> v = {1, 2, 3};

for (int x : v)  cout << x << " ";   // 1 2 3 (복사본)
for (int& x : v) x *= 2;             // 참조 → 원본 수정 {2,4,6}
for (auto x : v) { }                 // 타입 자동 추론
```

> 💡 **원소가 크면(문자열·pair·구조체) `const auto&`로 받아라.** 복사 비용을 없앤다.
> ```cpp
> for (const auto& s : words) { }   // string 복사 안 함
> ```

> 💡 원소가 `pair`나 구조체면 **구조적 바인딩(C++17)**으로 바로 풀어 받을 수 있다.
> ```cpp
> vector<pair<int,int>> pts = {{1, 2}, {3, 4}};
> for (const auto& [r, c] : pts) cout << r << "," << c << " ";   // 1,2 3,4
> ```

### while / do-while

```cpp
int n = 0;
while (n < 3) {        // 조건 먼저 검사
    cout << n;         // 0 1 2
    n++;               // 종료 조건을 향해 변화시켜야 함
}

int m = 0;
do {
    cout << m;         // 0 1 2 (최소 1번은 실행)
    m++;
} while (m < 3);
```

> ⚠️ 조건을 변화시키는 코드가 없으면 **무한 루프**다. `while` 안에서 종료를 향해 상태가 바뀌는지 꼭 확인하라.

> 💡 `do-while`은 **조건 검사 전에 일단 한 번 실행**한다. "최소 1회 실행"이 필요할 때 쓴다.

### break / continue

> `break` 즉시 탈출, `continue` 다음 반복으로. 파이썬과 동일.

```cpp
for (int i = 0; i < 10; i++) {
    if (i == 5) break;          // 0~4까지만
    if (i % 2 == 0) continue;   // 짝수 건너뜀
    cout << i << " ";           // 1 3
}
```

## 중첩 반복문

### 중첩 반복문

> 반복문 안의 반복문. 2차원 데이터 처리의 기본이다.

```cpp
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        cout << i << "," << j << "  ";
    }
    cout << "\n";
}
```

> 💡 중첩 반복문 안의 `break`는 **안쪽 반복문만** 빠져나간다. 바깥까지 한 번에 나가려면 플래그 변수를 두거나, 아예 함수로 빼서 `return`하는 게 깔끔하다.

## 참고

### 삼항 연산자

> `조건 ? 참값 : 거짓값` — 한 줄 분기. (파이썬 `참값 if 조건 else 거짓값`에 대응)

```cpp
int age = 20;
string result = (age >= 18) ? "성인" : "미성년자";

int mx = (a > b) ? a : b;   // 두 수 중 큰 값 (max(a,b)와 동일)
```

### 무한 루프

> 조건을 항상 참으로 두는 반복. `break`로 탈출한다.

```cpp
while (true) {
    // ...
    if (cond) break;
}

for (;;) { }     // 같은 의미 (조건 생략 = 무한)
```

### 값 교환 swap

> 두 변수의 값을 맞바꾼다. 정렬·시뮬레이션에서 자주 쓴다. (파이썬 `a, b = b, a`에 대응)

```cpp
int a = 1, b = 2;
swap(a, b);      // a=2, b=1  (<utility> / <algorithm>에 포함)
```

> 💡 `swap`은 벡터·문자열 같은 큰 객체도 **내용을 통째로 교환**해준다(내부적으로 이동 처리라 빠름).
